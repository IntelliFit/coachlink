# 小程序端"我的档案"页面实现说明

## 功能概述

已完成小程序端"我的档案"详情页面的开发,功能与PC端保持一致,包括:

1. **个人信息展示与编辑** - 身高、体重、年龄、性别、健身目标、健身水平等
2. **运动数据卡片** - 支持7大运动类型(力量举、街头力量举、街头健身、举重、健美/形体、跑步、骑行)
3. **进步足迹(PR记录)** - 显示个人最佳记录历史
4. **教练评语** - 显示教练的反馈和建议

## 文件结构

### 新增文件

#### 1. 服务层 (Services)
- `src/services/studentService.ts` - 学员相关API服务
  - `getStudentProfile()` - 获取学员档案
  - `updateProfile()` - 更新个人档案
  - `getE1RMHistory()` - 获取E1RM历史
  - `getCurrent1RM()` - 获取当前1RM

- `src/services/subscriptionService.ts` - 订阅相关API服务
  - `getCoachSubscriptions()` - 获取教练订阅
  - `getCoachReviews()` - 获取教练评价

- `src/services/executionService.ts` - 训练执行相关API服务
  - `getPRRecords()` - 获取PR记录

#### 2. 页面组件
- `src/pages/profile/detail/index.tsx` - 档案详情页面主组件
- `src/pages/profile/detail/index.scss` - 档案详情页面样式
- `src/pages/profile/detail/index.config.ts` - 页面配置

### 修改文件

#### 1. 原profile页面
- `src/pages/profile/index.tsx` - 添加点击头像区域跳转到详情页的功能
- `src/pages/profile/index.scss` - 添加箭头图标样式

#### 2. 应用配置
- `src/app.config.ts` - 注册新页面路由

#### 3. 后端API (支持小程序token鉴权)
- `coachlink/src/app/api/user/get-student-profile/route.ts`
- `coachlink/src/app/api/subscription/get-coach-reviews/route.ts`
- `coachlink/src/app/api/subscription/coach-subscriptions/route.ts`
- `coachlink/src/app/api/execution/get-pr-records/route.ts`

所有API已更新为使用 `getAuthUser()` 统一鉴权函数,同时支持:
- 网页端: NextAuth Cookie Session
- 小程序端: JWT Token (Authorization header)

## 页面功能详解

### 1. 头部信息区
- 渐变背景设计
- 圆形头像展示
- 用户昵称/手机号
- 会员等级徽章

### 2. Tab切换栏
四个Tab页签:
- **个人信息**: 基本信息和健身目标
- **运动数据**: 各项运动的成绩卡片
- **进步足迹**: PR记录时间线
- **教练评语**: 教练反馈列表

### 3. 个人信息Tab
- 基本信息卡片: 身高、体重、年龄、性别
- 健身目标卡片: 训练目标、当前水平、生活作息
- 支持点击"编辑"按钮修改(当前版本需跳转到编辑页面)

### 4. 运动数据Tab
- 动态展示用户激活的运动卡片
- 可折叠/展开查看详细数据
- 力量举/街头力量举显示总和
- 支持的运动类型:
  - 力量举: 深蹲、卧推、硬拉
  - 街头力量举: 引体、双杠、俄挺、深蹲
  - 街头健身: 最大次数、静态动作保持时间
  - 举重: 抓举、挺举
  - 健美: 体脂率、各部位围度
  - 跑步: 5K、10K、半马、全马成绩
  - 骑行: FTP、最大功率、最远距离

### 5. 进步足迹Tab
- 按时间倒序显示PR记录
- 每条记录包含:
  - 动作名称
  - 日期(智能显示:今天/昨天/X天前/具体日期)
  - 负荷公式(如: 100kg × 5reps)
  - 重量和次数统计
  - 备注信息
- 空状态提示

### 6. 教练评语Tab
- 显示教练头像和姓名
- 评语内容
- 评价时间
- 空状态提示

## 数据流程

### 页面加载流程
```
1. 用户进入页面
   ↓
2. 从本地存储获取用户信息
   ↓
3. 检查登录状态
   ↓
4. 并行请求三个API:
   - getStudentProfile (档案数据)
   - getPRRecords (PR记录)
   - getCoachReviews (教练评语)
   ↓
5. 解析运动卡片数据
   ↓
6. 渲染页面内容
```

### 鉴权流程
```
小程序请求 → 携带token (Authorization: Bearer xxx)
            ↓
后端API → getAuthUser() 统一鉴权
            ↓
        验证token → 解析userId
            ↓
        查询数据库
            ↓
        返回数据
```

## 技术特点

### 1. 统一鉴权
- 使用 `getAuthUser()` 函数统一处理session和token鉴权
- 保持向后兼容,不影响现有网页端功能
- 支持小程序端JWT token鉴权

### 2. 数据解析
- 智能解析运动卡片数据结构
- 动态渲染激活的运动类型
- 字段名中英文映射

### 3. 性能优化
- 并行请求多个API
- 按需加载数据
- 折叠卡片减少渲染

### 4. 用户体验
- 加载状态提示
- 空状态友好提示
- 错误处理和提示
- 智能日期显示

## 注意事项

1. **登录状态**: 页面需要用户登录后才能访问,未登录会跳转到登录页
2. **Token有效期**: JWT token有效期7天,过期需重新登录
3. **数据权限**: 只能查看自己的档案数据
4. **网络请求**: 所有API请求会自动携带token,无需手动处理
5. **错误处理**: API请求失败会显示Toast提示
