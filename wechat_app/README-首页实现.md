## 技术实现

### 使用的技术栈
- **框架**: Taro 4.x + React 18
- **UI 组件**: NutUI React Taro
- **样式**: SCSS + Tailwind CSS（部分）
- **类型**: TypeScript

### 核心样式特性
1. **渐变背景**：浅橙色到白色的渐变背景
2. **光晕效果**：使用 CSS `blur` 滤镜实现背景光晕
3. **动画效果**：
   - 脉冲动画（徽章）
   - 横向滚动动画（卖点条）
   - 按钮点击缩放动画
4. **响应式设计**：移动端优先，适配不同屏幕尺寸
5. **安全区域**：适配 iPhone 刘海屏等设备

### 文件结构
```

├── index.scss        # 首页样式文件
└── index.config.ts   # 页面配置（自定义导航栏）
```

## 使用说明

### 开发模式运行
```bash
# 进入小程序目录
cd coachlink-wechat-app

# 启动微信小程序开发模式
npm run dev:weapp

# 使用微信开发者工具打开 dist 目录
```

### 页面配置
页面使用了自定义导航栏（`navigationStyle: 'custom'`），因此顶部导航栏完全由组件控制。

### 注意事项
1. **图标**：当前使用 Emoji，后续可以替换为图标字体或图片
2. **颜色值**：主色调使用 `#f97316`（橙色），需要与设计规范保持一致
3. **动画**：部分动画使用了 CSS3，注意在低端设备上的性能
4. **安全区域**：使用 `env(safe-area-inset-*)` 确保在刘海屏设备上正常显示
