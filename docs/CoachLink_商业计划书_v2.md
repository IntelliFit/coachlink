> **版本**：v2.0 — 从"力量训练工具"重新定位为"自由教练商业化基础设施"  
> **日期**：2026年4月

## 一、重新理解目标用户

### 1.1 谁是我们的用户？

**不是"力量训练教练"。是"有流量但缺乏交付系统的线上自由教练"。**

```
传统健身教练                    线上自由教练
     │                              │
     ▼                              ▼
┌──────────┐                ┌──────────────────┐
│ 在健身房 │                │ 在抖音/小红书/B站 │
│ 等客户   │                │ 发训练视频/干货  │
│ 上班    │                │ 积累粉丝         │
└──────────┘                └──────────────────┘
     │                              │
     │    ❌ 不是我们的用户         │    ✅ 这是我们的用户
     │                              │
     │ 痛点：重复做计划            │ 痛点：粉丝想跟我练，但我没法
     │                              │       系统地带 100 个人训练
     │                              │
     │ 需求：效率工具              │ 需求：从"内容"到"交易"到
     │                              │       "交付"的完整闭环
```

### 1.2 三种典型用户画像

#### 画像 A：短视频健身博主

> **小明**，抖音 50 万粉，发徒手训练/街健教学视频。
> 
> 每天评论区都是"能不能带我练""求计划"。
> 
> 他现在怎么做的？在评论区回"私信我"，然后微信加好友，收个几百块钱，发一段文字计划过去。
> 
> 带了 20 个人就忙不过来了。每个人的计划、跟进、答疑都是手动。想涨价但交付跟不上。
> 
> **他的核心问题**：有流量，有信任，但缺乏"规模化交付"的能力。

#### 画像 B：小红书上镜教练

> **Sarah**，小红书 10 万粉，主打女性塑形/减脂。
> 
> 开了知识星球，发了几个 PDF 计划，但学员执行率极低，没人反馈，没人打卡。
> 
> 三个月后学员说"没效果"，要求退款。
> 
> **她的核心问题**：卖出了"计划"，但没有卖出"跟进和监督"。计划离开了执行系统就是废纸。

#### 画像 C：退役运动员转型

> **老王**，前省级举重运动员，现在做自由教练。
> 
> 靠口碑和转介绍，线下带 10 个学员，月入 1.5 万。
> 
> 想拓展线上，但不知道怎么把线下那套"看动作、调计划、盯进度"搬到线上。
> 
> **他的核心问题**：有专业能力，但缺乏"线上交付"的产品化工具。

### 1.3 这三类人的共同特征

| 特征 | 说明 | CoachLink 的价值 |
|------|------|-----------------|
| **自有流量** | 不需要平台给流量，自己就是流量入口 | 不跟他们抢流量，而是帮他们变现流量 |
| **个人品牌优先** | 学员认的是"这个人"，不是平台 | 平台隐身幕后，教练品牌在前台 |
| **交付瓶颈** | 流量 > 交付能力，这是卡脖子的地方 | 用工具放大交付能力，让 1 个人能带 100 人 |
| **混合收入** | 既有高价私教，也想做低价规模化产品 | 支持多档位定价 |
| **非技术背景** | 不懂编程，不会做 App，不会做小程序 | 零代码搭建自己的"线上训练服务" |

## 二、核心洞察：自由教练商业化的三重门

```
┌──────────────────────────────────────────────────────────────┐
│                    自由教练商业化的三重门                       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   第一重：获客                    第二重：交易              第三重：交付
│      │                              │                          │
│      ▼                              ▼                          ▼
│   ┌──────┐                      ┌──────┐                   ┌──────┐
│   │短视频│                      │微信  │                   │微信  │
│   │直播  │         ──→         │转账  │        ──→        │发PDF │
│   │图文  │                      │红包  │                   │答疑  │
│   └──────┘                      └──────┘                   └──────┘
│      │                              │                          │
│   流量入口                     收款工具                    交付黑洞
│   ✅ 教练自己做                ⚠️ 不正规                   ❌ 完全不可规模化
│                                难追溯                      无执行追踪
│                                易纠纷                      无数据沉淀
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**CoachLink 解决的是第二重和第三重。**

- 第一重（获客）：教练自己解决，平台不碰
- 第二重（交易）：平台提供正规订阅+支付+结算
- 第三重（交付）：平台提供计划下发→执行追踪→视频点评→进度反馈的完整闭环

**关键洞察**：自由教练不是缺"训练计划模板"，是缺"把粉丝变成付费学员、并让他们真正练起来"的一整套系统。

### 3.3 核心产品能力（按价值排序）

#### 🔥 第一优先级：让教练"能卖出服务"

| 功能 | 解决的问题 | 场景 |
|------|-----------|------|
| **教练主页/微店** | 粉丝点进来看到什么 | 抖音简介挂链接，粉丝点进来就是教练的品牌页+服务介绍+订阅入口 |
| **三档服务定价** | 卖多少钱、包含什么 | 基础版（仅计划）¥99/月，进阶版（计划+每周点评）¥299/月，全能版（1对1指导）¥599/月 |
| **一键订阅+支付** | 怎么收钱 | 学员选档位→支付宝付款→自动开始服务 |

#### 🔥 第二优先级：让学员"真正练起来"

| 功能 | 解决的问题 | 场景 |
|------|-----------|------|
| **今日训练推送** | 学员不知道今天练什么 | 每天打开微信/小程序，直接显示当天任务 |
| **自动算重量** | 学员不会算、算不准 | 输入 1RM 后，系统自动算出今天每组该用多少公斤 |
| **视频上传+教练点评** | 动作错了没人纠正 | 每组训练后可上传视频，教练用文字/语音批改 |
| **打卡分享卡片** | 练了没动力坚持 | 生成精美数据卡片，发朋友圈有面子 |

#### 🔥 第三优先级：让教练"一个人带更多人"

| 功能 | 解决的问题 | 场景 |
|------|-----------|------|
| **AI 智能导入** | 计划录入太麻烦 | 把别的计划复制粘贴，AI 自动识别生成结构化模板 |
| **AI 虚拟分身** | 重复问题太多 | "深蹲膝盖内扣怎么办"这类问题 AI 自动回复 |
| **批量操作** | 改计划太繁琐 | "把所有人下周三的卧推从 5 组改成 4 组"一键完成 |
| **学员进度看板** | 不知道谁在掉队 | 一眼看到"本周已练 3 天/0 天/掉队" |

## 四、商业模式重构

### 4.1 收入模型：SaaS + 交易抽成 双引擎

```
                    CoachLink 收入结构
                          │
            ┌─────────────┼─────────────┐
            │             │             │
            ▼             ▼             ▼
      ┌─────────┐   ┌─────────┐   ┌─────────┐
      │ SaaS订阅 │   │交易抽成 │   │增值服务 │
      │(教练端) │   │(双边)   │   │(双边)   │
      └─────────┘   └─────────┘   └─────────┘
            │             │             │
            ▼             ▼             ▼
      • 基础版免费    • 学员订阅费     • 知识库会员
      • 进阶版收费    • 平台抽 10%     • 数据分析报告
      • 高级版收费    • 教练拿 90%     • 企业版
```

#### 引擎一：SaaS 订阅（教练端）

这是最重要的战略调整：**向教练收工具费，而不是只抽学员的交易。**

为什么？
- 自由教练的学员是自己带来的，平台没有流量成本
- 如果抽成太高（20-30%），教练会觉得"不划算"
- 但如果收的是"工具费"，教练会觉得"这是我做生意的基础设施成本"

| 档位 | 月费 | 功能 | 目标用户 |
|------|------|------|----------|
| **免费版** | ¥0 | 最多 5 个学员、基础计划模板、基础执行追踪 | 刚起步的小教练 |
| **进阶版** | ¥99/月 | 最多 30 个学员、AI 导入、视频点评、AI 分身 | 有稳定收入的自由教练 |
| **专业版** | ¥299/月 | 无限学员、批量操作、高级数据看板、白标主页 | 全职线上教练 |

**定价逻辑**：
- 进阶版 ¥99/月，如果教练带 20 个学员、每人 ¥200/月，教练月收入 ¥4000，工具成本只占 2.5%
- 这比抽 20% 友好得多，而且收入可预测

#### 引擎二：交易抽成（轻抽成）

| 场景 | 抽成比例 | 说明 |
|------|----------|------|
| 通过平台支付通道完成的订阅 | 10% | 远低于行业 20-30%，因为获客是教练自己的 |
| 教练使用自有收款码 | 0% | 平台不干涉，但鼓励用平台通道（有交易记录） |

**关键设计**：抽成要低到教练觉得"无所谓"，目的是让交易发生在平台上（形成数据沉淀），而不是为了赚这笔抽成。

#### 引擎三：增值服务

| 服务 | 定价 | 说明 |
|------|------|------|
| 学员端会员（非私教用户） | ¥19-49/月 | 不找教练、但想用工具的散户 |
| 数据分析报告 | ¥9.9-29.9/份 | 学员训练数据深度分析（可教练代买） |
| 企业/健身房版 | 按需 | 健身房批量入驻，统一管理 |

### 4.2 为什么这套模式能跑通？

对比三种可能的商业模式：

| 模式 | 代表 | 问题 | CoachLink 选择 |
|------|------|------|---------------|
| **纯交易抽成** | 传统健身平台 | 需要平台有流量，否则教练不愿意给抽成 | ❌ 不适合 |
| **纯 SaaS** | Trainerize | 收入天花板明显，只能服务付费意愿强的教练 | ⚠️ 部分采用 |
| **SaaS + 轻抽成** | CoachLink | 工具费保证基础收入，交易抽成提供增长空间 | ✅ 采用 |

### 4.3 单位经济模型（以一位中等规模教练为例）

> **李教练**：抖音 10 万粉，全职自由教练，用 CoachLink 进阶版

| 项目 | 数值 |
|------|------|
| 月工具费 | ¥99 |
| 带学员数 | 25 人 |
| 人均月订阅费 | ¥200 |
| 月总收入 | ¥5,000 |
| 平台抽成（10%） | ¥500 |
| 平台总月收入（该教练）| ¥599 |
| 教练净收入 | ¥4,401 |
| 教练工具成本占比 | 12% |

**规模化假设**：
- 100 位活跃教练 × 平均 ¥600/月平台收入 = **¥60,000/月**
- 500 位活跃教练 = **¥300,000/月**

### 5.2 竞品分析

| 竞品 | 定位 | 优势 | 劣势 | 我们与他们的关系 |
|------|------|------|------|-----------------|
| **Keep** | 大众健身内容平台 | 流量大、品牌强 | 标准化内容，无个性化教练服务 | 不竞争。Keep 的教练是平台雇员，我们的教练是独立创业者 |
| **训记** | 训练记录工具 | 记录体验极好 | 无教练连接能力 | 互补。训记用户可能是我们的学员端用户 |
| **Trainerize** | 海外教练管理工具 | 功能成熟 | 国外生态、定价高、无小程序 | 直接竞品，但我们本土化+小程序是优势 |
| **知识星球** | 付费社群 | 门槛低、变现快 | 无训练执行系统，就是发图文 | 替代关系。我们能提供更好的交付体验 |
| **微信私域** | 最原始的方案 | 灵活、零成本 | 完全不可规模化、无数据 | 替代关系。我们的目标就是让教练从微信迁移过来 |

### 5.3 核心竞争力（为什么是我们）

| 壁垒 | 说明 |
|------|------|
| **1RM 自动算重** | 技术门槛高，竞品很难短时间复制 |
| **模板-实例体系** | 教练一次创建，无限复用+自动个性化 |
| **视频上下文** | 学员发视频自动带训练背景，解决线上教练"看不到"的痛点 |
| **小程序+Web 双端** | 学员用小程序（轻量），教练用 Web（功能全） |
| **AI 分身** | 用教练自己的资料库回答学员，降低维护成本 |

## 九、团队与资源需求

### 9.1 当前团队缺口

| 角色 |  urgency | 说明 |
|------|----------|------|
| **教练成功经理（CSM）** | 🔴 最急 | 负责教练入驻、培训、跟进、案例打造。这是当前最 bottleneck 的角色 |
| **内容运营** | 🟡 急 | 负责标杆案例内容、教练社群运营、获客内容 |
| **用户增长** | 🟡 急 | 学员端获客、产品驱动的病毒传播 |
| **移动端工程师** | 🟢 中 | 小程序体验优化 |

### 9.2 为什么"教练成功经理"是最关键的岗位

```
没有 CSM 的情况：
  教练注册 → 看到一堆功能 → 不知道第一步做什么 → 3天后忘记这个平台 → 流失

有 CSM 的情况：
  教练注册 → CSM 1v1 打电话 → 帮他设置主页 → 帮他设计第一档服务 
    → 帮他发第一条获客内容 → 收到第一笔订阅 → 教练觉得"这东西真能赚钱" → 留存
```

**这个岗位的价值不是"客服"，是"教练的商业化教练"。**

## 十一、总结

### 11.1 一句话总结

> **CoachLink 不是给"健身教练"用的训练计划工具。**  
> **CoachLink 是给"有流量、有知识、但缺交付系统的线上自由教练"用的商业化操作系统。**

### 11.2 核心逻辑

1. **获客是教练自己的事**（抖音/小红书/朋友圈）
2. **交易和交付是 CoachLink 的事**（订阅、支付、计划下发、执行追踪、视频点评）
3. **教练收入增加了，平台收入自然增加**

### 11.3 为什么现在能做

| 条件 | 状态 |
|------|------|
| 产品已完备 | ✅ 120+ 页面、完整闭环 |
| 付费已验证 | ✅ 14 人付费、客单价 ¥180 |
| 市场时机 | ✅ 大量健身教练正在从线下转向线上 |
| 核心瓶颈 | 🔴 教练入驻后不知道怎么用 → **这是运营问题，不是产品问题** |
