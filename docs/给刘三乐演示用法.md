1. 产品简介
Coach Link 是一个专为力量训练教练和学员打造的智能化线上执教平台。它不仅仅是一个训练记录工具，更是一个连接教练与学员的生态系统。通过 AI 辅助、自动化的数据追踪和丰富的社区互动，Coach Link 致力于将教练从繁琐的重复劳动中解放出来，同时为学员提供精准、科学且具有社交乐趣的训练体验。


---

2. 核心优势（宣传亮点）
在此次演示中特别强调的差异化优势，适合用于推广视频：

- ⚡️ 极速 AI 计划导入：不需要一个个手动点击添加动作。直接复制粘贴文本格式的计划（如聊天记录、文档），AI 自动识别动作、组数、次数、休息日，一键生成结构化模板。
- 📊 动态负荷管理：支持固定重量、百分比（%1RM）或 RM 区间设置。学员端根据最新极限数据（1RM）自动计算并填充当日训练重量，真正做到千人千面的科学负荷。
- 🎬 视频上下文交互：拒绝无效沟通。学员在聊天中发送训练视频时，系统自动附带该视频对应的“第几周、第几天、多大重量”等数据标签，教练点开即懂，无需反复询问背景信息。
- 🎥 一次上传，永久复用：教练建立个人动作库并上传讲解视频后，可应用到所有学员计划中。动作库支持更新，所有学员端同步即时生效。
- 📈 自动化进步足迹：学员只要打破纪录或提升数据，系统自动捕捉并生成“进步足迹”档案，让进步可视化，极大提升学员留存率。
- 🏆 趣味竞技社区：内置多维度排行榜（如负重引体、深蹲等），支持“严格/宽松”双标准，激发学员胜负欲，增加平台活跃度。

3. 教练使用指南

3.1 初始设置与主页
- 个人主页定制：设置专业领域、教学经验、个人简介及社交媒体账号。你的主页就是你的线上名片。
- 收款设置：
  - 直接收款：上传个人的微信/支付宝收款码。
  - 平台代收：使用平台支付通道（记录清晰，防逃单），资金进入“我的钱包”，可随时提现（类似抖音/B站机制）。
- 服务定价：自定义三个档位的服务（如：基础版、进阶版、全能指导版）。支持按月、按季度或自定义时长收费。
  
3.2 学员入驻与问卷
- 入驻流程：学员订阅课程 -> 自动触发入驻问卷。
- 问卷定制：
  - 必填项：系统预设（训练项目、每周频次、当前极限数据）。
  - 自定义项：教练可添加选项类（如器械条件）或文本类（如伤病史、饮食习惯、恢复能力）问题，体现个性化服务。
- 档案管理：问卷填完后自动生成“学员档案”，支持后续随时更新（如极限数据提升），计划重量也会随之自动调整。
  
3.3 计划制定（核心功能）
- 模板库管理：
  - 智能导入：复制文本计划 -> AI 识别（耗时几十秒至1分钟） -> 生成模板。
  - DeepSeek 辅助：可先用 DeepSeek 生成文本，再导入平台。
  - 手动微调：针对 AI 识别不准或特殊需求，可手动修改动作、组数、强度。
- 强度设置：
  - 支持 %1RM（如 80%）、RM区间（如 5-6RM）、固定重量（kg）。
  - 智能取值：对于区间范围（如 5-6RM），系统会根据算法取一个确定的计算值，也可手动调整保守或激进策略。
- 计划下发：将模板分配给学员，系统根据学员档案中的 1RM 数据，自动计算出每天、每组的具体重量（精确到 2.5kg 倍数）。
  
3.4 教学与反馈
- 动作讲解：在动作库中上传独家视频演示，学员点击动作名即可查看。
- 视频点评：在学员上传训练视频后，进行文字或语音点评。
- 沟通互动：使用内置聊天系统，支持发送视频、图片。
- 内容管理：发布专属教学材料（文章/视频），可设置为“仅订阅学员可见”。

4. 学员使用指南

4.1 开始训练
- 今日训练视图：登录后直接显示当天任务，无需翻找。
- 自主调整：
  - 重量微调：觉得预设的 50kg 太轻？可手动改为 60kg，后续组数自动联动。
  - 视频上传：每一组均可上传本地视频或现场录制，供教练检查。
- 打卡分享：训练结束后生成类似“训记”的精美数据卡片，支持扫码分享到微信群，为教练和平台引流。
  
4.2 数据与成长
- 个人档案：查看自己的订阅时长、训练历史、身体数据。
- 进步足迹：系统自动记录每一个 PR（个人最佳成绩），形成时间轴。
- 视频集：付费会员拥有更大的云存储空间，用于保存训练视频库。
  
4.3 社区与社交
- 排行榜：参与平台发起的挑战（如引体向上），上传视频经审核后上榜，赢取潜在奖金。
- 好友互动：添加训练搭子为好友，查看对方的训练记录和动态。

5. 平台商业模式与生态（针对运营方/教练）

5.1 盈利模式
1. 教练抽成：
  - 平台从教练收取的学费中抽取一定比例（约 10%-20%）。
  - 阶梯费率：带学员越多，抽成比例越低，鼓励做大做强。
2. 会员订阅（非私教用户）：
  - 针对不找教练的“散户”，提供基础/高级会员。
  - 权益包括：AI 计划导入功能、更大的视频存储空间、查看高级动作库、参与特定活动等。
    
5.2 平台生态
- 流量转化：通过好用的工具属性（打卡、视频存储、排行榜）吸引普通用户，这些用户是潜在的私教客户池。
- 拓展性：未来将加入饮食计划、睡眠监控，并从力量举扩展到健美、有氧甚至线下健身房合作专区。
- 小程序规划：目前为 Web 端（手机适配），内测稳定后将推出微信小程序，体验更流畅。
