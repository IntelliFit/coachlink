# CoachLink 微信分账审核口径说明

本说明用于统一微信合作伙伴计划分账申请材料、站内条款和后续产品口径，避免“申请文件这么写、实际页面那么写”的冲突。

## 一、统一业务口径

### 1. 平台角色

平台应统一表述为：

- 提供信息展示、教练筛选、交易系统、支付代收、订单管理、客服受理、售后协调、规则治理和技术支持；
- 对平台自营内容、平台标准化功能或页面明确标注由平台直接提供的服务承担相应责任。

### 2. 教练角色

教练应统一表述为：

- 入驻平台的具体教练服务提供方；
- 对其发布的服务内容、服务质量、履约结果、宣传信息和合法合规性承担直接责任；
- 应配合平台处理退款、投诉、纠纷和监管核查。

### 3. 用户角色

用户应统一表述为：

- 在平台浏览、下单并购买教练服务的消费者；
- 享有知情权、选择权、公平交易权、售后保障权和投诉申诉权。

## 二、资金流口径

统一写法建议如下：

1. 用户购买教练服务时，订单款项由平台统一代收。
2. 平台根据订单履约状态、退款情况及平台规则向教练进行分账或结算。
3. 平台可收取平台服务费、技术服务费或其他已明示费用。
4. 如发生退款、投诉、异常交易、违规处罚或先行赔付，平台有权从待结算款项中扣减、冻结或追偿。

不建议继续出现的表述：

- “用户直接支付给教练，平台不参与资金结算”
- “退款由教练与用户自行协商，平台不介入”
- “平台仅做展示，不承担任何售后协调义务”

## 三、责任边界口径

建议采用“分层责任”而非“完全免责”：

1. 平台不宜写成“完全不承担任何责任”。
2. 更稳妥的写法是：平台在其承诺的审核、交易保障、客服协调、信息安全保护等范围内承担相应责任。
3. 教练对其具体教练服务独立履约并承担直接责任。
4. 平台在必要情况下可以先行向用户退款、垫付或赔付，之后向责任教练追偿。

## 四、退款与消费者保护口径

建议保留的重点句式：

- 用户可基于误购、重复支付、服务未开始、服务与页面说明严重不符、教练未履约等情形发起退款申请。
- 平台将依据付款时间、履约状态、已使用权益、聊天与服务记录等因素审核退款申请。
- 平台设立统一客服渠道、投诉入口和争议处理流程。
- 平台建立商户审核、违规处理、异常交易识别和资金冻结机制。
- 平台在必要情况下可启动先行保障机制。

## 五、提交材料中的占位信息

以下信息仓库中尚未完整沉淀，提交前建议替换：

- 平台运营主体全称
- 平台联系地址
- 生效日期
- 如需更正式，可补充统一社会信用代码、投诉受理工作时效、结算周期具体值

## 六、提交前检查清单

1. 上传的三份文件是否全部使用“平台代收后分账”的统一口径。
2. 站内 `terms.md` 是否已移除“个人收款”“平台不介入退款”等旧说法。
3. 客服邮箱、电话、地址是否真实可用。
4. 如页面存在退款说明、支付弹窗、教练入驻说明，是否与本次材料一致。
5. 如当前生产环境尚未正式切到平台代收模式，是否已有明确上线改造计划以应对后续抽检。
