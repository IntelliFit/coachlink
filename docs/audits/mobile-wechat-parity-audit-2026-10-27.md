## 3. 本轮发现的问题与处理

1. **已定（2026-11-06）：教练记录对学员可见，统一叫「教练评语」**。原来教练端叫「教练私密记录」，学员个人资料页以「教练评语」展示同一批数据。用户决定保留学员可见，三端教练端都改名为「教练评语」并注明学员能看到。
2. **已修：教练记录接口缺少归属校验**。`get-coach-reviews` 不传筛选时会返回全表、传任意 `subscriptionId` / `studentId` 都能读；`create-coach-reviews` 信任请求里的 `coachId` / `subscriptionId` / `studentId`。现在统一走 `src/lib/coachReviewAccess.ts`：学员只读自己的，教练只读写自己名下订阅上的，写入 id 以订阅为准。
3. **已修：小程序动作库「引用」调用不存在的接口**。改为 `/api/student/action-lib/action-references`（参数 `actionIds`），展示计划名和引用处数。
4. **已修：小程序 e1RM 页曲线和 PR 列表**。接口返回的点是 `{ date, e1rm, isPR }`，页面却读 `value` 和不存在的 `prRecords`，线上曲线画不出、PR 列表恒为空；现在加载时转换字段，并按 `isPR` 推导 PR 列表。
5. **已修：休息时间单位**。统一按秒存、按分钟显示（见 DECISIONS 2026-10-27）。小程序教练「学员计划」页原来把分钟直接写进「休息时间」（执行端按秒读，设 2 分钟学员会拿到 2 秒）；只读核查线上进行中/暂停计划没有受影响的数据。
6. **已改（2026-10-29）：小程序训练执行页的间歇文案**（`formatRestSummary`）改为按分钟显示。
