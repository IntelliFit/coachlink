## 1. 本轮目标

本轮不是“再做一批新功能”，而是把已有功能重组成一个更容易理解、更适合新手开始、也能承接进阶用户的产品路径。

核心目标：

```text
让用户一进来知道：
1. 我现在处在哪条路径
2. 我今天该做什么
3. 为什么这样做
4. 卡住时去哪里找内容、教练或工具
```

小程序优先，因为它是用户真实训练时最可能打开的入口。Web 作为桌面端/补充端，后续同步同一套信息架构，但不抢第一阶段主工期。

## 3. 本轮产品定位

建议本轮把学生端从：

```text
训练 + 发现 + 工具 + 消息 + 个人
```

改成：

```text
今日 / 路径或能力 / 教练 / 我的
```

其中：

- `今日`：主入口，回答“我现在该做什么”。
- `路径/能力`：承接动作标准、知识内容、阶段进阶，不是泛知识库。
- `教练`：按问题提供支持，不是市场广场。
- `我的`：收纳历史、会员、消息、工具、排行榜、商城、设置。

### 待确认命名

一级导航第二项有两个候选：

1. `能力`
   - 优点：和能力树原型一致，有长期品牌感。
   - 缺点：对新手稍抽象。

2. `路径`
   - 优点：更直白，小白更容易理解“我在哪条路上”。
   - 缺点：长期成长感弱一点。

我倾向第一阶段小程序用 `路径`，页面内再表达“能力成长”。如果要强化能力树品牌，可以用 `能力`。

### 4.2 小程序首页

当前首页更像功能入口页。第一阶段有两种处理方式：

#### 方案 A：登录用户直接进入今日页

- `/pages/index/index` 保留给游客/未登录。
- 登录用户打开首页时，引导进入 `/training/today-training`。
- 优点：最直接，主线清楚。
- 缺点：首页现有功能需要重写较少，但游客体验仍需整理。

#### 方案 B：首页改成轻量今日路径首页

- 保留 `/pages/index/index`，但重写为“路径首页”。
- 首页展示：
  - 当前阶段
  - 今日主按钮
  - 本周只做 3 件事
  - 低暴露训练提示
  - 进入今日训练
- 优点：无需改变首页入口语义。
- 缺点：和 `/training/today-training` 会有一定重复。

我建议第一阶段选方案 A：让真实训练主线集中在 `today-training`，首页仅作为游客/品牌入口和兜底页。

文件：

- `wechat_app/src/pages/index/index.tsx`
- `wechat_app/src/pages/index/index.scss`

改动：

首屏顺序建议：

```text
1. 当前路径卡
   例：安全起步 · 第 1 周
   你现在先解决：怕练错 + 时间少 + 不敢进健身房

2. 本周只做这 3 件事
   - 完成 2 次低暴露训练
   - 每餐补一个蛋白质来源
   - 训练前检查肩/腰/膝

3. 今日主行动卡
   继续复用 TodayTrainingCard，但主按钮更明确：
   - 开始今天训练

   - 训练前哪里疼要停

6. 卡点升级
   - 动作不确定：找动作纠错
   - 怕进健身房：新手护航
   - 练了没效果：平台期诊断
```

保留：

- 现有训练执行入口。

- 现有轻量任务打卡。
- 现有计划须知弹窗。

隐藏或后置：

- 复杂周历/月历默认后置或折叠。
- 多教练切换保留，但不抢首屏。
- 计划库/历史/临时训练入口保持二级操作。

新手心理安全要求：

- 文案不要暗示“不自律就是失败”。
- 允许保底训练：
  - `今天很累？做 3 分钟保底版`
  - `漏一天不算失败，系统会顺延`
- 低暴露训练优先：
  - 家里
  - 宿舍
  - 户外
  - 健身房角落

## 12. 成功标准

做完第一阶段后，一个新手打开小程序应该能说清楚：

- 我今天要点 `今日`。
- 我不是要自己乱选功能，系统会告诉我本周做什么。
- 我如果不敢去健身房，可以先做低暴露训练。
- 我想知道动作怎么做，去 `路径`。
- 我需要人看动作或帮我突破，去 `教练`。
- 工具、记录、会员、消息、排行都在 `我的`。

这就是第一阶段的核心价值。
