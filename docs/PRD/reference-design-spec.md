# 小程序重构视觉与交互参考规范

> 参考图来源：`app/参考图/reference-dribbble.png`（Dribbble 健身类 App 设计稿）  
> 用途：作为 CoachLink 微信小程序端 UI/UX 大规模重构的核心视觉锚点。

---

## 一、整体设计语言（Design Language）

### 1.1 色彩体系

| 角色 | 色值（近似） | 用途 |
|------|-------------|------|
| **背景色** | `#F2F2F2`（浅灰） | 页面全局底色 |
| **卡片色** | `#FFFFFF` | 所有内容卡片、浮层、底部导航 |
| **主强调色** | `#f97316`（活力橙，项目主题色） | 按钮、进度条填充、图标高亮、选中态 |
| **次级强调色** | `#fb923c`（浅橙，项目副色） | 图表辅助色、次要高亮、渐变终点 |
| **主文字** | `#1A1A1A` | 标题、重要数据 |
| **次级文字** | `#6B6B6B` | 标签、说明、时间戳 |
| **描边/分隔线** | `#E5E5E5` | 卡片边缘、列表分隔 |

### 1.2 字体与排版

- **字体风格**：圆润无衬线（Inter / SF Pro / PingFang SC 均可），字重偏粗以提升运动感
- **标题**：32–40px，Bold，左对齐，贴近顶部留出呼吸感
- **数据大字**：24–28px，Semibold
- **标签/说明**：12–14px，Regular，次级灰
- **数字字体**：建议使用等宽或 Tabular 数字，保证数据对齐

### 1.3 圆角与阴影

- **大卡片**：圆角 `24rpx – 32rpx`
- **小卡片/按钮**：圆角 `16rpx – 24rpx`
- **图标容器**：正圆或 `50%` 圆角
- **阴影**：不使用强投影，依靠浅灰背景与白色卡片形成自然层次（Card-on-Canvas）

### 1.4 布局节奏

- **页面边距**：左右 `32rpx`（或 40rpx）
- **卡片内边距**：`24rpx – 32rpx`
- **模块间距**：`32rpx – 40rpx`
- **底部安全区**：固定底部导航高度约 `100rpx`，并适配 iPhone 底部横条

### 1.5 图标风格

- **线面结合**：细线轮廓（1.5px）+ 面性填充小点缀
- **尺寸**：快捷入口图标 `48rpx – 64rpx`，置于 `96rpx` 圆形浅灰底容器中

## 二、页面一：Dashboard（今日概览页）

### 2.1 页面定位
- **对应现有小程序页面**：`今日训练` / `个人中心` / `首页` 的融合态
- **核心功能**：一屏呈现用户今日目标完成度、快捷入口、核心数据摘要

### 2.2 结构拆解（从上到下）

| 区域 | 元素 | 设计说明 |
|------|------|----------|
| **StatusBar** | 时间 9:41、信号、电量 | 系统态，无需额外设计 |
| **Greeting区** | 大标题 "Let's start strong!" | 36px Bold，黑色，左对齐，距顶部 48rpx |
| **目标进度卡片** | 白色大卡片，圆角 28rpx | 左侧文字 "You're 45% to your daily goal"，右侧橙色闪电圆形图标 |
| | 进度条 | 灰色轨道 8rpx 高，橙色填充 45%，右侧显示 "2,340/8,000" |
| **快捷入口网格** | 4 个等宽圆形图标按钮 | Workout / Meal / Water / Sync，图标置于浅灰圆底中，下方 12px 标签 |
| **Daily Summary** | 小节标题 | 20px Semibold，左对齐 |
| | 两列数据卡片 | Steps（左）带环形进度图 + Calories Burned（右）大数字展示 |
| **底部导航** | 悬浮式胶囊导航 | 深灰底圆角胶囊，内含 4 个图标：Dashboard（当前选中，橙色高亮）/ 文档 / 闪电 / 个人 |

### 2.3 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 闪电图标（目标卡片） | button | 跳转目标详情或激励提示 | 目标设置页 |
| Workout | icon-button | 跳转训练入口 | 今日训练页 |
| Meal | icon-button | 跳转饮食记录 | 饮食记录页 |
| Water | icon-button | 跳转饮水记录 | 饮水打卡页 |
| Sync | icon-button | 同步健康数据 | 设备同步弹窗 |
| Steps 卡片 | card | 查看步数历史 | 数据详情页 |
| Calories 卡片 | card | 查看卡路里历史 | 数据详情页 |
| 底部 Dashboard | tab-icon | 当前页高亮 | — |
| 底部文档图标 | tab-icon | 跳转内容/知识库 | 知识库首页 |
| 底部闪电图标 | tab-icon | 跳转训练/发现 | 训练页 |
| 底部个人图标 | tab-icon | 跳转个人中心 | 个人中心页 |

### 2.4 状态与异常态

- **加载中**：骨架屏保留卡片轮廓，数字区域显示灰色脉冲块
- **无目标**：进度条显示 0%，文案变为 "Set your first daily goal"，按钮变为 CTA
- **设备未授权**：Sync 图标置灰，点击弹出授权引导

## 三、页面二：Progress（数据进度页）

### 3.1 页面定位
- **对应现有小程序页面**：`训练记录` / `当前计划` / `计划历史` 的数据可视化升级
- **核心功能**：以图表和圆环展示周/月维度的运动、站立、步数、距离数据

### 3.2 结构拆解

| 区域 | 元素 | 设计说明 |
|------|------|----------|
| **顶部 Tab** | Daily / Weekly / Monthly | 白色胶囊分段器，选中项白底黑字带微弱阴影，未选中项透明底灰字 |
| **橙色提醒卡片** | 全宽圆角卡片，橙红渐变底色 | 顶部有小头像/徽章，文案 "Stretching after workouts improves your sleep quality." |
| | 双按钮 | Dismiss（透明底白字）/ Set Routine（白底黑字） |
| **运动圆环区** | 大圆环图表 | 左侧黑色 Exercise 弧 + 次级色 Stand 弧，右侧数据标签 "240/600min"、"160/600min" |
| **步数与距离** | 底部两列白色卡片 | 左侧 Steps 柱状图（2,340），右侧 Distance 折线图（3.4km） |
| **底部导航** | 同 Dashboard | 当前选中 Progress（橙色高亮） |

### 3.3 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| Daily | tab | 切换日视图数据 | — |
| Weekly | tab | 切换周视图数据（默认选中） | — |
| Monthly | tab | 切换月视图数据 | — |
| Dismiss | button | 隐藏提醒卡片 | — |
| Set Routine | button | 跳转拉伸计划设置 | 计划设置页 |
| Exercise 圆环 | chart | 点击展开 Exercise 详情 | 详情弹窗 |
| Stand 圆环 | chart | 点击展开 Stand 详情 | 详情弹窗 |
| Steps 卡片 | card | 查看步数趋势大图 | 步数详情页 |
| Distance 卡片 | card | 查看距离趋势大图 | 距离详情页 |

### 3.4 状态与异常态

- **数据加载中**：圆环显示虚线轮廓，数字区域显示 "—"
- **无数据**：图表变为空状态插画 + "No activities yet this week"
- **提醒已关闭**：橙色卡片以向上滑出动画消失，下方内容自动顶补

## 四、页面三：AI Assistant（AI 助手页）

### 4.1 页面定位
- **对应现有小程序页面**：`消息中心` / `智能生成计划` / `教练沟通` 的融合升级
- **核心功能**：对话式 AI 交互，以气泡形式展示问答、数据反馈、快捷操作

### 4.2 结构拆解

| 区域 | 元素 | 设计说明 |
|------|------|----------|
| **对话历史** | 用户气泡（右）+ AI 气泡（左） | 用户气泡浅灰底圆角，AI 气泡白底圆角带轻微阴影 |
| **数据反馈卡片** | 横向滚动卡片组 | "You burned 420 kcal across 3 activities" 后紧跟 3 个活动卡片：Running / Push up / Sit up，每个带小圆环进度 |
| **快捷语音按钮** | 中央大圆形麦克风按钮 | 橙红渐变底，白色闪电图标，带外圈呼吸动画 |
| **快捷指令条** | 横向 Pill 按钮组 | "Start workout" / "Log water" / "How did I sleep?" |
| **输入区** | 底部固定输入条 | 圆角白底输入框，左侧 placeholder "Type something..."，右侧麦克风图标 |

### 4.3 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 用户历史问题 | text | 不可点击，纯展示 | — |
| AI 回复气泡 | text | 长按可复制 | — |
| Running 卡片 | card | 查看跑步详情 | 活动详情页 |
| Push up 卡片 | card | 查看俯卧撑详情 | 活动详情页 |
| Sit up 卡片 | card | 查看仰卧起坐详情 | 活动详情页 |
| 中央语音按钮 | button | 按住说话/点击触发语音输入 | 语音录制态 |
| Start workout | chip-button | 快捷指令：开始训练 | 训练执行页 |
| Log water | chip-button | 快捷指令：记录饮水 | 饮水记录弹窗 |
| How did I sleep? | chip-button | 快捷指令：查看睡眠 | 睡眠数据页 |
| 输入框 | input | 聚焦后键盘弹出 | — |
| 发送/麦克风 | icon | 空内容时显示麦克风，有内容时变发送 | — |

### 4.4 状态与异常态

- **语音录制中**：中央按钮外圈扩大动画，波形可视化，底部显示 "Listening..."
- **AI 思考中**：左侧显示跳动点（typing indicator）
- **发送失败**：气泡标红，显示重试图标
- **无网络**：顶部显示弱网提示条 "Offline mode — responses may be delayed"

## 五、与现有小程序的映射与重构建议

### 5.1 优先级页面（按视觉稿直接重构）

| 视觉稿页面 | 建议合并/映射的现有页面 | 重构要点 |
|-----------|------------------------|----------|
| **Dashboard** | `今日训练` + `个人中心` | 把「今日训练」升级为一屏概览，顶部放激励文案，中部放训练完成进度与快捷入口，底部放 Daily Summary（训练数据） |
| **Progress** | `训练记录` + `当前计划` | 将日历视图替换为圆环+图表组合，Daily/Weekly/Monthly 切换训练统计数据 |
| **AI Assistant** | `消息中心`（与教练聊天） | 升级为对话式 UI，支持快捷指令气泡、AI 生成计划结果卡片化展示 |

### 5.2 组件化建议（提前封装复用）

1. **Card 容器**：`WhiteRoundedCard`（白底、24rpx 圆角、32rpx padding）
2. **Segmented Control**：`CapsuleTab`（胶囊分段器，选中白底）
3. **Circular Icon Button**：`IconCircle`（浅灰圆底 + 图标 + 下方标签）
4. **Progress Ring**：`RingChart`（SVG 圆环，支持多段颜色）
5. **Voice Button**：`PulseVoiceButton`（中央大圆按钮 + 呼吸动画）
6. **Bottom Nav**：`FloatingCapsuleNav`（悬浮胶囊，4 图标）

### 5.3 技术实现注意点

- **背景统一**：所有页面统一使用 `#F2F2F2` 背景，取消默认白色页面底
- **底部导航改造**：从小程序原生 `tabBar` 改为自定义组件 `FloatingCapsuleNav`，以获得视觉一致性
- **圆角规范**：所有卡片统一 `border-radius: 24rpx`，按钮统一 `16rpx–24rpx`
- **数据图表**：建议使用 `echarts-for-weixin` 或 `f2` 实现圆环图与迷你柱状图/折线图
- **动画**：卡片入场采用 `fade-up`（透明度 + 位移），语音按钮采用 `scale-pulse`
