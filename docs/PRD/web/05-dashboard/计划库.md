# 计划库

- **路由**：`/dashboard/plan-lib`
- **所属模块**：Web / 教练工作台
- **功能概述**：教练训练计划模板的列表管理，支持搜索、分页、复制、删除和批量操作。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 新建按钮 | 按钮 |  | `/dashboard/plan-lib/create` |
| 搜索输入框 | 输入框 |  | `—` |
| 搜索按钮 | 按钮 |  | `—` |
| 模板卡片-编辑 | 按钮 |  | `/dashboard/plan-lib/edit/{id}` |
| 模板卡片-复制 | 按钮 |  | `—` |
| 模板卡片-删除 | 按钮 |  | `—` |
| 模板卡片-批量操作 | 按钮 |  | `—` |
| 分页器 | 分页组件 |  | `—` |
| 确认删除弹窗-确认/取消 | 确认对话框 |  | `—` |
| 批量操作弹窗 | 对话框 |  | `—` |

## 页面状态与异常态

- loading: Skeleton 骨架屏
- empty: 未找到匹配项空状态
- error: Toast 加载/搜索/删除失败
