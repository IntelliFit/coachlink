# 学员训练计划

- **路由**：`/dashboard/students/plan/[id]`
- **所属模块**：Web / 教练工作台
- **功能概述**：为单个学员定制/编辑训练计划实例，支持模板导入、AI修改、问卷编辑、1RM配置与执行反馈。
