# 我的档案

- **路由**：`/dashboard/my-profile`
- **所属模块**：Web / 教练工作台
- **功能概述**：学员视角的个人资料展示页（含基础信息、运动数据、教练观察等）。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 编辑资料按钮 | 按钮 | 打开编辑弹窗 | `—` |
| 去发现按钮 | 按钮 | 跳转到教练发现页 | `/coach/discovery` |
| 编辑资料弹窗-姓名输入框 | 输入框 | 编辑姓名 | `—` |
| 编辑资料弹窗-年龄输入框 | 数字输入框 | 编辑年龄 | `—` |
| 编辑资料弹窗-性别下拉框 | 下拉框 | 选择性别 | `—` |
| 编辑资料弹窗-身高输入框 | 数字输入框 | 编辑身高 | `—` |
| 编辑资料弹窗-体重输入框 | 数字输入框 | 编辑体重 | `—` |
| 编辑资料弹窗-生活作息输入框 | 输入框 | 编辑生活作息 | `—` |
| 编辑资料弹窗-取消按钮 | 按钮 | 关闭弹窗 | `—` |
| 编辑资料弹窗-保存按钮 | 按钮 |  | `—` |

## 页面状态与异常态

- loading: Skeleton 骨架屏
- error: Toast 提示加载/保存失败
