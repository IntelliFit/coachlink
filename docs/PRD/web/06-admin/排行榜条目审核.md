# 排行榜条目审核

- **路由**：`/admin/rankings/review/[id]`
- **所属模块**：Web / 管理后台
- **功能概述**：针对单个排行榜模板审核用户提交的排行榜成绩申请。

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|

| 通过审核 | 按钮 |  | `—` |

## 页面状态与异常态

- loading：页面整体显示 ProgressSpinner
- error：加载失败
- empty：所有申请已处理完毕
- permissionDenied：非管理员自动跳转首页
