# 教练支付设置

- **路由**：`/admin/payments/coach-settings`
- **所属模块**：Web / 管理后台
- **功能概述**：为每位教练单独配置支付模式及是否允许使用个人收款二维码。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 编辑设置 | 图标按钮 | 打开编辑 Dialog | `—` |
| 支付模式下拉框 | Dropdown | 选择教练专属支付模式 | `—` |
| 允许使用个人二维码 | InputSwitch开关 | 切换该教练是否允许上传和使用个人收款码 | `—` |
| 取消 | 按钮 | 关闭编辑 Dialog 不保存 | `—` |
| 保存 | 按钮 |  | `—` |
| 分页器/每页条数 | 分页组件 |  | `—` |

## 页面状态与异常态

- loading：页面整体显示 ProgressSpinner
- error：加载或保存失败
- empty：暂无教练数据
- permissionDenied：非管理员自动跳转首页
