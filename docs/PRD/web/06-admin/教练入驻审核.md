# 教练入驻审核

- **路由**：`/admin/coach-applications`
- **所属模块**：Web / 管理后台
- **功能概述**：管理员审核教练资质申请，支持批量批准、状态筛选、查看详情及通过/拒绝操作。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 刷新数据 | 按钮 | 重新加载教练申请列表 | `—` |
| 批量批准 | 按钮 | 对选中的多个申请执行批量通过 | `—` |
| 多选复选框 | 表格选择器 | 勾选/取消勾选单行或全选 | `—` |
| 状态筛选 | MultiSelect下拉筛选 | 按申请状态过滤列表 | `—` |
| 分页器 | 分页组件 | 切换页码和每页条数 | `—` |
| 查看详情 | 图标按钮 | 打开弹窗查看申请详细信息 | `—` |
| 批准 | 图标按钮 | 直接将 pending 状态的申请标记为 approved | `—` |
| 拒绝 | 图标按钮 | 打开弹窗输入拒绝原因 | `—` |
| ReviewNotesDialog-提交 | 弹窗按钮 | 提交拒绝原因并将申请标记为 rejected | `—` |
| ReviewNotesDialog-关闭 | 弹窗按钮 | 关闭拒绝备注弹窗 | `—` |

## 页面状态与异常态

- loading：表格行显示 Skeleton
- error：加载失败
- empty：暂无待处理的申请
- permissionDenied：非管理员自动跳转首页
