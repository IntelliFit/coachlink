# 排行榜管理

- **路由**：`/admin/rankings`
- **所属模块**：Web / 管理后台
- **功能概述**：管理系统排行榜模板，支持创建新排行榜及查看/编辑现有排行榜卡片。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 创建新排行榜 | 按钮 |  | `—` |
| LeaderboardCard操作 | 卡片组件 |  | `—` |
| CreateLeaderboardForm-提交 | 弹窗表单按钮 |  | `—` |
| CreateLeaderboardForm-取消 | 弹窗表单按钮 |  | `—` |
| ConfirmDialog-确认 | 确认弹窗按钮 |  | `—` |
| ConfirmDialog-取消 | 确认弹窗按钮 |  | `—` |

## 页面状态与异常态

- loading：显示自定义 Skeleton
- error：加载失败
- empty：暂无数据，点击上方按钮创建
- permissionDenied：非管理员自动跳转首页
