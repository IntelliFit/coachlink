# 提现管理

- **路由**：`/admin/withdrawals`
- **所属模块**：Web / 管理后台
- **功能概述**：管理教练提现申请，查看提现记录、筛选状态并对pending订单执行手动到账确认。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 全部 | 筛选按钮 |  | `—` |
| 待处理 | 筛选按钮 |  | `—` |
| 已到账 | 筛选按钮 |  | `—` |
| 刷新 | 按钮 |  | `—` |
| 分页器 | 分页组件 |  | `—` |
| 确认到账 | 按钮 |  | `—` |
| 转账订单号 | 文本输入框 |  | `—` |
| 确认 | 弹窗按钮 |  | `—` |
| 取消 | 弹窗按钮 |  | `—` |

## 页面状态与异常态

- loading：表格行显示 Skeleton
- error：加载失败
- empty：DataTable 默认空状态
- permissionDenied：非管理员自动跳转首页
