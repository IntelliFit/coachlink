# 用户行为分析

- **路由**：`/admin/analytics`
- **所属模块**：Web / 管理后台
- **功能概述**：多维度的平台数据看板，包含 Dashboard、功能使用、留存、发布记录和流量日志。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 总览 | Tab按钮 | 切换至 DashboardView | `—` |
| 功能分析 | Tab按钮 | 切换至 FeatureUsageView | `—` |
| 留存分析 | Tab按钮 | 切换至 RetentionView | `—` |
| 功能发布 | Tab按钮 | 切换至 ReleasesView | `—` |
| 流量日志 | Tab按钮 | 切换至 TraceView | `—` |
| 7天 | 范围切换按钮 | 设置功能分析时间范围为7天 | `—` |
| 30天 | 范围切换按钮 | 设置功能分析时间范围为30天 | `—` |
| 90天 | 范围切换按钮 | 设置功能分析时间范围为90天 | `—` |
| + 记录新功能发布 | 按钮 | 显示/隐藏新增发布记录表单 | `—` |
| 功能名称 | 文本输入框 | 输入新功能名称 | `—` |
| 发布日期 | 日期选择器 | 选择发布日期 | `—` |
| 取消 | 按钮 | 关闭发布记录表单 | `—` |
| 保存 | 按钮 | 提交表单创建新发布记录 | `—` |
| 开始日期 | 日期输入框 | 修改流量日志查询起始日期 | `—` |
| 结束日期 | 日期输入框 | 修改流量日志查询结束日期 | `—` |
| 包含开发环境 | 复选框 | 切换是否包含开发环境数据 | `—` |
| 包含管理员 | 复选框 | 切换是否包含管理员操作数据 | `—` |
| 刷新 | 按钮 | 重新请求流量日志数据 | `—` |

## 页面状态与异常态

- loading：显示加载中
- error：数据加载失败
- empty：暂无数据
