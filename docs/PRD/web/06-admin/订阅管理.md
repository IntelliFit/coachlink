# 订阅管理

- **路由**：`/admin/subscriptions`
- **所属模块**：Web / 管理后台
- **功能概述**：查看学员与教练之间的订阅关系，支持多维度筛选和分页。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 刷新 | 按钮 |  | `—` |
| 支付确认已废弃 | 按钮 |  | `—` |
| 学员筛选 | 自定义筛选组件 |  | `—` |
| 教练筛选 | 自定义筛选组件 |  | `—` |
| 订阅等级筛选 | 自定义筛选组件 |  | `—` |
| 状态筛选 | 自定义筛选组件 |  | `—` |
| 分页器 | 分页组件 |  | `—` |

## 页面状态与异常态

- loading：表格行显示 Skeleton
- error：加载失败
- empty：DataTable 默认空状态
- permissionDenied：非管理员自动跳转首页
