# 账单管理

- **路由**：`/admin/payments`
- **所属模块**：Web / 管理后台
- **功能概述**：查看并管理平台所有支付订单，支持状态/类型筛选和对已支付订单发起退款。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 订阅管理 | 链接按钮 | 跳转至订阅管理页面 | `/admin/subscriptions` |
| 刷新 | 按钮 | 重新加载账单列表 | `—` |
| 状态筛选 | Dropdown下拉框 | 按订单状态过滤 | `—` |
| 类型筛选 | Dropdown下拉框 | 按订单类型过滤 | `—` |
| 分页器 | 分页组件 | 切换页码和每页条数 | `—` |
| 退款 | 按钮 | 对已支付订单弹出 confirm 确认后调用退款接口 | `—` |

## 页面状态与异常态

- loading：表格行显示 Skeleton
- error：加载失败
- empty：无订单
- permissionDenied：非管理员自动跳转首页
