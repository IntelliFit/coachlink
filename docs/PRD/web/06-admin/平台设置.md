# 平台设置

- **路由**：`/admin/settings`
- **所属模块**：Web / 管理后台
- **功能概述**：配置平台级参数，当前仅支持全局默认支付模式设置。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 全局默认支付模式 | Dropdown下拉框 |  | `—` |
| 管理教练个人支付设置 | 按钮 |  | `/admin/payments/coach-settings` |
| 保存设置 | 按钮 |  | `—` |

## 页面状态与异常态

- loading：页面整体显示 ProgressSpinner
- error：加载或保存失败
- empty：无
- permissionDenied：非管理员自动跳转首页
