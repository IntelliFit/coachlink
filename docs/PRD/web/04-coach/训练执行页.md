# 训练执行页

- **路由**：`/coach/plans/dashboard/[id]/training-execution`
- **所属模块**：Web / 教练端
- **功能概述**：独立的训练日执行页面，学员在此录入实际训练数据。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| TrainingExecution 内嵌交互 | 嵌套组件 |  | `—` |
| 返回 | 组件内回调 |  | `/today-training` |
| 完成 | 组件内回调 |  | `/coach/plans/dashboard/{id}` |
