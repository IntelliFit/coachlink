# CoachLink 小程序页面合同审视（2026-05-13）

## 当前判断

前一轮已经把一级入口收成 `今日 / 路径 / 教练 / 我的`，方向是对的，但页面内部仍然混乱。问题不是入口名称，而是每个页面仍然同时承担太多任务：

- `今日` 同时在讲当前路径、本周任务、今日训练、日历、学习、教练、保底训练。
- `路径` 同时在做诊断、周计划、7 天计划、学习推荐、教练推荐、能力节点、工具入口。
- `学习路径` 首屏仍然像知识库，搜索、书籍笔记、人体地图都在抢注意力。
- `教练支持` 已经改成问题导向，但动作、资讯、服务商品仍默认露出。
- `首页` 对已登录用户仍像一个功能入口页，和 `今日` 重复。

对小白来说，正确的体验不是“知道平台有很多东西”，而是“我现在该点哪里、做什么、做完去哪”。

## 页面合同

| 页面 | 它应该回答的问题 | 当前主要问题 | 目标交互 |
| --- | --- | --- | --- |
| 首页 `/pages/index/index` | 未登录用户：CoachLink 能帮我怎么安全开始？ | 已登录后仍展示四个入口，和底部导航重复 | 已登录自动进入 `今日`；未登录只保留“生成起点路径/登录开始/看教练支持”等少量入口 |
| 今日 `/training/today-training` | 我现在马上要做什么？ | 路径说明和本周任务压在今日主行动前面 | 首屏先给唯一主行动；路径解释、学习、教练支持都放在主行动之后 |
| 路径 `/content/path/index` | 我当前处在哪条路，本周只做哪几件事？ | 诊断、7 天计划、能力节点、工具入口混在一页 | 默认展示当前路径 + 本周 3 件事 + 去今日；诊断改成可展开调整；能力节点/工具不再默认露出 |
| 训练执行 `/training/training-execution` | 当前这一组/这一项怎么完成？ | 已经有卡片式执行，但重量、次数、RPE、视频、PR、新增组等对小白仍偏重 | 后续应区分“简洁记录”和“高级记录”，默认只暴露完成本组所需字段 |
| 学习 `/content/knowledge` | 我当前卡点应该先学哪 1-3 个内容？ | 首屏仍是搜索 + 书籍 + 人体地图，像资料库 | 先放卡点推荐；搜索保留；书籍和人体地图折叠为资料库 |
| 教练 `/discovery/index` | 我什么时候需要人带，应该找哪类人？ | 教练推荐之后直接露出动作、资讯、商品，仍像发现页 | 默认只展示问题分类和教练列表；更多资源手动展开 |
| 我的 `/me/profile/index` | 我的记录、设置、历史、工具在哪里？ | 基本方向正确，但高级工具和长尾链接仍较多 | 作为仓库页保留，后续可把高级工具进一步折叠 |

## 本轮执行边界

本轮不删除旧功能，不改数据库，不重写训练执行核心逻辑。先做入口层和首屏秩序：

1. 首页：已登录用户不再停留在首页，直接进入今日。
2. 今日：主行动提前，移除本周任务重复展示。
3. 路径：把诊断折叠，隐藏能力节点和工具入口，保留“当前路径 / 本周 3 件事 / 去今日 / 今天只学这些 / 什么时候找教练”。
4. 学习：增加卡点推荐，书籍和人体地图放入可展开资料库。
5. 教练：动作、资讯、服务商品默认折叠到“更多资源”。

后续还需要单独处理训练执行页的“新手简洁记录模式”，但这涉及执行数据录入体验，建议作为下一轮重点。
