# 教练主页

- **路由**：`/discovery/coach-profile`
- **所属模块**：小程序 / 发现
- **功能概述**：教练详情页，展示简介、定价、教学内容、评价，支持订阅与智能生成计划。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| Tab切换 | tab | 切换：关于教练 / 订阅价格 / 教学内容 / 学员评价 | `—` |
| 待支付订阅横幅 | banner | 点击继续完成购买支付 | `/me/payment/webview/index` |
| 立即订阅/查看价格 | button | 滚动定位到订阅价格区并切换Tab | #tab-pricing-anchor |
| 续费 | button | 已订阅用户进入续费模式选择套餐 | `—` |
| 查看订阅进度 | button | 订阅处理中时的状态提示 | `—` |
| 智能生成计划 | button | 跳转AI生成计划页（需已订阅） | `/discovery/generate-plan` |
| 填写/更新训练需求问卷 | button | 打开问卷弹窗（需已订阅） | `—` |
| 套餐选择 | card | 选择时长套餐进行购买或续费 | `/me/payment/webview/index` |
| 教学内容项 | card | 点击跳转内容详情 | `/content/content-detail` |
| 问卷弹窗 | modal | 加载并提交训练需求问卷 | `—` |
