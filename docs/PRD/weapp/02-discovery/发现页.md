# 发现页

- **路由**：`/discovery/index`
- **所属模块**：小程序 / 发现
- **功能概述**：一站式发现教练、服务商品、热门动作与健身资讯。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 搜索输入框 | input | 输入姓名或专长关键字，回车触发搜索 | `—` |
| 专长筛选下拉 | button | 调起微信 ActionSheet 选择专长过滤 | `—` |
| 搜索按钮 | button | 触发教练列表搜索 | `—` |
| 服务商品-查看更多 | link | 跳转服务市场 | `/discovery/market` |
| 商品卡片-购买 | button | 校验登录后跳转支付页 | `/me/payment/webview/index` |
| 商品卡片-加购 | button | 校验登录后加入购物车 | `—` |
| 热门动作-查看动作库 | link | 跳转动作库列表 | `/training/actions` |
| 动作卡片-详情 | button | 跳转动作详情 | `/training/action-detail/index` |
| 动作卡片-加入 | button | 将公开动作加入我的动作库 | `—` |
| 动作卡片主体 | card | 点击跳转动作详情 | `/training/action-detail/index` |
| 健身资讯-查看更多 | link | 跳转知识库首页 | `/content/knowledge` |
| 文章卡片 | card | 点击跳转内容详情 | `/content/content-detail` |
| 教练卡片 | card | 点击跳转教练主页 | `/discovery/coach-profile` |
| 加载更多 | button | 加载下一页教练列表 | `—` |

## 页面状态与异常态

- {'stateName': '加载中', 'description': '教练列表、商品、动作、文章加载时显示骨架屏'}
- {'stateName': '空状态', 'description': '无教练/无商品/无动作/无文章时显示空提示'}
- {'stateName': '专注模式', 'description': '仅展示专属邀请教练，隐藏搜索与筛选'}
- {'stateName': '触底加载', 'description': '滚动到底部自动加载更多教练'}
