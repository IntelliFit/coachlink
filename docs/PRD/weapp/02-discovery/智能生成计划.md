# 智能生成计划

- **路由**：`/discovery/generate-plan`
- **所属模块**：小程序 / 发现
- **功能概述**：为订阅教练的学员选择训练域并填写评估表单以AI生成计划。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 训练域选择卡片 | card | 单选：负重引体 / 负重臂屈伸 / 引体+臂屈伸组合 | `—` |
| 返回按钮 | button | 返回上一页 | `—` |
| 下一步按钮 | button | 确认域选择后展示评估表单 | `—` |
| 评估表单-返回 | button | 返回域选择 | `—` |
| 评估表单-提交 | button | 提交评估后跳转等待页 | `/discovery/generate-plan/waiting` |

## 页面状态与异常态

- {'stateName': '未登录重定向', 'description': '未登录自动跳登录页'}
- {'stateName': '缺少教练ID', 'description': '无 coachId 时重定向到发现页'}
- {'stateName': '加载中', 'description': '等待 coachId 校验时显示加载中'}
