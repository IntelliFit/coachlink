# 排行榜详情

- **路由**：`/discovery/ranking/detail`
- **所属模块**：小程序 / 发现
- **功能概述**：展示单个排行榜的规则、排名榜单及成绩提交入口。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 立即挑战 | button | 打开成绩提交弹窗 | `—` |
| 成绩提交弹窗 | modal | 填写成绩表单并提交，成功后刷新榜单 | `—` |
| 返回 | link | 排行榜不存在时返回上一页 | `—` |
