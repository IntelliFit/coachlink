# 计划生成等待页

- **路由**：`/discovery/generate-plan/waiting`
- **所属模块**：小程序 / 发现
- **功能概述**：展示AI计划生成进度与结果，支持重试与查看计划列表。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 查看全部计划 | button | 跳转计划历史 | `/me/plan-history/index` |
| 重新生成 | button | 清除错误并重试快速生成 | `—` |
| 智能快速生成 | button | 手动触发计划生成请求 | `—` |
| 返回按钮 | button | 返回上一页 | `—` |

## 页面状态与异常态

- {'stateName': '轮询中', 'description': '显示进度条与生成中提示'}
- {'stateName': '成功', 'description': '显示成功图标并自动跳转计划历史'}
- {'stateName': '失败', 'description': '显示错误信息，提供重新生成和查看计划入口'}
- {'stateName': '异步任务已提交', 'description': '后端返回 taskId，提示稍后去计划列表查看'}
