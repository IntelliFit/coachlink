# 服务市场

- **路由**：`/discovery/market`
- **所属模块**：小程序 / 发现
- **功能概述**：按教练展示所有可购买的订阅服务商品，支持筛选与加购。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 搜索输入框 | input | 实时过滤商品（教练、商品、专长关键词） | `—` |
| 套餐等级筛选 | tab | 切换全部/基础/专业/全能标签过滤 | `—` |
| 购物车按钮 | button | 跳转购物车 | `/me/cart/index` |
| 教练信息区 | card | 点击跳转教练主页定价Tab | `/discovery/coach-profile` |
| 购买按钮 | button | 校验登录后跳转支付页 | `/me/payment/webview/index` |
| 加购按钮 | button | 加入购物车并弹出去购物车/继续选购提示 | `—` |
