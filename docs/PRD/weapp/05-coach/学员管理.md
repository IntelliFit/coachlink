# 学员管理

- **路由**：`/coach/students`
- **所属模块**：小程序 / 教练端
- **功能概述**：教练查看所有订阅学员列表，支持搜索、排序、批量AI生成计划、支付确认。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 搜索框 | Input | 输入学员昵称/手机号搜索 | `—` |
| 清除搜索 | 按钮 | 清空搜索关键词 | `—` |
| 排序按钮 | 按钮 | 弹出ActionSheet选择排序方式 | `—` |
| 批量快速生成按钮 | 按钮 | 为未配置计划学员批量AI生成计划 | `—` |
| 待支付确认按钮 | 按钮 | 打开待支付确认弹窗 | `—` |
| 学员卡片-展开/收起 | 卡片 | 点击展开显示学员详情操作 | `—` |
| 学员卡片-档案按钮 | 按钮 | 跳转学员详情 | `/coach/students/detail` |
| 学员卡片-查看计划/创建计划 | 按钮 | 跳转学员计划页 | `/coach/students/plan` |
| 学员卡片-AI生成 | 按钮 | 为单个学员AI生成计划 | `—` |
| 学员卡片-联系学员 | 按钮 | 打开聊天会话 | `/me/messages/chat/index` |
| 未计划学员复选框 | Checkbox | 勾选/取消参与批量AI生成 | `—` |
| 全选本页/清空本页 | 链接 | 批量选择当前页无计划学员 | `—` |
| 上一页 | 按钮 | 分页切换 | `—` |
| 下一页 | 按钮 | 分页切换 | `—` |
| 待支付弹窗-待确认Tab | Tab | 切换Tab | `—` |
| 待支付弹窗-历史Tab | Tab | 切换Tab | `—` |
| 手动待确认-全选/取消全选 | 链接 | 批量选择手动待确认项 | `—` |
| 手动待确认-勾选框 | Checkbox | 选择单项确认 | `—` |
| 确认支付按钮(单项) | 按钮 | 确认学员已支付 | `—` |
| 忽略通知按钮(系统) | 按钮 | 忽略系统支付通知 | `—` |
| 底部批量确认支付 | 按钮 | 批量确认选中的手动支付 | `—` |
| 支付凭证图片 | Image | 点击预览支付凭证大图 | `—` |
| 关闭弹窗 | 按钮 | 关闭待支付确认弹窗 | `—` |

## 页面状态与异常态

- loading
- empty
- paymentDialogOpen
- unauthorized
