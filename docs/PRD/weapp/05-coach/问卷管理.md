# 问卷管理

- **路由**：`/coach/questionnaire`
- **所属模块**：小程序 / 教练端
- **功能概述**：管理线上版本和草稿版本的学员问卷，支持发布和设置默认。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 编辑草稿/从线上复制草稿/新建问卷按钮 | 按钮 |  | `/coach/questionnaire/edit` |
| 线上版本卡片-查看线上配置 | 按钮 |  | `/coach/questionnaire/edit?mode=online` |
| 线上版本卡片-设为默认 | 按钮 |  | `—` |
| 草稿版本卡片-继续编辑草稿 | 按钮 |  | `/coach/questionnaire/edit?mode=draft` |
| 草稿版本卡片-发布为线上 | 按钮 |  | `—` |
| 草稿空状态-从线上复制草稿 | 按钮 |  | `—` |
| 草稿空状态-直接新建问卷 | 按钮 |  | `/coach/questionnaire/edit?mode=draft` |

## 页面状态与异常态

- loading
- noOnline
- noDraft
- unauthorized
