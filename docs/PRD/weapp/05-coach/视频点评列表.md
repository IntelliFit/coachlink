# 视频点评列表

- **路由**：`/coach/videos`
- **所属模块**：小程序 / 教练端
- **功能概述**：查看学员上传的训练视频，按待点评/已点评筛选。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 待点评Tab | Tab切换 | 切换筛选条件 | `—` |
| 已点评Tab | Tab切换 | 切换筛选条件 | `—` |
| 视频卡片-去点评 | 按钮 | 点击进入点评页 | `/coach/videos/review` |
| 视频卡片-查看点评 | 按钮 | 点击查看已点评详情 | `/coach/videos/review` |

## 页面状态与异常态

- loading
- empty
- unauthorized
