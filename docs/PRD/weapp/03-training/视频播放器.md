# 视频播放器

- **路由**：`/common/common/video-player`
- **所属模块**：小程序 / 训练
- **功能概述**：通用 PR 视频播放页，支持小程序内播放与失败后的链接复制 fallback。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 返回 | 按钮 |  | `—` |
| 复制链接在浏览器打开 | 按钮 |  | `—` |
| 点此复制链接到浏览器打开 | 文字按钮 |  | `—` |
| Video 组件 | 视频播放 |  | `—` |

## 页面状态与异常态

- 视频地址无效空状态
- 视频加载失败 fallback 状态（提示复制到浏览器）
