# 单杠位置

- **路由**：`/streetlifting/index/locations`
- **所属模块**：小程序 / 训练
- **功能概述**：单杠训练点社区列表，支持搜索筛选、图片上传、地图位置选择、编辑与导航。

## 页面状态与异常态

- 列表加载中/加载更多中
- 定位中/定位失败
- 图片上传中
- 总览分析加载中
- 贡献榜加载中
- 列表为空（引导成为第一个分享者）
- 表单校验失败（名称必填）
