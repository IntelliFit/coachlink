# 今日训练

- **路由**：`/training/today-training`
- **所属模块**：小程序 / 训练
- **功能概述**：展示学员今日训练计划的核心页面，支持教练/自建计划切换、日历选天、补练/跳过、轻任务管理、打卡分享与训练入口。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 计划切换 Tab | tab切换 | 切换 coach/self 计划模式 | `—` |
| 教练订阅 Tab | tab切换 | 多教练时横向滚动切换当前订阅 | `—` |
| 移除自建计划 | 按钮 | 弹出确认后删除自建计划实例 | `—` |
| 说明卡片 | 卡片点击 | 打开「为什么要确认完成」说明弹窗 | `—` |
| 收起返回确认 Banner | 文字按钮 | 隐藏训练完成返回提示 | `—` |
| 补练按钮 | 按钮 | 跳转到对应天的训练执行页 | `/training/training-execution` |
| 跳过按钮 | 按钮 | 弹出确认后跳过该训练日 | `—` |
| 去续费链接 | 文字按钮 | 跳转到教练主页续费 | `/discovery/coach-profile` |
| 日历面板 | 日历/日期选择 | 点击某天切换选中并展示当天安排 | `—` |
| 即兴锻炼入口 | 按钮 | 跳转即兴锻炼配置页 | `/training/impromptu-training` |
| 整日打卡图 | 按钮 | 打开生成日打卡分享图弹窗 | `—` |
| 今日训练卡片 | 组件交互 | 打开轻任务/添加轻任务/删除轻任务 | `—` |
| 轻任务 Sheet 弹窗 | 弹窗 | 填写并提交轻任务完成数据（饮食/有氧/习惯） | `—` |
| 轻动作选择器 | 弹窗 | 从动作库选择轻任务类型动作 | `—` |
| 轻任务配置弹窗 | 弹窗 | 输入时间、备注、饮食内容/有氧距离/习惯名称等并创建任务 | `—` |
| 日打卡分享弹窗 | 弹窗 | 展示分享图并支持小程序分享 | `—` |
| 计划完成弹窗 | 弹窗 | 展示完成祝贺，提供更新档案/生成下一计划/查看全部计划 | `/me/profile/detail/index` |
| 说明弹窗-去输入并校准 | 按钮 | 关闭弹窗并跳转训练执行页 | `/training/training-execution` |
| 空状态-即兴锻炼 | 按钮 | 跳转即兴锻炼页 | `/training/impromptu-training` |
| 空状态-联系教练 | 按钮 | 跳转消息页 | `/me/messages/index` |
| 空状态-AI长期计划/我的计划库 | 按钮 | 跳转计划库 | `/me/plan-lib/index` |
| 空状态-浏览教练 | 按钮 | 跳转发现教练 | `/discovery/index` |

## 页面状态与异常态

- loading 骨架屏状态
- 无计划空状态（等待教练制定 / 未订阅）
- 教练计划宽限期锁定状态
- 多教练切换时的「待制定/待续费」标记
- missingDays 补练提示条
- 今日已完成提示条
- 返回确认提示条（banner）
- 轻任务配置/选择/打卡弹窗显隐状态
- 计划完成庆祝弹窗状态
