# 即兴锻炼

- **路由**：`/training/impromptu-training`
- **所属模块**：小程序 / 训练
- **功能概述**：学员自定义即兴训练，选择动作与组次参数后创建并进入标准执行页。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 返回训练 | 按钮 | 返回今日训练页 | `/training/today-training` |
| AI 长期计划 | 按钮 | 跳转 AI 计划创建页 | `/me/plan-lib/create/index` |
| 添加项目 | 按钮 | 新增一条训练项 | `—` |
| 删除项目 | 按钮 | 移除对应训练项 | `—` |
| 选择动作 | 触发器/弹窗 | 打开动作选择弹窗 | `—` |
| 动作选择弹窗 | 弹窗 | 从力量动作库中选择具体动作 | `—` |
| 组数输入 | 输入框 | 数字输入 | `—` |
| 次数输入 | 输入框 | 数字输入 | `—` |
| 休息输入 | 输入框 | 秒数数字输入 | `—` |
| 重量输入 | 输入框 | 可选，数字输入 | `—` |
| 开始训练 | 主按钮 | 校验后创建即兴训练并跳转执行页 | `/training/training-execution` |

## 页面状态与异常态

- 未登录跳转登录页
- 动作库加载中
- 无训练项空提示
- 开始训练 loading 状态
