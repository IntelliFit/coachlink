# 动作编辑

- **路由**：`/training/action-edit`
- **所属模块**：小程序 / 训练
- **功能概述**：学员添加或编辑自定义动作到个人动作库。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 动作名称 | 输入框 | 必填，最大100字符 | `—` |
| 动作描述 | 文本域 | 选填，最大500字符 | `—` |
| 训练部位 | 输入框 | 选填，多个用逗号分隔 | `—` |
| 动作类型选项 | 单选标签 | 选择 STRENGTH/DIET/CARDIO/HABIT | `—` |
| 演示视频链接 | 输入框 | 选填 | `—` |
| 添加动作/保存 | 提交按钮 | 调用 addAction 后返回 | `—` |

## 页面状态与异常态

- 提交中 disabled 状态
- 表单校验失败提示（名称必填）
