# 训练执行

- **路由**：`/training/training-execution`
- **所属模块**：小程序 / 训练
- **功能概述**：训练当日执行与记录页面，支持逐组录入重量/次数/RPE、视频上传、休息计时、添加额外动作/组、一键完成及训练反馈。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 返回 | 按钮 | 返回上一页 | `—` |
| 联系教练 | 按钮 | 打开与教练的聊天会话 | `/me/messages/chat/index` |
| 跳过今日 | 文字按钮 | 弹出确认后跳过当天训练 | `—` |
| 动作卡片头部 | 卡片点击 | 展开/折叠动作，定位到该动作第一待完成组 | `—` |
| 删除额外动作 | 文字按钮 | 删除学员自行添加的动作（student_extra） | `—` |
| 组行点击 | 列表项点击 | 待完成组设为当前组；已完成组展开详情 | `—` |
| 删除额外组 | 文字按钮 | 删除学员自行添加的组 | `—` |
| 重量输入 | 输入框 | 录入当前组实际重量（kg） | `—` |
| 次数输入 | 输入框 | 录入当前组实际次数 | `—` |
| RPE输入 | 输入框 | 录入主观用力程度 1-10 | `—` |
| 备注输入 | 输入框 | 记录本组训练感受或问题 | `—` |
| 选视频 | 按钮 | 调用 chooseVideo 并上传 | `—` |
| 贴链接 | 按钮 | 弹出可编辑 Modal 粘贴视频链接 | `—` |
| 标记PR | toggle/标签 | 切换当前组是否标记为个人纪录 | `—` |
| 完成本组 | 主按钮 | 提交当前组数据并自动推进到下一组/动作 | `—` |
| 编辑本组 | 按钮 | 允许修改已完成组的数据 | `—` |
| 取消编辑 | 按钮 | 退出编辑状态并恢复原始值 | `—` |
| + 新增一组 | 按钮 | 为当前动作添加额外组 | `—` |
| 非力量项目完成打卡 | 按钮 | 提交饮食/有氧/习惯类项目的完成数据 | `—` |
| + 添加动作 | 按钮 | 打开动作选择弹层 | `—` |
| 动作选择弹层 | 弹窗/搜索 | 搜索并选择动作库中的 STRENGTH 动作添加 | `—` |
| 完成训练 | 主按钮 | 弹出确认后结束本次训练 | `—` |
| 一键完成训练 | 主按钮 | 自动补齐未完成组后结束训练 | `—` |
| 返回今日安排继续轻任务 | 主按钮 | 当轻任务未完成时返回今日训练页 | `/training/today-training` |
| 休息计时弹窗 | 弹窗 | 展示组间倒计时，支持 +30秒 / 跳过休息 | `—` |
| 训练反馈弹窗 | 弹窗 | 选择难度感受并填写文字反馈发送给教练 | `—` |

## 页面状态与异常态

- loading 加载中
- 加载失败重试状态
- 只读模式（readOnly）禁止修改
- 即兴训练模式（impromptu）
- 组间休息倒计时覆盖层
- 所有组完成后的完成提示
- 轻任务未完成拦截提示
- 训练反馈弹窗（可选跳过）
- 视频上传中状态
