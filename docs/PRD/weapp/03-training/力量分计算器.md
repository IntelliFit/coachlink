# 力量分计算器

- **路由**：`/streetlifting/index/calculator`
- **所属模块**：小程序 / 训练
- **功能概述**：基于网页端一致逻辑的力量分计算器，支持正向计算与反向推导做组重量/次数。

## 页面状态与异常态

- 公式加载中
- 公式加载失败提示
- 输入校验错误提示（体重/次数/质量必填等）
- 结果展示区域（含力量分等级、RM 对照表）
