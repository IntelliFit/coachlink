# 社区数据

- **路由**：`/streetlifting/index/data`
- **所属模块**：小程序 / 训练
- **功能概述**：街健社区数据列表，支持筛选排序、搜索、提交个人数据与认领匿名数据。

## 页面状态与异常态

- 列表加载中
- 筛选结果为空
- 未登录提示
- 个人档案缺失性别/体重提示
- 提交中 loading
- 认领中 loading
