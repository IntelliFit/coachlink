# 个人资料详情

- **路由**：`/me/profile/detail/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：展示学员详细档案，包括个人信息、运动卡片、教练备注、力量进步、进步足迹、问卷、训练视频。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 编辑资料 | 按钮 | 跳转编辑资料页 | `/me/profile/edit/index` |
| 进步足迹Tab | tab | 显示进步时间线 | `—` |
| 需求问卷Tab | tab | 显示训练需求问卷 | `—` |
| 训练视频Tab | tab | 显示训练视频集合 | `—` |
| 编辑问卷 | 按钮 | 打开问卷表单弹窗 | `—` |
| 提交问卷 | 弹窗按钮 | 保存问卷答案 | `—` |
| 关闭问卷弹窗 | 弹窗按钮 | 隐藏问卷表单 | `—` |

## 页面状态与异常态

- {'state': '未登录', 'description': '重定向到登录页'}
- {'state': '初始加载', 'description': '显示骨架屏'}
- {'state': '加载错误', 'description': '显示错误文本'}
- {'state': '无问卷数据', 'description': '显示暂无训练需求问卷数据'}
- {'state': '无视频', 'description': 'VideoCollectionSection内部处理空状态'}
