# 动作库

- **路由**：`/me/action-lib/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：管理我的动作库与浏览公共动作库，支持搜索、筛选、批量操作、贡献、点赞、纠错。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| Tab切换 | tab | 切换我的动作库/公共动作库 | `—` |
| 从教练添加 | 按钮 | 跳转从教练导入动作 | `/training/copy-from-coach` |
| 新建动作 | 按钮 | 跳转新建动作页 | `/me/action-lib/edit/index` |
| 快捷筛选标签 | 筛选芯片 | 按全部/新手推荐/减脂有氧/胸肩手臂/腰背核心筛选公共动作 | `—` |
| 仅看有演示 | 开关芯片 | 过滤出有视频演示的公共动作 | `—` |
| 搜索框 | 输入框 | 输入关键词搜索动作 | `—` |
| 搜索按钮 | 按钮 | 提交搜索 | `—` |
| 清除搜索 | 按钮 | 清空搜索词 | `—` |
| 我的动作卡片 | 卡片点击 | 进入编辑页 | `/me/action-lib/edit/index` |
| 我的动作长按 | 长按手势 | 进入批量选择模式 | `—` |
| 引用 | 菜单按钮 | 查看该动作被哪些计划引用 | `弹窗展示引用列表` |
| 合并 | 菜单按钮 | 合并到另一个动作并更新引用 | `ActionSheet + 确认弹窗` |
| 贡献 | 菜单按钮 | 将个人动作发布到公共动作库 | `确认弹窗` |
| 删除 | 菜单按钮 | 删除动作 | `确认弹窗后刷新列表` |
| 批量更新1RM | 按钮 | 弹出批量设置1RM弹窗 | `—` |
| 取消批量 | 按钮 | 退出批量模式 | `—` |
| 公共动作卡片 | 卡片点击 | 查看动作详情 | `/training/action-detail/index` |
| 点赞 | 按钮 | 对公共动作点赞/取消点赞 | `—` |
| 纠错 | 按钮 | 打开纠错建议弹窗 | `—` |
| 加入我的库 | 按钮 | 将公共动作加入个人动作库 | `—` |
| 纠错弹窗-提交建议 | 弹窗按钮 | 提交纠错内容 | `—` |
| 纠错弹窗-取消 | 弹窗按钮 | 关闭弹窗 | `—` |
| 下拉刷新 | 手势 | 刷新当前tab列表 | `—` |

## 页面状态与异常态

- {'state': '加载中', 'description': '显示骨架屏'}
- {'state': '我的动作为空', 'description': '显示空状态，提示新建或从教练/公共库添加'}
- {'state': '公共动作为空', 'description': '显示空状态，提示换关键词或关闭仅看有演示'}
- {'state': '批量模式', 'description': '显示复选框和批量操作栏'}
