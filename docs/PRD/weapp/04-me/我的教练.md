# 我的教练

- **路由**：`/me/my-coaches/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：展示已订阅教练列表，支持查看教练详情、续费、发起沟通。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 发现更多 | 按钮 | 跳转发现教练页 | `/discovery/index` |
| 教练卡片-详情 | 卡片内按钮 | 查看教练资料 | `/discovery/coach-profile` |
| 教练卡片-续费 | 卡片内按钮 | 跳转续费支付页 | `/me/payment/webview/index` |
| 教练卡片-沟通 | 卡片内按钮 | 打开与该教练的聊天 | `/me/messages/chat/index` |
| 空状态-发现教练 | 按钮 | 跳转发现页 | `/discovery/index` |
| 错误重试 | 按钮 | 重新加载列表 | `—` |
| 下拉刷新 | 手势 | 刷新教练列表 | `—` |

## 页面状态与异常态

- {'state': '加载中', 'description': '显示骨架屏'}
- {'state': '空列表', 'description': '显示暂无订阅教练及发现引导'}
- {'state': '加载失败', 'description': '显示错误文本和重试按钮'}
- {'state': '未登录', 'description': '显示请先登录'}
