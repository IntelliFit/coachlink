# 账户设置

- **路由**：`/me/settings/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：账户安全与偏好设置，支持修改密码和退出登录。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 修改密码 | 设置项点击 | 打开修改密码弹窗 | `—` |
| 原密码输入 | 密码输入框 | 输入原密码 | `—` |
| 新密码输入 | 密码输入框 | 输入新密码 | `—` |
| 确认新密码输入 | 密码输入框 | 再次输入新密码 | `—` |
| 取消 | 弹窗按钮 | 关闭弹窗 | `—` |
| 确认 | 弹窗按钮 | 校验并提示在网页端完成 | `—` |
| 退出登录 | 设置项点击 | 确认弹窗后退出并跳转登录页 | `/auth/login` |

## 页面状态与异常态

- {'state': '密码弹窗', 'description': '显示修改密码表单'}
- {'state': '校验失败', 'description': '密码不一致或过短时toast提示'}
