# 全部计划

- **路由**：`/me/plan-history/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：查看当前计划与历史计划列表，支持按来源筛选与跳转训练记录。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 训练记录入口 | 按钮 | 跳转训练历史 | `/me/training-history/index` |
| 筛选-全部计划 | tab | 显示全部来源计划 | `—` |
| 筛选-教练指派 | tab | 仅显示教练指派计划 | `—` |
| 筛选-我的计划 | tab | 仅显示自定义计划 | `—` |
| 计划卡片 | 卡片点击 | 查看计划详情 | `/me/plan-history/detail/index` |
| 去今日训练 | 按钮 | 跳转今日训练 | `/training/today-training` |
| 去我的计划库 | 按钮 | 跳转计划库 | `/me/plan-lib/index` |
| 下拉刷新 | 手势 | 刷新列表 | `—` |
| 触底加载 | 手势 | 加载更多历史计划 | `—` |

## 页面状态与异常态

- {'state': '加载中', 'description': '显示加载中...'}
- {'state': '空列表', 'description': '显示暂无计划及快捷入口'}
- {'state': '全部加载完', 'description': '底部显示已加载全部记录'}
