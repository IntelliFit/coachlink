# 计划库

- **路由**：`/me/plan-lib/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：管理常用训练计划模板，支持新建、编辑、删除、应用计划，应用前可配置1RM。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 新建 | 按钮 | 跳转创建计划页 | `/me/plan-lib/create/index` |
| 计划卡片 | 卡片点击 | 跳转编辑计划页 | `/me/plan-lib/edit/index` |
| 应用 | 按钮 | 激活计划（如有1RM动作先弹窗配置） | `/training/today-training` |
| 删除 | 按钮 | 删除计划模板 | `确认弹窗后刷新` |
| 1RM配置弹窗-输入框 | 数字输入框 | 为相关动作设置1RM值 | `—` |
| 1RM配置弹窗-跳过 | 按钮 | 关闭弹窗不应用 | `—` |
| 1RM配置弹窗-确认应用 | 按钮 | 确认1RM并激活计划 | `—` |
| 空状态-创建第一个计划 | 按钮 | 跳转创建页 | `/me/plan-lib/create/index` |
| 下拉刷新 | 手势 | 刷新计划列表 | `—` |

## 页面状态与异常态

- {'state': '加载中', 'description': '显示骨架屏'}
- {'state': '空列表', 'description': '显示空状态和创建引导'}
- {'state': '应用中带1RM', 'description': '弹出1RM配置弹窗'}
