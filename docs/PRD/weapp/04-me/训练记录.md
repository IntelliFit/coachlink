# 训练记录

- **路由**：`/me/training-history/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：日历形式的训练记录查看，支持按月切换、选择日期查看当日训练明细与分享。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 返回 | 按钮 | 返回上一页 | `—` |
| 即兴锻炼 | 按钮 | 跳转即兴训练 | `/training/impromptu-training` |
| 上月 | 按钮 | 切换至上一个月 | `—` |
| 下月 | 按钮 | 切换至下一个月 | `—` |
| 日期格子 | 日历格子点击 | 加载该日训练明细 | `—` |
| 训练明细项 | 卡片点击 | 展开/收起动作摘要 | `—` |
| 分享本次训练 | 按钮 | 生成分享链接并跳转 | `分享页` |
| 页面分享 | 小程序分享 | 分享训练记录页面 | `—` |

## 页面状态与异常态

- {'state': '加载中', 'description': '日历和统计区域显示加载中'}
- {'state': '当日无记录', 'description': '显示暂无训练记录'}
- {'state': '未登录', 'description': '跳转登录页（由service层处理）'}
