# 个人中心

- **路由**：`/me/profile/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：学员端个人主页，展示用户头像、昵称、积分、身份徽章，并提供多个功能入口菜单。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 用户头像/信息区 | 卡片点击 | 查看个人资料详情 | `/me/profile/detail/index` |
| 全部计划 | 菜单图标 | 跳转计划历史 | `/me/plan-history/index` |
| 我的教练 | 菜单图标 | 跳转我的教练 | `/me/my-coaches/index` |
| 我的会员 | 菜单图标 | 跳转会员中心 | `/me/membership/index` |
| 训练记录 | 菜单图标 | 跳转训练历史 | `/me/training-history/index` |
| 我的好友 | 菜单图标 | 跳转好友列表 | `/me/friends/index` |
| 消息中心 | 菜单图标 | 跳转消息列表 | `/me/messages/index` |
| 我的动作库 | 菜单图标 | 跳转动作库 | `/me/action-lib/index` |
| 知识库 | 菜单图标 | 跳转知识库 | `/content/knowledge` |
| 我的计划库 | 菜单图标 | 跳转计划库 | `/me/plan-lib/index` |
| 排行榜 | 菜单图标 | 跳转排行榜 | `/discovery/ranking` |
| 购买记录 | 菜单图标 | 跳转购买记录 | `/me/purchase-history/index` |
| 切换角色 | 按钮 | 学员/教练端切换 | `/coach/overview` |
| 申请成为教练 | 按钮 | 跳转教练申请 | `/coach/application` |
| 个人设置 | 按钮 | 编辑个人资料 | `/me/profile/edit/index` |
| 账户设置 | 按钮 | 跳转账户设置 | `/me/settings/index` |
| 退出登录 | 按钮 | 显示确认弹窗并退出 | `/auth/login` |
| 立即登录 | 按钮 | 跳转登录页 | `/auth/login` |
| 注册账号 | 按钮 | 跳转注册页 | `/auth/register` |
| 底部链接 | 文本链接 | 跳转关于/免责声明/联系/文档/入驻说明/消费者权益/用户协议/平台协议 | `对应文档页` |

## 页面状态与异常态

- {'state': '未登录态', 'description': '显示游客模式、点击登录、注册账号、申请成为教练入口'}
- {'state': '教练身份', 'description': '显示切换到学员端，个人设置跳转教练资料编辑页'}
- {'state': '加载失败', 'description': '导航失败时通过 toast 提示'}
