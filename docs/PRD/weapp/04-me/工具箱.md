# 工具箱

- **路由**：`/me/toolbox/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：训练辅助工具入口。顶部主卡固定为单杠地图（2026-10-22 起，使用人数最多），下方实用工具网格为力量计算器、功率视频分析、单手引体测算、社区数据，再往下为体感小游戏。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 单杠地图主卡封面 / 找附近单杠 | 主卡 / 主按钮 | 跳转单杠地图列表 | `/streetlifting/index/locations` |
| 上传点位 | 主卡次按钮 | 进入单杠地图并直接打开分享表单（游客先提示登录） | `/streetlifting/index/locations?create=1` |
| 力量计算器 | 工具卡片 | 跳转力量计算器 | `/streetlifting/index/calculator` |
| 功率视频分析 | 工具卡片 | 跳转功率分析 | `/toolbox/power-analysis/index` |
| 社区数据 | 工具卡片 | 跳转社区数据 | `/streetlifting/index/data` |
| 场景急救箱卡片 | 卡片点击 | 跳转场景详情 | `/me/toolbox/scenario/index` |
| 分享 | 分享按钮 | 小程序原生分享 | `—` |

## 页面进入埋点（2026-10-22）

- 工具箱首页及各工具页调用 `usePageEnterTrace()`（`apps/wechat/src/utils/pageTrace.ts`），页面显示时向 `/api/trace` 写 `page_enter`，与网页共用 `admin_trace_events`。
- `path` 为小程序路由（不带 query），`url` 为 `weapp://<envVersion><path>`；查正式版用 `url like 'weapp://release/%'`，以 `anon_id` 去重访客为主指标，`from_path` 看从工具箱进入各工具的转化。
- 服务端只在 production 且非 localhost 时入库；请求失败静默，不弹提示、不阻塞导航。
- 选择依据：2026-09-21 至 10-20 只读统计，单杠地图新增点位 563 条 / 217 人（10-10 窗口为 93 人），小程序此前无页面访问记录。
