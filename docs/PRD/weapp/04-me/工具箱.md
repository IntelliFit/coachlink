- **路由**：`/me/toolbox/index`

## 页面进入埋点（2026-10-22）

- 工具箱首页及各工具页调用 `usePageEnterTrace()`（`apps/wechat/src/utils/pageTrace.ts`），页面显示时向 `/api/trace` 写 `page_enter`，与网页共用 `admin_trace_events`。
- `path` 为小程序路由（不带 query），`url` 为 `weapp://<envVersion><path>`；查正式版用 `url like 'weapp://release/%'`，以 `anon_id` 去重访客为主指标，`from_path` 看从工具箱进入各工具的转化。
- 服务端只在 production 且非 localhost 时入库；请求失败静默，不弹提示、不阻塞导航。
- 选择依据：2026-09-21 至 10-20 只读统计，单杠地图新增点位 563 条 / 217 人（10-10 窗口为 93 人），小程序此前无页面访问记录。

## 哑铃弹弹（2026-10-24 上线，10-25 改物理，10-26 改为长尾“游戏物理”）

- **玩法**：前置摄像头全屏，左右两块大杠铃片，中间一道比哑铃粗细略宽、比哑铃长度窄的缝。每局小哑铃从漏斗里**随机位置、随机角度、随机初速度和自转**松手，在重力下来回撞片子，撞一次计 1 个；只有碰巧**竖着**经过缝口才会掉出去，掉出画面就结束，撞了几下就做几个（顶部文字“我今天要做 N 个 X”）。没有手动喊停。
- **物理**：2D 刚体模拟（胶囊形哑铃 vs 圆形片子，冲量碰撞 + 摩擦带出转动），完全弹性且总能量守恒（每步按松手时的总能量校正），哑铃不会弹得比松手处更高，也不会越弹越没劲。每局摩擦随机（0–0.35，偏向小值），相当于每只哑铃“手感”不同。固定 1/240 秒步长；贴着滚动不计数；万一卡住 1.2 秒或到 20 分钟 / 9999 下兜底结束。
- **次数分布**（1000 次随机松手）：0 下 0.6%、1–9 下 13%、10–99 下 41%、100–999 下 42%、1000 下以上 3.5%；中位约 84 下，P90 约 480，最多约 3600。1× 下约每秒 7–10 下，中位一局约 12 秒，P90 约 75 秒，P99 约 4.6 分钟。
- **速度**：1× / 2× / 3× / 5× / 10× 只是快进模拟时间，轨迹和次数不变，弹的过程中可切换。动作可选俯卧撑、引体向上、深蹲、臂屈伸、波比跳、卷腹；速度和动作记在本机。
- **流程**：松手扔哑铃 → 3-2-1 倒计时（哑铃停在本局松手姿态）→ 弹跳 → 掉出画面 → 结果停留约 2 秒后结束录制 → “保存视频”免费存相册。
- **视频**：相机帧 + 叠层合成，竖屏 448×800、20 fps，无原声，单段最长 10 分钟（超过的长局视频停在 10 分钟，游戏照常弹完，建议开快进）。物理世界固定 9:16，实时画布和录制画布只是缩放不同，轨迹一致。微信版本不支持 `createMediaRecorder` / 离屏画布时只能玩、不录，会提示；开发者工具不支持录制，需真机验证。
- **品牌露出**：不压角标水印（避免被抖音、小红书按站外水印限流），改为杠铃片上印 `COACHLINK`。
- **代码**：`apps/wechat/src/toolbox/dumbbell-bounce/`；物理模型 `bounceModel.ts`（单测 `tests/dumbbell-bounce-model.test.ts`），实时画布与录制共用绘制 `bounceScene.ts`；录制管线与其他体感小游戏共用 `toolbox/games/cameraCompositeRecorder.ts`。
