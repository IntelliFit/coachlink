# 聊天详情

- **路由**：`/me/messages/chat/index`
- **所属模块**：小程序 / 个人中心
- **功能概述**：与教练或好友的单聊页面，支持文字、图片消息及历史消息加载。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 消息气泡 | 图片长按 | 图片消息长按显示菜单 | `—` |
| 加载更多 | 列表顶部点击 | 加载更早消息 | `—` |
| 相册 | 按钮 | 选择图片发送 | `—` |
| 消息输入框 | 输入框 | 输入文字消息 | `—` |
| 发送 | 按钮 | 发送文字消息 | `—` |

## 页面状态与异常态

- {'state': '加载中', 'description': '显示加载中...'}
- {'state': '缺少会话信息', 'description': '显示缺少会话信息'}
- {'state': '草稿带入', 'description': '自动将其他页面带入的草稿填充到输入框'}
- {'state': '发送失败', 'description': '移除乐观消息并恢复输入内容'}
