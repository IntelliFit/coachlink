# 登录页

- **路由**：`/auth/login`
- **所属模块**：小程序 / 认证
- **功能概述**：用户登录入口，支持密码/验证码双模式登录及微信手机号快捷登录。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 密码登录/验证码登录切换 | tab | 切换登录模式，清空对应输入 | `—` |
| 手机号或邮箱输入框 | input | 输入账号 | `—` |
| 登录密码输入框 | input | 输入密码（仅在密码登录模式显示） | `—` |
| 验证码输入框 | input | 输入6位验证码（仅在验证码登录模式显示） | `—` |
| 获取验证码按钮 | button | 触发滑块验证后发送短信/邮件验证码，带60秒倒计时 | `—` |
| 用户协议勾选框 | checkbox | 同意用户服务协议和隐私政策 | `—` |
| 《用户服务协议》 | link | 跳转协议页 | `/me/terms/index` |
| 《隐私政策》 | link | 跳转隐私政策页 | `/me/privacy/index` |
| 立即登录按钮 | button | 校验后执行登录，成功后跳转对应首页 | `/training/today-training` |
| 手机号快捷登录按钮 | button | 调起微信 getPhoneNumber 授权并快捷登录 | `/training/today-training` |
| 忘记密码？ | link | 显示重置密码表单 | `—` |
| 立即注册 | link | 跳转注册页，携带 invite 参数 | `/auth/register` |
| 返回登录 | button | 重置密码表单内返回登录态 | `—` |
| 滑块验证弹窗 | modal | 人机验证，成功后发送验证码 | `—` |

## 页面状态与异常态

- {'stateName': '登录中', 'description': '按钮显示 loading 动画，禁止重复点击'}
- {'stateName': '验证码倒计时', 'description': '获取验证码按钮显示剩余秒数并禁用'}
- {'stateName': '重置密码表单', 'description': '替换登录表单显示重置密码界面'}
