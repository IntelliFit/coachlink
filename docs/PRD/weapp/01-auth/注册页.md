# 注册页

- **路由**：`/auth/register`
- **所属模块**：小程序 / 认证
- **功能概述**：新用户注册页，通过手机号/邮箱+验证码完成注册并自动登录。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 手机号或邮箱输入框 | input | 输入注册账号 | `—` |
| 登录密码输入框 | input | 输入密码 | `—` |
| 确认密码输入框 | input | 再次输入密码校验一致性 | `—` |
| 邀请码输入框 | input | 可选，填写邀请码 | `—` |
| 验证码输入框 | input | 输入6位验证码 | `—` |
| 获取验证码按钮 | button | 触发滑块验证后发送验证码，带倒计时 | `—` |
| 同意协议勾选框 | checkbox | 同意用户协议与免责声明 | `—` |
| 《用户协议》 | link | 跳转用户协议页 | `/me/terms/index` |
| 《免责声明》 | link | 跳转免责声明页 | `/me/disclaimer/index` |
| 立即注册按钮 | button | 校验后注册并自动登录 | `/training/today-training` |
| 立即登录 | link | 返回登录页 | `/auth/login` |
| 滑块验证弹窗 | modal | 人机验证，成功后发送验证码 | `—` |

## 页面状态与异常态

- {'stateName': '注册中', 'description': '按钮显示 loading 动画'}
- {'stateName': '验证码倒计时', 'description': '获取验证码按钮禁用并显示倒计时'}
