# 学员 onboarding

- **路由**：`/auth/student-onboarding`
- **所属模块**：小程序 / 认证
- **功能概述**：学员首次登录后完善基础档案的三步表单流程。

## 交互元素清单

| 元素名称 | 类型 | 触发行为 | 跳转目标 |
|---|---|---|---|
| 昵称输入框 | input | 填写昵称 | `—` |
| 性别选择 | card | 单选卡片：男 / 女 | `—` |
| 身高输入 | inputNumber | 输入身高(cm) | `—` |
| 体重输入 | inputNumber | 输入体重(kg) | `—` |
| 健身目标选择 | card | 单选卡片：减脂塑形/增肌强身/力量提升/体能改善/体态矫正/运动恢复/综合体适能/灵活柔韧 | `—` |
| 训练水平选择 | card | 单选卡片：零基础/有一点基础/有系统训练经验 | `—` |
| 感兴趣的训练方向 | chip | 多选标签：上肢/下肢/核心/体态纠正/减脂燃脂/灵活性/力量举/心肺有氧 | `—` |
| 常用器械 | chip | 多选标签：徒手/哑铃/杠铃/拉力器/器械区/壶铃 | `—` |
| 单次训练时长 | chip | 单选标签：15/20/30/45/60 分钟 | `—` |
| 上一步 | button | 返回上一步 | `—` |
| 下一步 | button | 校验并进入下一步 | `—` |
| 开始训练 | button | 提交档案并跳转训练页 | `/training/impromptu-training` |

## 页面状态与异常态
