## 第二条 健康与安全风险警示

### 2.1 健身训练固有风险

**健身训练活动本身具有一定的危险性和不可预见性。**
参与健身训练可能导致的风险包括但不限于：

1. **肌肉骨骼损伤**：肌肉拉伤、韧带扭伤、关节损伤、骨折等
2. **心血管意外**：心律失常、心肌梗塞、中风等
3. **呼吸系统问题**：过度换气、呼吸困难等
4. **代谢问题**：脱水、电解质紊乱、低血糖等
5. **其他意外**：器械使用不当导致的伤害、跌倒、碰撞等

### 2.2 个体差异

每个人的身体状况、健康水平、运动能力和恢复能力均存在差异。同样的训练计划对不同个体可能产生不同的效果和风险。

### 2.3 医疗咨询建议

**本平台强烈建议您在开始任何新的训练计划之前：**

1. 咨询您的医生或专业医疗人员，确认您的身体状况适合进行健身训练
2. 如有任何慢性疾病（包括但不限于心脏病、高血压、糖尿病、关节疾病、呼吸系统疾病等），务必获得医生的运动许可和建议
3. 如近期有过手术、受伤或身体不适，应在完全康复后再进行训练
4. 如您正在服用任何药物，应了解药物对运动的影响

### 2.4 紧急情况处理

1. 用户在训练过程中如感到胸痛、呼吸困难、头晕、恶心或其他异常症状，应**立即停止训练**
2. 如发生紧急情况，请立即拨打急救电话（120）或前往最近的医疗机构
3. 本平台不提供任何形式的紧急医疗救助服务
