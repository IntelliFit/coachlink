> **版本**：v1.0  
> **日期**：2026年4月  
> **定位**：力量训练教练智能化线上执教平台  
> **战略路径**：从工具到平台 — 用好用深双边工具，把交易自然嵌入平台

---

## 一、项目概述

### 1.1 一句话定位

**CoachLink 是力量训练领域的 "教练数字化办公室"** —— 不是另一个训练记录 App，而是让教练能规模化带学员、让学员获得专业指导的智能化执教平台。

### 1.2 核心洞察

教练行业有一个被忽视的结构性矛盾：

> **教练的价值在于知识和经验，但教练 80% 的时间花在了重复劳动上。**

- 重复制定相似计划
- 在微信里翻聊天记录找学员视频
- 手工计算每个学员的重量
- 同样的动作要领要解释 100 遍

CoachLink 的底层逻辑是：**把教练的知识资产化（模板、动作库、内容），通过自动化交付实现规模化，让教练的时间从 "体力劳动" 转向 "真正需要人的服务"。**

### 1.3 当前产品形态

| 维度 | 状态 |
|------|------|
| Web 端 | Next.js 16 + React 18，120+ 页面，PWA 适配 |
| 小程序 | 微信小程序（Taro），已上线内测 |
| 数据库 | Supabase PostgreSQL，75 张表 |
| 核心功能 | 计划模板库、训练执行、1RM 自动算重、视频点评、即时通讯、排行榜、知识库、支付系统 |

## 二、市场分析

### 2.1 目标市场

**第一阶段（当前）**：中国力量训练 / 街健 / 力量举垂直领域

| 细分人群 | 规模估算 | 痛点 |
|----------|----------|------|
| 有一定训练基础、想找教练指导的爱好者 | 数十万级 | 找不到靠谱的线上教练 |
| 想从线下拓展到线上的力量训练教练 | 数千级 | 带学员有数量天花板 |
| 街健 / 力量举社群活跃玩家 | 数万级 | 缺乏系统化指导和数据追踪 |

**市场选择的理由**：
1. **数据化程度高**：重量×次数×组数，天然适合数字化
2. **付费意愿明确**：力量训练爱好者对专业指导有明确付费习惯
3. **教练价值高**：计划个性化需求强，AI 无法完全替代
4. **用户粘性强**：长周期训练（8-16 周为一个阶段），持续服务需求

### 2.2 竞品格局

| 竞品类型 | 代表产品 | 优势 | 劣势 | CoachLink 差异点 |
|----------|----------|------|------|-----------------|
| 训练记录工具 | 训记、Strong | 记录体验好 | 无教练连接能力 | 我们连接教练，不是替代教练 |
| 健身课程平台 | Keep、薄荷 | 流量大 | 内容标准化，无个性化 | 千人千面计划 + 真人教练反馈 |
| 教练私域运营 | 微信+Excel | 灵活 | 效率极低，无法规模化 | 把私域流程产品化、自动化 |
| 国外教练平台 | Trainerize | 功能成熟 | 国外生态，本地化差 | 国内首家专注力量训练的本土化方案 |

**核心竞争壁垒**：
- **1RM 自动算重量系统**：基于学员最新极限数据动态计算训练负荷，技术门槛高
- **计划模板-实例体系**：教练一次创建，无限复用，每次下发自动个性化
- **视频上下文系统**：学员发送训练视频自动带训练背景标签（第几周、第几天、什么重量），解决教练"翻聊天记录"的痛点

## 三、产品架构：从工具到平台

### 3.1 战略框架

```
                    ┌─────────────────────────────┐
                    │        平台层（交易）         │
                    │   订阅、支付、抽成、数据服务   │
                    └──────────────┬──────────────┘
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         │                         │                         │
         ▼                         ▼                         ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   教练端工具     │    │   学员端工具     │    │   社区与内容     │
│                 │    │                 │    │                 │
│ • 计划模板库    │◄──►│ • 今日训练      │    │ • 排行榜        │
│ • AI 智能导入   │    │ • 训练执行      │    │ • 好友/搭子     │
│ • 动作库+视频   │    │ • 1RM 计算      │    │ • 教练专栏      │
│ • 学员管理看板  │    │ • 进步足迹      │    │ • 街健指数      │
│ • 问卷系统      │    │ • 视频上传      │    │ • 知识库        │
│ • AI 虚拟分身   │    │ • 即时通讯      │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

**关键逻辑**：
- **双边工具必须先好用**：教练愿意用，因为能帮他省时间、多带学员；学员愿意用，因为能获得专业计划和数据追踪。
- **交易自然嵌入**：当教练和学员在平台上形成稳定的训练关系后，订阅付费是自然而然的一步。
- **平台价值随双边密度指数增长**：教练越多，学员选择越多；学员越多，教练收入越高。

### 3.2 教练端核心工具

| 工具 | 解决的问题 | 效率提升 |
|------|-----------|----------|
| **计划模板库** | 重复制定相似计划 | 2-3小时 → 10分钟（12-18倍） |
| **AI 智能导入** | 把文本计划转成结构化模板 | 手动输入 → AI 自动识别 |
| **动作库 + 示范视频** | 同一动作要领重复解释 | 一次上传，所有学员即时查看 |
| **1RM 自动算重** | 手动计算每个学员的重量 | 全自动，精确到 2.5kg |
| **学员管理看板** | 无法一眼看到所有学员进度 | 档案、进度、视频一站式查看 |
| **AI 虚拟分身** | 学员常见问题占用大量时间 | 自动回复 + 资料库驱动 |
| **计划脚本模式** | 批量修改计划效率低 | 文本批量编辑 → 编译回结构化 |

### 3.3 学员端核心工具

| 工具 | 解决的问题 | 用户体验 |
|------|-----------|----------|
| **今日训练** | 不知道今天练什么 | 打开即看到当天任务 |
| **训练执行** | 记不住组次、算不准重量 | 逐组引导、自动填重 |
| **1RM 估算与追踪** | 不知道自己的真实极限 | 每次训练自动估算 e1RM |
| **进步足迹** | 看不到自己的进步 | 自动记录 PR，生成时间轴 |
| **视频上传+教练点评** | 动作不对没人纠正 | 每组都可上传视频，教练文字/语音点评 |
| **排行榜** | 训练太枯燥没动力 | 与全国玩家竞技，生成分享海报 |
| **街健力量指数** | 不知道自己什么水平 | 标准化评分体系 |

### 3.4 社区与内容层

| 功能 | 目的 |
|------|------|
| **排行榜系统** | 游戏化激励，提升训练频率 |
| **好友/搭子系统** | 社交关系增加平台粘性 |
| **教练专栏** | 让教练成为内容创作者，建立个人品牌 |
| **知识库 + 人体地图** | 权威内容建立平台公信力 |
| **分享卡片** | 社交裂变，为教练和平台引流 |

## 四、商业模式

### 4.1 收入结构

```
CoachLink 收入 = 交易抽成 + 会员订阅 + 增值服务
```

#### 第一层：交易抽成（核心）

这是平台最健康、最可持续的收入来源。

| 模式 | 说明 | 当前验证 |
|------|------|----------|
| 平台代收 | 学员通过平台支付订阅费用，平台抽成后结算给教练 | ✅ 已上线支付宝支付 |
| 教练自主定价 | 教练自定义三档服务价格（基础/进阶/全能） | ✅ 已支持 |
| 阶梯费率 | 带学员越多，平台抽成比例越低，鼓励做大 | 📋 规划中 |

**当前数据验证**：
- 订阅支付客单价约 **180 元**
- 付费订阅用户 **14 人**
- 付费订单 **15 笔**
- 已有 **1 位重复付费用户**（验证续费意愿）

#### 第二层：会员订阅（学员自助）

针对不找私教、但想使用平台工具的"散户"用户。

| 权益 | 免费版 | 基础会员 | 高级会员 |
|------|--------|----------|----------|
| 训练记录 | ✅ | ✅ | ✅ |
| 自建计划 | 1 个 | 5 个 | 无限 |
| AI 计划导入 | ❌ | 3 次/月 | 无限 |
| 视频存储 | 100MB | 1GB | 10GB |
| 排行榜参与 | ✅ | ✅ | ✅ |
| 知识库访问 | 基础 | 全部 | 全部 |
| 价格 | 免费 | ¥19/月 | ¥49/月 |

#### 第三层：增值服务

| 服务 | 定价 | 说明 |
|------|------|------|
| 教练 AI 虚拟分身 | 包含在订阅中 | 降低教练沟通成本 |
| 数据分析报告 | ¥9.9-29.9/份 | 学员训练数据深度分析 |
| 内容付费解锁 | 教练自定 | 单篇专栏文章/视频付费 |
| 企业/健身房版 | 按需报价 | 健身房批量入驻 |

### 4.2 成本结构

| 成本项 | 当前水平 | 优化方向 |
|--------|----------|----------|
| 服务器/数据库 | Supabase 按需 | 当前量级成本可控 |
| AI API（DeepSeek/Ofox） | 按调用量 | 缓存+规则引擎降低 LLM 调用 |
| 视频存储/CDN | 按使用量 | 前端压缩 + 异步处理 |
| 支付通道费 | 支付宝 ~0.6% | 无优化空间 |
| 运营/审核人力 | 目前一人多岗 | 未来需要专职运营 |

### 4.3 单位经济模型（Unit Economics）

以当前数据为基准，假设一位活跃教练带 20 位学员：

| 项目 | 数值 |
|------|------|
| 单学员月均订阅费 | ¥180 |
| 单教练月总收入（20学员） | ¥3,600 |
| 平台抽成（15%） | ¥540/教练/月 |
| 单教练获客成本 | 极低（口碑+教练自有流量） |
| 边际成本 | 接近零（平台自动化交付） |

**关键结论**：当平台教练数达到 100 人、人均带 20 学员时，月 GMV 约 72 万，平台月收入约 10.8 万。

### 6.2 下一阶段：教练规模化（2026 Q3 - 2027）

**核心任务**：解决"教练入驻后不活跃"的问题

| 举措 | 预期效果 |
|------|----------|
| 教练入驻后 7 天新手引导 | 降低首次使用门槛 |
| 标杆教练案例打造 | 让新教练看到"别人怎么赚钱" |
| 教练社群运营 |  peer pressure + 经验分享 |
| 简化首批学员获取 | 平台流量分配或推荐机制 |
| AI 虚拟分身降低维护成本 | 让"带 1 个学员"也能有正收益 |

**目标指标**：
- 活跃教练从 3 人 → 30 人（10 倍）
- 每位活跃教练带 20+ 学员
- 计划完成率从 <1% → 15%
