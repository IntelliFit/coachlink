# 分享卡片系统详细设计

## 1. 概述

分享卡片系统让学员在训练完成后，一键生成精美的训练总结卡片，保存到手机相册或复制链接，发到微信群/朋友圈进行"打卡"展示。

### 1.1 平台兼容策略

| 平台               | 用户占比 | 保存方式                      |
| ------------------ | -------- | ----------------------------- |
| **移动端（优先）** | ~90%     | Web Share API → 原生分享/保存 |
| **桌面端**         | ~10%     | 自动下载 PNG 文件             |

### 1.2 裂变增长元素（核心）

卡片必须包含以下元素来促进传播和拉新：

| 元素         | 作用                               | 实现                               |
| ------------ | ---------------------------------- | ---------------------------------- |
| **扫码入口** | 路人扫码 → 查看训练详情 → 引导注册 | 二维码链接带推荐参数 `?ref=userId` |
| **个性签名** | 增加卡片的可读性与仪式感           | "训练是通向自由的唯一途径"         |
| **教练露出** | 引流到教练主页                     | "跟随教练 XX 训练"                 |
| **挑战文案** | 激发互动欲望                       | "今日训练 12,450 kg，你呢？"       |
| **品牌曝光** | 平台认知                           | CoachLink Logo + Slogan            |

## 3. 技术实现方案

### 3.1 核心技术：html2canvas

```typescript
// 动态导入（Next.js SSR 兼容）
const html2canvas = await import("html2canvas");

// 生成图片
const canvas = await html2canvas.default(cardElement, {
    backgroundColor: null, // 透明背景
    scale: 2, // 2倍分辨率，保证清晰度
    useCORS: true, // 允许跨域图片
    logging: false,
});

// 转为 Blob
const blob = await new Promise<Blob>((resolve) => {
    canvas.toBlob((b) => resolve(b!), "image/png", 1.0);
});
```

### 3.2 保存到设备

**方案 A：Web Share API（推荐，移动端优先）**

```typescript
async function shareCard(blob: Blob, filename: string) {
    const file = new File([blob], filename, { type: "image/png" });

    if (navigator.canShare?.({ files: [file] })) {
        // 移动端原生分享
        await navigator.share({
            files: [file],
            title: "我的训练打卡",
        });
    } else {
        // 回退：下载文件
        downloadBlob(blob, filename);
    }
}
```

**方案 B：直接下载（桌面端回退）**

```typescript
function downloadBlob(blob: Blob, filename: string) {
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url;
    a.download = filename;
    a.click();
    URL.revokeObjectURL(url);
}
```

### 3.3 移动端保存到相册

在 PWA 或 WebView 环境下：

- **iOS Safari**：长按图片 → "添加到照片"
- **Android Chrome**：Web Share API 自动支持保存到相册
- **微信内置浏览器**：长按图片保存（需确保图片是 `<img>` 标签）

**最佳实践**：生成后先展示预览图，用户长按即可保存。

## 5. 数据接口

### 5.1 获取分享所需数据

**API**: `GET /api/execution/[id]/share-info`

**响应**:

```json

  "success": true,
  "data": {
    "executionId": "uuid",
    "shareToken": "uuid",
    "dayIndex": 24,
    "planName": "胸肌力量训练",

    "totalVolume": 12450,
    "totalSets": 24,
    "duration": 45,
    "prRecords": [
      { "exercise": "卧推", "weight": 85, "unit": "kg" }
    ],
    "monthlyTrainingDays": ["2026-01-02", "2026-01-04", ...],
    "user": {
      "nickname": "锦恢",
      "avatarUrl": "..."
    }
```

### 5.2 公开分享页数据

**API**: `GET /api/public/training/[shareToken]`

无需登录即可访问，返回简化的训练摘要。

```
训练完成
    ↓

    ↓
点击弹出 ShareCardModal
    ↓

    ↓

    ↓
├── 移动端：Web Share API → 分享/保存
└── 桌面端：自动下载 PNG
    ↓
复制分享链接（可选）
```

## 7. 注意事项

### 7.1 性能优化

- 卡片渲染使用 `visibility: hidden` 隐藏，避免布局抖动
- 图片生成在用户点击保存时才执行，不预先生成
- 用户头像等外部图片需配置 CORS

### 7.2 兼容性

- iOS Safari 不支持 `navigator.share` 分享文件，需提示长按保存
- 微信内置浏览器限制较多，建议展示图片让用户手动长按

### 7.3 二维码生成

使用 `qrcode.react` 库生成小程序码/网页二维码：

```tsx
import { QRCodeSVG } from "qrcode.react";

<QRCodeSVG
    value={`https://coachlink.app/share/training/${shareToken}`}
    size={64}
    bgColor="transparent"
    fgColor="#ffffff"
/>;
```
