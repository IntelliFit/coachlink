# 变更日志 & 开发进度 (Changelog)

本文档记录了代码库近期的变更、功能实现和 Bug
修复。通过记录修改内容，帮助工程师快速了解项目的当前状态。

## 2026-01-05 (当前)

### 📂 文档治理

- **重组**: 将 `docs/todo` 重构为基于功能的目录结构
  (`docs/todo/features/`)，以提高可读性。
- **整合**: 将变更日志和 README 整合至 `docs/todo` 统一管理。

## 2026-01-04

### 🏋️‍♂️ 学员自建计划管理

- **功能**: 扩展了计划管理系统，支持学员自建计划（"收藏的计划"）。
- **逻辑**: 实现了学员自建计划的执行和续期逻辑，无需教练干预。

### 🐛 API 修复

- **视频引用**: 修复了 `/api/chat/list-student-videos` 中的
  `500 Internal Server Error`。
- **原因**: 查询中缺失 `is_progress_set` 列。
- **修复**: 修正了执行集视频查询中的列引用。

### 📊 既往训练周数 (Prior Training Weeks)

- **功能**: 在 `StudentSubscription` 中添加了 `prior_training_weeks` 字段。
- **UI**: 更新了教练仪表盘（学员详情），允许编辑和查看此字段。
- **计算**: 服务层在计算总训练时长时现在会包含既往周数。

### 🗄️ Supabase 存储 & 资源

- **存储**: 修复了 `avatars` (头像) 和 `payment-qr-codes` (支付二维码)
  存储桶的问题。
- **逻辑**: 上传时使用正确的 `bucket_id`。
- **清理**: 实现了当数据库记录被删除时，自动删除存储中物理视频文件的逻辑。

### 💳 支付 & 教练设置

- **移动端**: 在 `PaymentDialog` 中实现了移动设备检测，使用
  `alipay.trade.wap.pay` 接口。
- **管理后台**: 为教练支付模式（全局 vs 个人）和个人二维码管理添加了精细化控制。

### 🖼️ UI/UX 修复

- **头像**: 修复了教练头像显示问题，增加回退逻辑至 `user_profiles.avatar_url`。
- **多端适配**: (分析) 评估了将 Web 应用转换为微信/抖音小程序的策略。

## 2026-01-03 - 之前

### 📅 训练逻辑

- **Bug 修复**:
  解决了已完成训练日显示错误或重复日期的问题（例如同一天显示两条记录）。
