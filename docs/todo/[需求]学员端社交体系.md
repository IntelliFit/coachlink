# [需求] 学员端社交体系需求文档

## 1. 文档概述

- **文档版本**：V1.0
- **创建时间**：2025-12-29
- **文档目的**：明确 CoachLink
  学员端新增“社交属性”的业务目标、用户故事及功能边界，指导后续的功能设计与开发。

## 2. 业务背景与价值

### 2.1 现状分析

目前 CoachLink 学员端是一个纯工具属性的
App，学员完成训练后缺乏展示出口。虽然部分学员会在微信群打卡，但缺乏统一、美观的载体（通常是截图），传播效果差，且无法回流到平台。

### 2.2 核心价值

1. **满足学员虚荣心
   (Acquisition/Retention)**：通过提供精美的“战绩卡片”，降低学员在私域（朋友圈/微信群）装逼的门槛，提升产品粘性。
2. **品牌传播
   (Referral)**：分享卡片自带品牌标识与二维码，将私域流量转化为潜在的新用户（或至少提升品牌认知）。
3. **弱社交连接
   (Engagement)**：提供基础的好友功能，满足熟人/同门之间互相“监工”的需求，但严格限制陌生人骚扰，保护教练的“私域感”。

## 3. 用户故事 (User Stories)

### 3.1 核心场景：分享与炫耀 (P0)

- **US-01 训练打卡**：作为一个学员，我刚完成了一次艰难的深蹲训练，通过了
  PR，我希望一键生成一张包含我核心数据（重量、次数、总容量）的酷炫图片，发到健身群里求点赞。
- **US-02
  历史回顾**：作为一个学员，我想查看我上个月的训练热力图（坚持了多少天），并生成一张月度总结图，发朋友圈纪念我的自律。
- **US-03
  外部查看**：作为一个群友，我扫了别人发的二维码，我希望能直接在一个无需登录的网页上看到他这次训练的详细内容（动作、组数），并能简单点个赞。

### 3.2 辅助场景：熟人围观 (P1)

- **US-04 精确加友**：作为一个学员，我在微信群里认识了另一个用 CoachLink
  的大神，我希望输入他的精确ID加他为好友，方便以后看他练什么。
- **US-05
  拒绝骚扰**：作为一个社恐学员，我不希望被“系统自动推荐”给陌生人，也不希望别人在
  App 里跟我闲聊，我就想安安静静训练。
- **US-06
  好友动态**：作为一个学员，我想一眼看到我关注的那几个大神今天有没有训练（已练/未练状态），点击能看到他们具体的训练课表，激励我自己去练。

## 4. 功能需求列表 (Feature List)

### 4.1 社交分享 (Share System)

| ID   | 功能名称         | 详细描述                                                                                              | 优先级 |
| :--- | :--------------- | :---------------------------------------------------------------------------------------------------- | :----- |
| S-01 | **战绩卡片生成** | 支持多模板生成图片（数据流、日历流、极简流）。需包含核心训练数据、用户信息、App品牌Logo、回流二维码。 | **P0** |
| S-02 | **公开训练页**   | 生成一个公共的 Web 页面（Public Page），展示单次训练详情。非注册用户可访问。                          | P0     |
| S-03 | **微信一键跳转** | (如果是在微信小程序环境) 支持直接唤起微信分享；(如果是 App/Web) 支持保存图片到本地。                  | P0     |

### 4.2 好友体系 (Friend System)

| ID   | 功能名称           | 详细描述                                                                          | 优先级 |
| :--- | :----------------- | :-------------------------------------------------------------------------------- | :----- |
| F-01 | **好友搜索与添加** | **仅支持精确搜索**（昵称/ID）。不支持模糊搜索，不支持“附近的人”。需对方确认同意。 | P1     |
| F-02 | **隐私设置**       | 开关：是否允许被搜索、是否开放训练详情给好友、敏感数据（体重/围度）是否隐藏。     | P1     |
| F-03 | **好友列表**       | 展示好友列表，标识“今日已练/未练”。                                               | P1     |
| F-04 | **好友训练详情**   | 点击好友头像/动态，可查看其训练计划详情（只读）。                                 | P1     |

## 5. 非功能需求 (Non-Functional Requirements)

### 5.1 隐私与边界 (Privacy & Boundaries)

- **去中心化**：坚决**不**做“同门推荐”、“教练榜单”等可能打通教练私域流量池的功能。学员之间的连接必须基于用户主动发起的“精确查找”。
- **轻量化**：**不**做 App 内的 IM 聊天功能。想聊天去微信聊，App
  内仅维持“点赞”级别的弱互动。

### 5.2 性能体验

- 图片生成速度需 < 2秒。
- 公共分享页需针对移动端极致优化首屏加载速度（SSR/ISR）。

## 6. 后续规划 (Out of Scope for V1)

- **站内互动**：V1
  暂不做站内点赞、评论等功能，所有互动均引导至微信/外部平台（“去微信群里聊”）。
- **广场/发现页**：V1 不做公域流量分发。
