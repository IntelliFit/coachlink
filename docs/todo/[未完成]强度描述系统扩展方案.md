## 需求背景

### 当前系统

- 模板中的动作强度**仅支持 RM 描述**（如 5RM = 能做5次的最大重量）
- 学员端根据学员填写的 1RM 数据，使用 `calcRecommendedLoad` 函数自动计算具体重量
- 现有代码位置：`src/lib/rmCaculator.ts`、`src/app/api/plan-lib/create-ai-instance/match.ts`

### 问题

1. **外部计划导入困难**：教练手头的计划通常使用具体重量（如"50kg"），无法直接导入
2. **描述方式受限**：有些教练习惯用百分比设置计划（如"80% 1RM"），而非 RM
3. **缺乏灵活性**：某些动作可能不适合 RM 描述，需要固定重量

### 期望

扩展强度描述系统，支持：

- **RM**：如 5RM（需要1RM才能计算）
- **百分比**：如 80%（需要1RM才能计算）
- **固定重量**：如 50kg（不需要计算，直接使用）

---

## 设计目标

1. **灵活性**：支持三种强度描述方式
2. **优先级**：相对强度（RM/百分比）优先，固定重量作为备选
3. **自动计算**：有1RM时自动计算具体重量，无时显示相对强度文字
4. **向后兼容**：现有模板数据无需迁移，读取时自动转换
5. **单位支持**：固定重量同时支持 kg 和 lbs

---

## 核心概念：双属性设计

强度不是单一维度的"三选一"，而是**两个独立属性**，按优先级使用：

| 属性                               | 说明                          | 必填 | 示例           |
| ---------------------------------- | ----------------------------- | ---- | -------------- |
| **相对强度** (`relativeIntensity`) | RM 或 百分比，需要1RM才能计算 | 可选 | `5RM` 或 `80%` |
| **推荐数值** (`recommendedLoad`)   | 固定重量，不需要计算          | 可选 | `50kg`         |

### 优先级逻辑

```
有相对强度？
  ├─ 是 → 学员有1RM数据？
  │       ├─ 是 → 计算具体重量 (source: 'calculated')
  │       └─ 否 → 显示相对强度文字 (source: 'relative-text')
  └─ 否 → 有推荐数值？
          ├─ 是 → 直接显示推荐数值 (source: 'recommended')
          └─ 否 → 不显示重量 (source: 'none')
```

### 使用场景

| 场景     | relativeIntensity                   | recommendedLoad             | 效果                         |
| -------- | ----------------------------------- | --------------------------- | ---------------------------- |
| 纯相对   | `{ type: 'rm', value: 5 }`          | -                           | 有1RM→计算，无→显示"5RM"     |
| 纯固定   | -                                   | `{ value: 50, unit: 'kg' }` | 直接显示"50kg"               |
| 双填     | `{ type: 'percentage', value: 80 }` | `{ value: 64, unit: 'kg' }` | 优先用80%计算，无1RM时用64kg |
| 导入计划 | -                                   | `{ value: 50, unit: 'kg' }` | 教练后续可补充相对强度       |

/**

export type RelativeIntensityType = "rm" | "percentage";

/**

export interface RelativeIntensity {

export interface IntensityConfig {

    displayText?: string; // 备用文字显示（如"5RM"、"80%"）

}

## 计算逻辑

### 体重处理说明

| 动作类型     | 示例                 | `includesBodyWeight` | 1RM含义       | 计算逻辑                       |
| ------------ | -------------------- | -------------------- | ------------- | ------------------------------ |
| **不含体重** | 深蹲、卧推、硬拉     | `false`              | 杠铃重量      | `推荐负重 = 1RM × 系数`        |
| **含体重**   | 负重引体、负重臂屈伸 | `true`               | 体重+外挂负重 | `推荐外挂 = 1RM × 系数 - 体重` |

### RM 与百分比的转换关系

使用 Brzycki 公式：`1RM = weight × (36 / (37 - reps))`

反推：`weight = 1RM × (37 - reps) / 36`

即：`reps对应的百分比 = (37 - reps) / 36`

| RM   | 约等于 1RM 的百分比 |
| ---- | ------------------- |
| 1RM  | 100%                |
| 2RM  | ~97.2%              |
| 3RM  | ~94.4%              |
| 5RM  | ~88.9%              |
| 8RM  | ~80.6%              |
| 10RM | ~75.0%              |
| 12RM | ~69.4%              |

### 核心计算函数

**文件位置**: `src/lib/rmCaculator.ts`（扩展现有文件）

```typescript
import type {
    CalcIntensityResult,
    IntensityConfig,
    WeightUnit,
} from "@/types/intensity";

export interface CalcIntensityOptions {
    intensityConfig?: IntensityConfig;
    // 旧字段兼容
    legacyRm?: number; // 旧的 params.强度 字段

    oneRM?: number; // 学员该动作的 1RM（可能没有）
    bodyWeight: number; // 学员体重 (kg)
    includesBodyWeight: boolean; // 动作是否包含体重（如引体向上）
}

/**
 * RM次数转换为百分比
 * 基于 Brzycki 公式
 */
export function rmToPercentage(rm: number): number {
    if (rm <= 0 || rm >= 37) {
        return rm === 1 ? 1 : 0.5; // 边界处理
    }
    return (37 - rm) / 36;
}

/**
 * 百分比转换为RM次数（近似）
 * 反向 Brzycki 公式
 */
export function percentageToRm(percentage: number): number {
    // percentage 是百分比值，如 80 表示 80%
    const p = percentage / 100;
    // 反推: rm = 37 - 36 × p
    return Math.round(37 - 36 * p);
}

/**
 * 计算并返回强度显示值
 * 这是新的主入口函数，替代部分 computeActionWeight 逻辑
 */
export function calcIntensityDisplay(
    options: CalcIntensityOptions,
): CalcIntensityResult {
    const {
        intensityConfig,
        legacyRm,
        oneRM,
        bodyWeight,
        includesBodyWeight,
    } = options;

    // 1. 优先使用 intensityConfig
    if (intensityConfig?.relativeIntensity) {
        const ri = intensityConfig.relativeIntensity;

        if (oneRM && oneRM > 0) {
            // 有1RM，计算具体重量
            let targetLoad: number;

            if (ri.type === "percentage") {
                // 百分比模式：直接乘以百分比
                targetLoad = oneRM * (ri.value / 100);
            } else {
                // RM模式：使用现有公式
                // 使用 calcRecommendedLoad 或直接计算
                const percentage = rmToPercentage(ri.value);
                targetLoad = oneRM * percentage;
            }

            // 如果动作含体重，需要减去体重得到外挂重量
            const displayWeight = includesBodyWeight
                ? targetLoad - bodyWeight
                : targetLoad;

            return {
                displayWeight: Math.round(Math.max(0, displayWeight) * 10) / 10,
                displayUnit: "kg",
                source: "calculated",
            };
        } else {
            // 无1RM，显示相对强度文字
            const text = ri.type === "rm" ? `${ri.value}RM` : `${ri.value}%`;

            // 尝试使用推荐数值作为备选显示
            if (intensityConfig.recommendedLoad) {
                return {
                    displayWeight: intensityConfig.recommendedLoad.value,
                    displayUnit: intensityConfig.recommendedLoad.unit,
                    displayText: text, // 同时保留相对强度文字
                    source: "recommended",
                };
            }

            return {
                displayText: text,
                source: "relative-text",
            };
        }
    }

    // 2. 使用推荐数值
    if (intensityConfig?.recommendedLoad) {
        return {
            displayWeight: intensityConfig.recommendedLoad.value,
            displayUnit: intensityConfig.recommendedLoad.unit,
            source: "recommended",
        };
    }

    // 3. 旧格式兼容：使用 legacyRm（原 params.强度）
    if (legacyRm && legacyRm > 0) {
        if (oneRM && oneRM > 0 && bodyWeight > 0) {
            // 使用现有的 calcRecommendedLoad 函数
            const alpha = includesBodyWeight ? 1 : 0;
            const calculatedWeight = calcRecommendedLoad(
                oneRM,
                bodyWeight,
                legacyRm,
                alpha,
                "average",
            );

            return {
                displayWeight: calculatedWeight,
                displayUnit: "kg",
                source: "calculated",
            };
        } else {
            return {
                displayText: `${legacyRm}RM`,
                source: "relative-text",
            };
        }
    }

    // 4. 无任何强度配置
    return { source: "none" };
}
```

## 向后兼容方案

### 数据层兼容

现有模板数据使用 `params.强度` 存储 RM 值，不做数据库迁移，在读取时自动兼容：

```typescript
// src/lib/intensityUtils.ts (新建)

import type { IntensityConfig } from "@/types/intensity";

/**
 * 将旧格式的 params 转换为新的 IntensityConfig
 */
export function normalizeIntensityConfig(
    params: any,
): IntensityConfig | undefined {
    // 新格式：直接返回
    if (params?.intensityConfig) {
        return params.intensityConfig;
    }

    // 旧格式：params.强度 是 RM 值
    if (params?.强度 && typeof params.强度 === "number") {
        return {
            relativeIntensity: {
                type: "rm",
                value: params.强度,
            },
        };
    }

    return undefined;
}
```

### 写入时的处理

新保存的模板使用新格式 `intensityConfig`，同时保留旧字段以兼容可能的老代码：

```typescript
// 保存时
const params = {
    组数: 5,
    次数: 5,
    intensityConfig: {
        relativeIntensity: { type: "rm", value: 5 },
        recommendedLoad: { value: 100, unit: "kg" },
    },
    // 兼容旧代码
    强度: 5, // 同步写入旧字段
};
```

## 待确认问题

> [!IMPORTANT]
> 以下问题需要讨论确认后再继续实施

### 1. 单位转换

- 系统内部统一使用 kg 计算，还是保持用户选择的单位？
- 学员体重和1RM可能使用不同单位，如何处理？
- 建议：内部统一 kg，显示时按用户偏好转换（1 lbs = 0.453592 kg）

### 2. 负数处理

- 负重动作计算结果可能为负数（体重已超过目标负重）
- 显示方案：
  - A. 显示负数（如"-5kg"），让学员理解需要减重
  - B. 显示0，并提示"当前体重已足够"
- 建议：采用方案B

### 3. 百分比精度

- 用户输入百分比是整数（如80）还是小数（如0.8或80.5）？
- 建议：整数，范围 1-100

### 4. 导入计划时的默认处理

- 外部计划包含具体重量（如"50kg"），导入时：
  - 仅设置 `recommendedLoad`
  - 不设置 `relativeIntensity`（教练后续手动添加）
- 是否自动识别可能是引号的动作并设置 `includesBodyWeight`？

### 5. RM 与 reps 的区分

- 模板中的 `次数`（reps）表示每组实际完成的次数
- 模板中的 `RM`（相对强度）表示能完成的最大次数对应的强度
- 通常 reps ≤ RM（如5RM强度做5次，或5RM强度做3次作为保留）
- 需要在 UI 中明确说明两者区别吗？

### 6. 显示优先级确认

- 有 `relativeIntensity` + 有 `recommendedLoad` + 无 1RM 时：
  - 当前设计：显示 `recommendedLoad` 的值 + 同时显示相对强度文字
  - 是否合理？
