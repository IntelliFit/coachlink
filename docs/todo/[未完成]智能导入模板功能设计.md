# 智能导入模板功能设计

> **状态**：未完成\
> **创建日期**：2025-12-26\
> **依赖**：强度描述系统扩展（已完成）

---

## 背景

教练需要从外部来源（如 Excel、文本文档、AI
生成的内容）快速导入训练计划模板，而不是手动一个个添加动作。每个教练的格式习惯不同，需要灵活的解析能力。

## 核心决策

- **AI 模型**：gemini-3-flash-preview（这才是最新模型，不要改）
- **流程**：两阶段（先创建动作，再生成模板）
- **动作处理**：自动创建不存在的动作

## 用户场景示例

### 示例 1：简洁风格

```
W1 D1 
70%rm  4*4  3组自重引体 rpe 双手悬挂力竭3组 组间60s 

D2
反握引体 70% 4*4 下半程引体3组自重 rpe9 拉力/推力的辅助项
```

### 示例 2：详细风格

```
**W1D1**
- 负重引体（底部暂停） 4组9次 (使用10-11RM的重量) (组休4-5分钟)
- 锤式弯举 3组8次
- 普通弯举 3组8次

**休息1天**
- 拉伸、松解、低强度有氧
```

## 两阶段流程设计

### 阶段 1：解析并创建动作

```
用户粘贴文本 → Gemini 提取动作列表 → 匹配现有动作 → 自动创建缺失动作 → 用户确认
```

**API 端点**：`POST /api/plan-lib/parse-actions`

**请求**：

```typescript
{
  text: string; // 用户粘贴的训练计划文本
}
```

**响应**：

```typescript
{
  actions: {
    name: string;
    matchedExistingId: string | null;
    needsAutoCompute: boolean;
    includesBodyWeight: boolean;
    attrs: string[];
    isNew: boolean;  // 是否需要新建
  }[];
}
```

### 阶段 2：生成结构化模板

```
基于已有动作库 → Gemini 生成周/天结构 → 用户预览确认 → 写入模板
```

**API 端点**：`POST /api/plan-lib/parse-template`

**请求**：

```typescript
{
  text: string;           // 原始文本
  actions: CoachActionRow[];  // 所有可用动作（含新建的）
}
```

**响应**：

```typescript
{
  weeks: number;
  daysPerWeek: 7;
  trainingDays: {
    weekIndex: number;
    dayIndex: number;
    type: 'training' | 'rest';
    actions: ParsedAction[];
    note?: string;
  }[];
}
```

## 强度解析规则

| 输入格式                   | 解析类型   | 结果示例                             |
| -------------------------- | ---------- | ------------------------------------ |
| `5RM` / `5rm`              | RM 模式    | `{ type: "rm", value: 5 }`           |
| `10-11RM`                  | RM 模式    | `{ type: "rm", value: 10 }` (取较小) |
| `70%` / `70%rm` / `80%1RM` | 百分比模式 | `{ type: "percentage", value: 70 }`  |
| `50kg` / `100lbs`          | 固定重量   | `{ value: 50, unit: "kg" }`          |
| `rpe9` / `RPE 8`           | 存入备注   | note 字段                            |
| 无强度描述                 | 不设置     | `null`                               |

## 组次解析规则

| 输入格式      | 结果               |
| ------------- | ------------------ |
| `4*4` / `4x4` | 4组4次             |
| `3组8次`      | 3组8次             |
| `8-12次`      | 8次（取较小）      |
| `总数30个`    | 特殊处理，存入备注 |

## 休息时间解析规则

| 输入格式      | 结果（秒）    |
| ------------- | ------------- |
| `组休4-5分钟` | 270（取平均） |
| `组间60s`     | 60            |
| `组休3分钟`   | 180           |
| 无描述        | 默认 180      |

## Prompt 设计

### 阶段 1：动作提取 Prompt

```
你是一个训练计划解析助手。

任务：从以下训练计划中提取所有独立的训练动作名称。

已有动作库：
${existingActions.map(a => `- ${a.name} (ID: ${a.id})`).join('\n')}

解析规则：
1. 提取每个不同的动作名称（去重）
2. 识别动作是否需要"自动计算重量"功能（基于是否有RM、百分比等强度描述）
3. 判断动作是否"包含自重"（如引体向上、臂屈伸、俯卧撑等）
4. 如果动作在已有动作库中存在（名称相似即可），记录匹配ID
5. 确定动作的属性：组数、次数、强度、休息时间

训练计划文本：
"""
${userInput}
"""

请严格返回以下 JSON 格式（不要添加其他内容）：
{
  "actions": [
    {
      "name": "动作名称",
      "matchedExistingId": "uuid 或 null",
      "needsAutoCompute": true,
      "includesBodyWeight": false,
      "attrs": ["组数", "次数", "强度", "休息时间"]
    }
  ]
}
```

### 阶段 2：模板生成 Prompt

```
你是一个训练计划解析助手。

任务：将以下训练计划解析为结构化的周训练模板。

可用动作库：
${actionsWithIds.map(a => `- ${a.name} (ID: ${a.id})`).join('\n')}

强度识别规则：
- "5RM" 或 "5rm" 或 "5-6RM" → 取较小值，type: "rm"
- "70%" 或 "70%rm" 或 "80%1RM" → type: "percentage"
- "50kg" 或 "50公斤" 或 "100lbs" → type: "fixed"
- 无强度描述 → intensityConfig: null

组次识别规则：
- "4*4" = 4组4次
- "3组8次" = 3组8次
- 范围如"8-12次"取较小值

休息时间规则：
- "组休4-5分钟" → 取平均值转秒
- "组间60s" → 60秒
- 无描述 → 默认 180 秒

训练计划文本：
"""
${userInput}
"""

请严格返回以下 JSON 格式（不要添加其他内容）：
{
  "weeks": 4,
  "trainingDays": [
    {
      "weekIndex": 1,
      "dayOfWeek": 1,
      "type": "training",
      "actions": [
        {
          "actionId": "匹配的动作UUID",
          "sets": 4,
          "reps": 8,
          "restSeconds": 240,
          "intensityConfig": {
            "relativeIntensity": { "type": "rm", "value": 5 }
          },
          "note": "备注信息（如 rpe9 等）"
        }
      ],
      "dayNote": "当天整体备注"
    }
  ]
}
```

## 数据结构定义

### ParsedAction

```typescript
interface ParsedAction {
  originalText: string;
  actionId: string;
  sets: number;
  reps: number;
  restSeconds?: number;
  intensityConfig?: IntensityConfig;
  note?: string;
}
```

### ParsedDay

```typescript
interface ParsedDay {
  weekIndex: number;
  dayOfWeek: number;
  type: "training" | "rest";
  actions: ParsedAction[];
  dayNote?: string;
}
```

## UI 流程

1. 模板编辑页添加"智能导入"按钮
2. 弹出对话框，提供大文本框
3. 用户粘贴训练计划文本
4. 点击"解析动作" → 阶段1
5. 显示动作列表预览：
   - ✅ 已匹配的动作
   - 🆕 将新建的动作
6. 用户确认 → 创建新动作
7. 点击"生成模板" → 阶段2
8. 显示模板预览（周/天结构）
9. 用户确认 → 写入模板
