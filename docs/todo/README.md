# CoachLink 规划与任务中心 (`docs/todo/`)

本目录是 CoachLink
项目的实施和规划中心。它将活跃的任务、功能设计和进度跟踪与通用的项目文档区分开来。

## 📂 目录结构

### 📝 [CHANGELOG.md](CHANGELOG.md) (变更日志)

**请先阅读此处。** 倒序记录了最新的代码变更、已完成的功能和修复。

### 🚀 Features (`features/`) - 功能规划

包含正在进行中的模块的设计文档、实施计划和需求说明。

- **[Chat System](features/chat/) (聊天系统)**: @提及功能, 即时通讯逻辑。
- **[Knowledge Base](features/knowledge-base/) (知识库)**: 学员端知识库规划。
- **[Plan System](features/plans/) (计划系统)**: 通用计划体系扩展 (饮食/有氧),
  自动续费逻辑。
- **[Social Features](features/social/) (社交功能)**: 好友系统, 分享卡片,
  动态/朋友圈。

### 🗄️ Archive (`archive/`) - 归档

过时或已完成的任务文档。

---

## 💡 如何使用

- **查看进度**: 阅读 `CHANGELOG.md`。
- **开始新功能**: 在 `features/<主题>/` 下创建新的规划文件。
- **查阅设计**: 导航至 `features/` 下的特定子文件夹。
