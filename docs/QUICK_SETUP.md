## ⚡ 5分钟启用真实邮件

### 步骤 1：获取免费 Resend API 密钥

1. 访问 [resend.com](https://resend.com) 注册账号（免费）
2. 进入控制台，点击 "API Keys" → "Create API Key"  
3. 复制生成的密钥（以 `re_` 开头）

### 步骤 2：在 Supabase 中设置环境变量

1. 登录 [Supabase Dashboard](https://supabase.com/dashboard)
2. 选择你的项目：`uhlqribpagvklpqmcqvo`
3. 进入 **Settings** → **Edge Functions**
4. 在 "Environment Variables" 部分添加：
   ```
   RESEND_API_KEY = re_your_api_key_here
   ```

### 步骤 3：重新部署函数（如果已部署过）

如果你之前部署过 Supabase Functions，需要重新部署：

```bash
npx supabase functions deploy send-email-code
```

### 步骤 4：测试

现在访问你的网站 `http://localhost:5176/`：
- 输入邮箱地址点击"获取验证码"
- **真实邮件将发送到你的邮箱！** 📬
- 不再只是显示在网页上
