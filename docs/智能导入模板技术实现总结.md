# 智能导入模板功能 - 技术实现总结

## 功能概述

使用 Gemini AI 从自由格式文本快速导入训练计划模板，支持两阶段解析流程。

---

## 架构设计

```
用户输入文本
    ↓
┌─────────────────────────────┐
│  阶段1: parse-actions API   │  ← Gemini 解析动作
│  - 提取动作名称              │
│  - 匹配现有动作库            │
│  - 识别新动作属性            │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│  用户确认动作                │  ← SmartImportDialog Step 2
│  - 可编辑动作名称            │
│  - 切换使用已有/新建          │
│  - 设置自动计算/含自重        │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│  batch-create-actions API   │  ← 批量创建新动作
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│  阶段2: parse-template API  │  ← Gemini 解析模板结构
│  - 解析周/天/动作            │
│  - 解析组数/次数/强度/休息   │
└─────────────────────────────┘
    ↓
导入到模板编辑器
```

## 遇到的 Bug 及解决方案

### 1. Gemini 模型名称错误

**错误**: `models/gemini-2.5-flash-preview-05-20 is not found` **原因**:
使用了过时的模型名称 **解决**: 改为 `gemini-3-flash-preview`

### 2. 数据库字段名不匹配

**错误**: `Could not find the 'includes_body_weight' column` **原因**:
数据库使用驼峰命名 (`includesBodyWeight`)，代码使用蛇形命名 **解决**: 修正为
`enableAutoWeightCompute` 和 `includesBodyWeight`

### 3. 休息日没有 actions 数组

**错误**: `Cannot read properties of undefined (reading 'map')` **原因**: Gemini
返回的休息日没有 `actions` 字段 **解决**: 使用 `(day.actions || []).map(...)`

### 4. attrs 为 null 导致 filter 失败

**错误**: `Cannot read properties of null (reading 'filter')` **原因**:
`currentAction?.attrs.filter(...)` 当 attrs 为 null 时仍会报错 **解决**: 改为
`(currentAction?.attrs || []).filter(...)`

### 5. 缺少 attrs 字段

**错误**: 同上 **原因**: 批量创建动作时没有设置 `attrs` 字段 **解决**: 添加默认
`attrs: ["组数", "次数", "强度", "休息时间"]`

### 6. dayIndex 索引不匹配

**错误**: `Cannot read properties of undefined (reading 'params')` **原因**:
SmartImportDialog 使用 0-based 索引，页面期望 1-based **解决**: 修改
`convertToTemplateDays` 使用 `dayIndex = i + 1`

### 7. params 字段名不匹配

**错误**: 导入后字段不显示 **原因**: 使用英文字段名 (`sets`, `reps`) 而非中文
(`组数`, `次数`) **解决**: 改为中文字段名与 action.attrs 对应

### 8. actionSet undefined 导致崩溃

**错误**: `Cannot read properties of undefined (reading 'params')` **原因**:
actionSets 或 actionSet 可能不存在 **解决**: 添加全面的防御性检查

## 关键代码片段

### Gemini API 调用

```typescript
// src/lib/gemini.ts
export async function callGemini(prompt: string): Promise<string> {
    const model = genAI.getGenerativeModel({
        model: "gemini-3-flash-preview",
    });
    const result = await model.generateContent(prompt);
    return result.response.text();
}
```

### 数据结构转换

```typescript
// SmartImportDialog.tsx - convertToTemplateDays
result.push({
    dayIndex: i + 1, // 1-based 索引
    type: "training",
    actionSets: parsedDay.actions.map((action, idx) => ({
        type: "no-filter",
        actionId: action.actionId,
        params: {
            "组数": action.sets, // 中文字段名
            "次数": action.reps,
            "休息时间": action.restSeconds || 180,
            "强度": action.intensityConfig?.relativeIntensity?.value,
            intensityConfig: action.intensityConfig || null,
        },
    })),
});
```

### 防御性检查

```typescript
// create/page.tsx - handleActionSetChange
if (!newDays[actualDayIndex].actionSets) {
    newDays[actualDayIndex].actionSets = [];
}

const actionSet = newDays[actualDayIndex].actionSets[setIndex];
if (!actionSet) {
    console.warn(`ActionSet not found`);
    return;
}

actionSet.params = { ...(actionSet.params || {}), ...(value as any) };
```

## 使用方式

1. 进入 **新建模板** 页面
2. 点击 **"智能导入"** 按钮
3. 粘贴训练计划文本
4. 按流程：**解析动作** → **确认动作** → **生成模板** → **导入**
