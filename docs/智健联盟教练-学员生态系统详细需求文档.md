# 智健联盟教练-学员生态系统详细需求文档

## 📋 项目概述

### 当前状态分析
基于代码审查，当前系统已具备：
- ✅ **用户认证系统**：支持学员、教练、管理员三种角色
- ✅ **教练申请审核流程**：从申请到管理员审核的完整链路
- ✅ **基础对话功能**：ChatService组件，支持文字、语音、图片、视频消息
- ✅ **教练主页雏形**：CoachProfilePage已有内容展示框架（但功能有限）
- ✅ **数据库基础表结构**：subscriptions、coaches、video_submissions等

### 系统目标
构建一个完整的**内容创作者经济**平台，让教练能够：
1. 发布专业内容（视频、文字、图片教程）
2. 与学员建立订阅关系
3. 提供分层次的付费服务
4. 进行一对一指导和群体互动

### 2.2 数据库表结构扩展
```sql
-- 教练订阅关系表
CREATE TABLE coach_subscriptions (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  student_id uuid NOT NULL REFERENCES users(id),
  coach_id uuid NOT NULL REFERENCES coaches(id),
  tier integer NOT NULL CHECK (tier IN (1, 2, 3)),
  status text DEFAULT 'active' CHECK (status IN ('active', 'paused', 'cancelled', 'expired')),
  start_date timestamptz DEFAULT now(),
  end_date timestamptz,
  auto_renew boolean DEFAULT true,
  monthly_price decimal(10,2) NOT NULL,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  UNIQUE(student_id, coach_id) -- 一个学员只能订阅一个教练的一个方案
);

-- 教练内容表
CREATE TABLE coach_contents (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  coach_id uuid NOT NULL REFERENCES coaches(id),
  title text NOT NULL,
  content text NOT NULL,
  content_type text NOT NULL CHECK (content_type IN ('text', 'video', 'image', 'live', 'plan')),
  media_urls text[] DEFAULT '{}',
  thumbnail_url text,
  required_tier integer DEFAULT 0 CHECK (required_tier IN (0, 1, 2, 3)),
  is_featured boolean DEFAULT false,
  tags text[] DEFAULT '{}',
  likes_count integer DEFAULT 0,
  views_count integer DEFAULT 0,
  comments_count integer DEFAULT 0,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now()
);

-- 内容互动表（点赞、评论）
CREATE TABLE content_interactions (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  content_id uuid NOT NULL REFERENCES coach_contents(id) ON DELETE CASCADE,
  user_id uuid NOT NULL REFERENCES users(id),
  interaction_type text NOT NULL CHECK (interaction_type IN ('like', 'comment', 'view')),
  comment_content text, -- 仅在interaction_type为comment时使用
  created_at timestamptz DEFAULT now(),
  UNIQUE(content_id, user_id, interaction_type) -- 防止重复点赞
);

-- 对话记录表
CREATE TABLE coach_messages (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  conversation_id uuid NOT NULL, -- 对话ID，用于分组消息
  sender_id uuid NOT NULL REFERENCES users(id),
  receiver_id uuid NOT NULL REFERENCES users(id),
  message_type text NOT NULL CHECK (message_type IN ('text', 'image', 'video', 'voice', 'file')),
  content text NOT NULL,
  media_url text,
  file_name text,
  file_size bigint,
  duration integer, -- 语音/视频时长（秒）
  is_read boolean DEFAULT false,
  created_at timestamptz DEFAULT now()
);

-- 创建索引
CREATE INDEX idx_coach_subscriptions_student ON coach_subscriptions(student_id);
CREATE INDEX idx_coach_subscriptions_coach ON coach_subscriptions(coach_id);
CREATE INDEX idx_coach_contents_coach ON coach_contents(coach_id);
CREATE INDEX idx_coach_contents_tier ON coach_contents(required_tier);
CREATE INDEX idx_content_interactions_content ON content_interactions(content_id);
CREATE INDEX idx_coach_messages_conversation ON coach_messages(conversation_id);
CREATE INDEX idx_coach_messages_time ON coach_messages(created_at);
```

## 九、技术难点与解决方案

### 9.1 实时通讯并发处理
**挑战**：同时处理大量在线用户的消息发送
**解决方案**：
- 使用Supabase Realtime进行WebSocket连接管理
- 实现消息队列机制处理高并发
- 消息分片和压缩减少带宽占用

### 9.2 内容权限控制
**挑战**：确保付费内容只能被对应等级订阅用户访问
**解决方案**：
- 数据库层面的RLS策略严格控制
- 前端组件级别的权限验证
- API接口双重验证机制

### 9.3 推荐算法实时性
**挑战**：为用户提供实时、准确的内容和教练推荐
**解决方案**：
- 构建用户行为实时分析pipeline
- 使用缓存机制存储计算结果
- 实现增量更新推荐模型

### 9.4 多媒体内容处理
**挑战**：大量视频、图片的上传、存储、转码
**解决方案**：
- 集成云存储服务(Supabase Storage)
- 实现自动视频转码和压缩
- CDN加速内容分发
