# 针对女性/小白/非硬核用户的产品价值与吸引力策略

## 1. 现状审视：我们现在的产品“太硬核”了吗？

通过阅读现有的 `docs/给刘三乐演示用法.md` 和
`docs/coach_plan_system_design.md`，CoachLink 目前的核心卖点（AI 导入、%1RM
自动计算、精准负荷管理）有着非常明显的**“硬核/竞技/学院派”**基因。

这种基因对于**力量举爱好者**或**严肃训练者**是“神兵利器”，但对于您提到的**“女性/小白/非硬核健身人群”**，可能会产生以下摩擦：

- **“1RM”的恐惧感**：小白用户（尤其是初学者女性）往往不知道也不敢测 1RM。
- **“精准”的压迫感**：她们可能并不追求“这一组必须是
  82.5kg”，而是追求“我今天练爽了/出汗了”。
- **“效率”的误解**：对于硬核用户，教练回消息快、讲重点是“专业”；但对于小白用户，教练如果不嘘寒问暖，只是冷冰冰丢过来一个
  Excel，会觉得“被冷落”。

## 2. 这部分用户的核心价值是什么？（意义在哪里）

您问到这部分用户的“意义”，其实在于**商业价值的底座**。

- **收入的基石**：在商业健身房或私教工作室，**80%
  的收入往往来自这部分“小白/养生/减脂”人群**，只有 20% 来自硬核铁粉。
- **高依赖性**：硬核大佬往往最后都“自己练”了，因为他们懂。**小白才最离不开教练**，因为她们缺乏安全感、自律性和专业知识。
- **情绪价值付费**：这部分用户与其说是为“技术”付费，不如说是为“陪伴、监督、鼓励”付费。

## 3. 如何构建吸引力？（产品调整建议）

为了吸引并留住这部分用户，我们需要在“硬核内核”外面包裹一层“温情/易用”的糖衣。

### A. 重新定义“进步” (Redefine Progress) —— 不仅仅是重量

**现状**：系统强调 PR（个人纪录）、重量提升。 **建议**：增加更软性的“成就系统”。

- **打卡连续性**：突出“连续运动天数”、“月度全勤奖”。小白最大的成就是“坚持”。
- **非训练指标**：加入**体重、围度（腰围/臀围）、体态照片**的记录与对比功能。对于女性用户，腰围少
  1cm 比深蹲多 10kg 更值得发朋友圈。
- **习惯养成**：在计划中加入“喝水”、“睡眠”、“饮食打卡”等轻量级任务，让她们觉得教练在全方位管着她。

### B. 降低认知门槛 (Lower Friction)

**现状**：%1RM、RPE。 **建议**：提供“傻瓜模式”。

- **RPE 的替代**：用“轻松”、“适中”、“力竭”等词汇替代 RPE 1-10。
- **重量建议**：如果用户没有 1RM
  数据，支持通过“上次训练重量”或“自重”来生成计划，不要强制要求输入极限数据。
- **视频演示的调性**：目前的演示如果都是硬核猛男，女性用户会害怕。建议支持上传（或预设）一些**更生活化、更亲和（甚至女性示范）**的动作库视频。

### C. 强化“被关注感” (Sense of Care) —— 既然是卖服务，就要这感觉

**现状**：强调主要为了以此来减少教练的重复沟通。
**建议**：利用节省下来的时间，做高价值的沟通。

- **自动化的“情绪价值”**：
  - 当用户完成一次训练，系统可以提示教练发送一句鼓励（甚至可以 AI 生成：“@用户
    今天的有氧完成得很棒，坚持就是胜利！”）。
  - **生理期关怀**：允许女性用户标记生理期，系统自动提示教练调整当周强度（或自动把训练日变为拉伸/瑜伽），这会让用户觉得**“非常贴心”**。
- **作业批改的仪式感**：教练的反馈不要只是“下背部收紧”，可以增加表情包、语音鼓励。

### D. 社交与分享 (Social & Aesthetic)

**现状**：数据卡片类似“训记”（硬核数据流）。 **建议**：做“更美”的分享卡片。

- **“Insta-worthy”
  设计**：分享卡片支持上传自拍作为背景，上面叠加精美的水印（“Day 25
  打卡”、“汗水不会骗人”）。
- **弱化数据，强化氛围**：对于部分用户，可以选择隐藏具体重量数字，只显示“完成了
  5 个动作，消耗 300 大卡”。

## 4. 总结：双轨制策略

不需要抛弃现在的硬核优势，而是采用**“双轨制”**：

| 特性     | 硬核模式 (Pro)     | 生活模式 (Lifestyle)       |
| :------- | :----------------- | :------------------------- |
| **目标** | 提升竞技表现 (1RM) | 改善体态、保持健康、减脂   |
| **度量** | 重量、容量、RPE    | 围度、体重、打卡天数、感受 |
| **沟通** | 极简、精准、技术流 | 鼓励、陪伴、生活化         |
| **视频** | 严格动作分析       | 氛围感、主要看有没有做错   |
| **分享** | 晒数据、晒 PR      | 晒自拍、晒坚持、晒汗水     |

**吸引力的核心在于**：告诉她们，CoachLink
不只是一个冷冰冰的记数器，而是一个**懂她生理周期、懂她爱美之心、能督促她坚持下去的“贴身管家”**。对于教练来说，这就是帮他**赚最容易赚的那份钱**的工具。
