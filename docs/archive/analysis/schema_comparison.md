## 📝 总结

### 主要发现

1. **表数量差异**：分支数据库比主数据库多2个表（主要是 `training_exercises`）
2. **字段缺失**：`coaches` 表在分支数据库中缺少2个字段
3. **索引不一致**：`coaches` 表缺少唯一索引约束
4. **文档差异**：主数据库文档更详细，包含历史记录和优化建议

### 核心问题

**分支数据库与主数据库结构不完全一致**，主要体现在：
- 旧表未清理（`training_exercises`）
- 新字段未同步（`coaches.profile`, `coaches.payment_qr_code`）
- 索引约束不一致（`coaches.user_id` 唯一索引）

### 建议

**优先同步分支数据库结构到主数据库的最新状态**，确保：
1. 删除已废弃的表
2. 添加新字段
3. 统一索引约束
4. 保持两个数据库结构一致
