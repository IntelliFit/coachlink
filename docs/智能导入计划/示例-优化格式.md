# 智能导入计划 - 优化格式版本

## 优化说明

根据智能导入功能的解析规则，对原始计划进行了以下优化：

1. **动作名清晰化**：移除强度、组次等描述，只保留动作名称
2. **组次明确化**：统一使用 "组数×次数" 格式
3. **强度标准化**：使用 "5RM"、"70%"、"50kg" 等标准格式
4. **休息时间明确**：统一使用 "组休X分钟" 或 "组间休息X秒"
5. **拆分复合动作**：将 "然后" 连接的动作用换行分开
6. **复杂逻辑备注化**：将无法结构化的逻辑放入备注
7. **休息日标准化**：使用 "休息1天"、"休息2天" 格式

## 格式优化要点总结

### ✅ 已优化的内容

1. **动作名标准化**：
   - "负重引体 5RM" → "负重引体 5RM"（动作名和强度分离）
   - "5公斤引体" → "5公斤引体"（保留重量前缀，系统会自动识别为"负重引体"）

2. **组次格式统一**：
   - "3×3" → "3组×3次"
   - "三组" → "3组"
   - "五组" → "5组"

3. **休息时间标准化**：
   - "组休 3分" → "组休3分钟"
   - "组间歇30秒" → "组间休息30秒"
   - "组间歇2分" → "组间休息2分钟"

4. **休息日标准化**：
   - "休一天" → "休息1天"
   - "休两天" → "休息2天"
   - "休息四五天" → "休息4-5天"

5. **复合动作拆分**：
   - "自重引体力竭然后双手悬垂力竭" → 拆分为两个独立动作行

6. **复杂逻辑备注化**：
   - "累积（极限个数×5）个" → 在备注中说明
   - "第一组降速临界点...循环三组" → 在备注中说明完整逻辑

### ⚠️ 需要注意的特殊情况

1. **累积训练**：系统会将"累积X个"识别为组数，但实际执行逻辑在备注中
2. **降速临界点**：作为备注保留，实际执行需要学员理解
3. **测试新极限**：作为独立动作或备注，需要手动处理
4. **同等数量弹力宽拉**：在备注中说明，可能需要创建新动作"弹力宽拉"

### 📝 建议

1. **导入后检查**：
   - 检查所有动作是否正确匹配
   - 确认累积训练的组数设置是否合理
   - 验证复杂逻辑的备注是否完整

2. **动作库准备**：
   - 确保以下动作已存在或会被创建：
     - 负重引体
     - 自重引体
     - 双手悬垂
     - 单手悬垂
     - 锤式弯举
     - 折刀撑
     - 弹力宽拉（可能需要新建）
     - 5公斤引体（可能需要新建或映射到"负重引体"）
     - 10公斤引体（可能需要新建或映射到"负重引体"）
     - 5公斤半程引体（可能需要新建）

3. **学员执行说明**：
   - 在计划描述中说明"累积训练"的执行方式
   - 解释"降速临界点"的含义
   - 说明"测试新极限"的测试方法
