## 智能导入计划（Smart Import）文档索引

这是一组面向研发/产品的文档，用于说明“智能导入计划”当前实现、稳定性与成本控制策略、以及未来升级（尤其是与**动作库共建生态**的联动）。

- `02-现有实现速览.md`
- `03-与动作库共建生态的联动.md`
- `04-与问卷条件筛选的关系.md`
- `05-测试用例规范与用例集.md`
- `06-LLM全流程门禁与文本修缮（规划）.md`
- `07-提示词设计-动作识别与属性抽取.md`

### 本文件夹内容说明

- **面向“稳定/成本”**：明确哪些规则必须做成确定性逻辑（不用 AI 猜），哪些可以交给 AI。
- **面向“升级”**：公共动作库上线后，智能导入默认只匹配“私有动作库”；公共库通过“一键加入/关联 canonical”间接提升命中率（不在导入链路里做公共库搜索）。
- **面向“测试”**：提供可持续扩展的用例组织方式（`cases/`），方便回归与对齐预期。

### 示例文件说明

本文件夹包含三个示例文件，用于演示和参考：

1. **`示例-优化格式.md`**
   - **职能**：展示如何将原始训练计划优化为智能导入可识别的格式
   - **内容**：包含优化说明、优化后的完整训练计划（12周）、格式优化要点总结
   - **用途**：供用户参考，了解如何格式化自己的训练计划文本以提高导入成功率
   - **特点**：Markdown 格式，包含详细的优化说明和注意事项

2. **`示例-可直接使用.txt`**
   - **职能**：可直接复制粘贴到智能导入功能的纯文本训练计划
   - **内容**：与 `示例-优化格式.md` 相同的训练计划，但以纯文本格式呈现
   - **用途**：用户可以直接复制此文件内容，粘贴到智能导入对话框中进行测试
   - **特点**：纯文本格式，无 Markdown 标记，适合直接使用

3. **`完整技术文档.md`**
   - **职能**：智能导入功能的完整技术文档（历史版本，已拆分为多个专题文档）
   - **内容**：包含业务场景、技术架构、核心流程、代码实现细节、稳定性保障、成本优化、功能升级方向等
   - **用途**：作为完整参考文档，适合需要全面了解技术细节的开发人员
   - **特点**：内容详尽，已拆分为多个专题文档（见上方“阅读顺序”），但保留完整版本便于查阅
