# 智健联盟平台项目总结文档

## 1. 项目概述

**智健联盟**是一个基于Supabase技术栈的现代化健身训练平台，专注于为用户提供专业的健身指导、个性化训练计划、社区互动和成就追踪。平台采用前后端分离架构，前端使用React + TypeScript，后端基于Supabase的PostgreSQL数据库和Edge Functions。

### 1.1 核心定位
- **专业健身社区**：连接健身爱好者与专业教练
- **个性化训练**：基于AI算法的个性化训练计划生成
- **成就系统**：完善的排行榜和成就追踪
- **教练服务**：提供多层次的教练订阅服务

### 1.2 技术特色
- **现代化架构**：React + Supabase全栈解决方案
- **AI驱动**：智能训练计划生成系统
- **灵活认证**：支持匿名和认证用户混合模式
- **实时互动**：基于WebSocket的实时聊天系统

## 2. 系统架构

### 2.1 技术栈
```
前端：
├── React 18.3.1
├── TypeScript
├── Vite (构建工具)
├── Tailwind CSS (样式框架)
├── Lucide React (图标库)
└── Supabase Client (数据访问)

后端：
├── Supabase (BaaS平台)
├── PostgreSQL 17 (数据库)
├── Deno Edge Functions (无服务器函数)
├── Row Level Security (行级安全)
└── JWT认证 (用户认证)

部署：
├── Vercel/Netlify (前端部署)
├── Supabase Cloud (后端服务)
└── CDN (静态资源)
```

### 2.2 核心模块
1. **用户系统**：注册、登录、个人资料管理
2. **教练系统**：教练认证、服务管理、学员管理
3. **训练系统**：AI训练计划、自定义计划、进度追踪
4. **社区系统**：排行榜、视频分享、成就系统
5. **订阅系统**：多层级教练订阅服务
6. **管理系统**：管理员后台、内容审核

## 3. 功能详解

### 3.1 用户认证系统
- **认证方式**：手机号 + 密码登录
- **注册流程**：手机号验证 → 密码设置 → 个人资料完善
- **权限管理**：基于RLS的行级安全控制
- **匿名支持**：支持匿名用户提交记录后认领

### 3.2 教练服务系统
- **教练申请**：完整的申请→审核→认证流程
- **三角色管理**：学员、教练、管理员身份切换和权限控制
- **申请审核**：管理员可审批教练申请，支持批准/拒绝
- **状态管理**：pending→approved/rejected的状态流转
- **服务内容**：
  - 视频动作点评和反馈
  - 专业训练指导
  - 学员进度跟踪
  - 教练工作台管理

### 3.3 训练计划系统
- **AI生成**：基于用户偏好和水平的智能计划
- **个性化**：考虑用户目标、水平、器材等因素
- **动态调整**：根据训练反馈自动优化
- **数据追踪**：完整的训练记录和进度分析

### 3.4 社区互动系统
- **引体向上排行榜**：基于相对力量的专业排名
- **视频分享**：训练视频提交和教练点评
- **成就系统**：多维度成就徽章和积分奖励
- **社交功能**：用户间互动和经验分享

### 3.5 管理后台
- **记录审核**：引体向上成绩的人工审核
- **用户管理**：用户信息和权限管理
- **内容管理**：训练计划和课程管理
- **数据分析**：用户行为和平台数据统计

## 4. 数据库设计

### 4.1 核心表结构
```sql
-- 用户基础信息 (15个字段)
users (
  id, phone, password_hash, has_drawn, subscription_level, subscription_expires_at,
  is_admin, admin_role, admin_permissions, is_coach, coach_status, primary_role,
  created_at, updated_at, last_login_at
)

-- 用户详细资料 (16个字段)
user_profiles (
  id, user_id, full_name, nickname, avatar_url, gender, birth_date, height, weight,
  fitness_goal, fitness_level, bio, phone, address, created_at, updated_at
)

-- 教练信息 (15个字段，含user_id外键)
coaches (
  id, name, title, avatar_url, specialties, bio, rating, total_students,
  years_experience, achievements, is_featured, user_id, status,
  created_at, updated_at
)

-- 训练计划 (11个字段)
training_plans (
  id, user_id, coach_id, title, description, difficulty_level, duration_weeks,
  ai_generated, coach_reviewed, created_at, updated_at
)

-- 练习动作 (13个字段)
exercises (
  id, training_plan_id, name, category, description, sets, reps, rest_time,
  video_url, image_url, tips, order_index, created_at
)

-- 引体向上排行榜 (18个字段，支持匿名和认领)
pullup_leaderboard (
  id, user_id, weight_kg, video_url, douyin_nickname, claim_code, is_claimed,
  gender, notes, submission_status, submitted_by, submitted_at, reviewed_by,
  reviewed_at, admin_feedback, is_user_submission, created_at, created_by
)

-- 视频提交 (10个字段)
video_submissions (
  id, user_id, exercise_id, video_url, description, status, coach_feedback,
  coach_rating, submitted_at, reviewed_at
)

-- 管理员用户 (6个字段)
admin_users (
  id, user_id, role, permissions, created_at, created_by
)

-- 快递信息 (11个字段，支持中奖商品配送)
shipping_info (
  id, user_id, prize_id, recipient_name, phone, address, notes, status,
  tracking_number, created_at, updated_at
)
```

### 4.2 关键特性
- **关系设计**：1:1用户资料、1:N训练计划、1:N视频提交
- **索引优化**：基于查询模式的关键字段索引
- **数据完整**：外键约束和级联操作
- **安全策略**：完善的RLS权限控制

## 5. API接口设计

### 5.1 Edge Functions API端点
基于Supabase Edge Functions的后端API，当前部署了**20个**活跃函数：

```
# 用户认证相关
POST /auth-with-password          # 密码登录认证
POST /register-with-phone         # 手机号注册
POST /update-profile              # 更新用户资料

# 训练计划相关  
POST /generate-ai-plan            # AI生成个性化训练计划
POST /get-training-plans          # 获取用户训练计划
POST /create-training-plan        # 创建自定义训练计划

# 视频提交与审核
POST /submit-video                # 提交训练视频
POST /get-user-videos             # 获取用户视频列表

# 引体向上排行榜
GET  /get-pullup-leaderboard      # 获取排行榜数据
POST /submit-pullup-record        # 提交引体向上记录
POST /claim-leaderboard-record    # 认领排行榜记录
POST /admin-add-unclaimed-record  # 管理员添加未认领记录
POST /review-pullup-submission    # 审核用户提交
POST /get-user-submissions        # 获取用户提交记录
POST /get-pending-submissions     # 获取待审核提交

# 教练系统  
POST /apply-coach                 # 申请成为教练
POST /admin-review-coach          # 管理员审核教练申请
POST /get-coach-applications      # 获取教练申请列表

# 其他功能
POST /update-lottery-status       # 更新抽奖状态
POST /save-shipping-info          # 保存快递信息
```

### 5.2 认证机制
- **自定义认证**：基于手机号+密码的SHA-256哈希认证系统
- **多层权限**：学员、教练、管理员三级权限体系
- **灵活认证**：支持认证用户和匿名用户混合使用
- **记录认领**：匿名记录通过认领码绑定到认证用户
- **数据安全**：密码加盐哈希、敏感信息加密存储
