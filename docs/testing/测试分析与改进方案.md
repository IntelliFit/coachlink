## 🧪 如何运行和检验测试

### 运行单元测试
```bash
# 运行所有单元测试
npm test

# 监听模式（开发时使用）
npm run test:watch

# 生成测试报告
npm run test:report
```

### 运行E2E测试
```bash
# 运行所有E2E测试
npm run test:e2e

# 运行特定测试文件
npx playwright test e2e/b1-subscription.spec.ts

# 以UI模式运行（调试用）
npx playwright test --ui

# 查看测试报告
npx playwright show-report
```

### 运行前准备
1. **确保开发服务器运行**：Playwright会自动启动（通过 `webServer` 配置），但也可以手动运行：
   ```bash
   npm run dev
   ```

2. **环境变量**：确保设置了必要的环境变量（Supabase URL、密钥等）

3. **数据库**：E2E测试会创建和删除测试数据，确保使用测试数据库或开发数据库

### 方案2：在CI/CD中集成E2E测试

修改 `.github/workflows/test.yml`，添加E2E测试步骤：

```yaml
- name: Run E2E Tests
  run: npm run test:e2e
  env:
    E2E_SECRET: ${{ secrets.E2E_SECRET }}
    # 其他必要的环境变量
```

### 方案3：创建上线前测试清单脚本

创建一个脚本，在上线前运行所有关键测试：

```bash

# 1. 运行单元测试

# 2. 运行E2E测试

# 3. 检查环境变量
echo "🔐 检查环境变量..."
node scripts/check-env.js || exit 1

echo "✅ 所有检查通过，可以上线！"
```
