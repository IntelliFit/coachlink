## 版权边界

- 现代书只发布 CoachLink 原创解释、决策框架和自绘思维导图。
- 不上传电子书原文件，不提供下载，不复制原书插图、表格、完整训练模板或长段正文。
- 正式引用需回到正版书核对作者、版本、出版社和页码。
- 《黄帝内经》只同步公版古籍原文，并保留来源与版本说明；不抓取现代翻译或现代注释。
- 导入接口会移除本机 `originalFilePath`，客户端只获得可公开的来源元数据。

## 可重复生成

```bash
npm run knowledge-books:bootstrap-classics -- --force
npm run knowledge-books:sync-neijing -- --force
npm run knowledge-books:import -- --all-workspaces --summary
```

最后一条默认为 dry-run。只有明确确认数据库目标后，才增加 `--apply`。
