# 单杠恢复文字优先录入（2026-10-03）

用户核对旧版本事实后选择恢复原思路，要求在界面讲清文字和地图分工。本轮只在本地修改，不延用上一轮1031体验包上传授权；未提交、推送、上传或更新服务器，不改真实历史点位。

## 用户流程

1. 打开分享表单，默认地点在中国；海外地点才展开国家/地区输入与选择。
2. 填名称、地区、详细地址/找路说明，例如“学院路学知园，北门进入后右转，篮球场旁边”。名称必填，地区/详细地址与旧版一样可选填。
3. 点击“在地图上标记位置”，搜索附近地点后确认单杠实际位置。国内优先微信chooseLocation；取消保持文字，非取消失败自动转现有地图选点；海外现有地图支持地名搜索/地图点击/地图中心标记。搜到公园只确定附近区域，必须由用户确认实际单杠。
4. 选点/重新选点只保存纬经度及坐标系，名称/国家/地区/详细找路文字全部保留。系统自动记录坐标，用户无需输入经纬度。
5. 提交；地图不可用仍可保存文字记录。未标记的位置只显示列表，没有坐标不能自动出现在地图或用该点导航，界面已明确说明。国家变化清空旧坐标，要求重新标记，避免把旧国家位置带到新地点；手填文字保留。

这不是完全回滚旧代码：旧微信选点曾自动补名称/覆盖地址，新流程按用户选择让详细文字由人填写、选点仅记录位置。1031“强制地图先选→Photon地址回填”已移除，选点页不再反查地址、等待识别或承诺自动得到详细地址；海外搜索依旧可以显示搜索结果名称，但不会拿其英文地区覆盖表单。
