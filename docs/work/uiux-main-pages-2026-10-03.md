# CoachLink 微信小程序 UI/UX：五个一级页面

这轮建议基于自动点击和截图。使用同一学员登录态，在真实小程序中完成“训练 → 教练 → 知识 → 工具箱 → 我的”；两轮重复后又独立验证了自动启动到截图。没有修改产品 UI、伪造业务数据或进行训练/支付写入。全部截图与复跑方式见 [自动化验收](weapp-ui-automation-2026-10-03.md)。

总体判断：暖色品牌与卡片语言已有基础，主要问题是各页层级和密度不一致、信息状态不够准确，以及大段说明占据了原本可给用户操作的空间。优先统一导航与标题、区分“尚未加载”和“确实为零”，再优化卡片内容。无需先换一整套配色。

| 步骤 | 页面与实测健康情况 | 优先级最高的改进 |
| --- | --- | --- |
| 1 | 训练：首页可见、入口可操作；当前没有执行中的长期计划 | 收拢重复空状态，明确开始自由训练与使用已保存计划 |
| 2 | 教练：可自动进入，实际列表加载十位教练 | 澄清评分、突出专项和服务风格，提升筛选可发现性 |
| 3 | 知识：计划与文章可读、导航成功 | 减少长摘要，让三个内容分类都容易被发现 |
| 4 | 工具箱：真实图片加载、底部入口有效 | 常用工具优先，减少占位入口与上方大标题的空间 |
| 5 | 我的：最终统计为 13/3/11；首轮加载时先显示零 | 加载状态正确表达，菜单分组，统一统计标题和单位 |

## 1. 训练首页

![训练首页](D:/files/coachlink/artifacts/uiux-audit/2026-10-03/final-unattended/01-pages-index-index.png)

主按钮明确、品牌色集中，这是可以保留的基础。现在“还没有长期计划”在大卡片、副说明和下方状态里重复；页面下半部分大面积空白，但真正有用的已保存计划、近期训练或训练快捷入口没有出现在这里。

- P1：统一“自由训练”和“即兴锻炼”的名称。建议主按钮叫“开始自由训练”，副入口叫“我的计划库”；仅在没有执行中计划时提供一句简洁说明。
- P1：圆形勾号容易让人理解为已完成，当前却是“未开始”。换为与开始训练一致的状态图形；开始、进行中和已完成分别表达。
- P1：已保存计划与执行中计划应区分。当前我的页显示三项计划库，不应只通过“没有长期计划”让用户以为计划不存在。
- P2：找教练和计划库的灰色文字/图标较弱。统一副按钮的白底、清楚边框与文字，控制主卡片内行动数量。
- P2：下方区域优先放最近一次训练或已有计划入口，避免再放一条重复空状态；真实没有数据时再用轻量引导。

## 2. 教练

![教练列表](D:/files/coachlink/artifacts/uiux-audit/2026-10-03/final-unattended/02-discovery-index.png)

搜索和专项标签有基础，列表比大封面更便于比较。上方标题、说明、搜索和推荐区占据较多空间；多位教练显示“0.0”，容易被理解为很差的服务质量。

- P1：确认“0.0”的业务含义。若表示尚无评价，显示“暂无评价”；已有评价则显示分数及评价数，避免将缺失数据展示为零分。
- P1：每张卡片保留名称、最关键的两个专项，以及一条可核验的服务/经验摘要。只靠名字、头像和标签不足以支持选择。
- P2：把“筛选方向”做成明显的筛选控件；当前小灰字较难发现。选中后显示筛选标签并提供清除。
- P2：缩短“这里只做找教练”等泛说明，把首屏空间用于比较教练；标题字号与其他主页面统一。
- P2：标签过长时不要挤成一整行，明确显示最多两项与“更多”；卡片可点击性可用轻量箭头或“查看主页”表达。

本轮只验证了列表和导航，教练详情、沟通与订阅尚未实际走完；不能据此评价完整选教练链路。

## 3. 知识库

![知识库](D:/files/coachlink/artifacts/uiux-audit/2026-10-03/final-unattended/03-content-knowledge.png)

计划、文章和书籍的分区方向清楚，横向计划卡也能在有限空间展示处方概况。但第一篇文章摘要约占五行，书籍分区被推到更深处；顶部原生标题与正文大标题重复。

- P1：保留统一搜索，用三个清楚入口或可定位的分类标签呈现“训练计划 / 精选好文 / 书籍笔记”。分类状态与当前内容要一致。
- P1：文章卡片摘要限制为两行，保留标题、作者和必要元信息。把更多阅读空间留给详情页，让首页能展示更多选择。
- P1：计划选择优先呈现训练目标、适用水平、每周频率和周期；卡片有明确的适用对象，用户才能判断是否适合自己。
- P2：去掉重复的大标题，统一与教练、工具箱的首屏导航样式。
- P2：计划横向区域要有清楚的可滑动提示或位置指示，完整列表入口保持一致位置。

截图中的内容数量来自实际运行，不把它们当作长期固定值；没有验证搜索结果与每个详情页的可用性。

## 4. 工具箱

![工具箱](D:/files/coachlink/artifacts/uiux-audit/2026-10-03/final-unattended/04-toolbox-index.png)

图片有较强识别度，计算、分析、地图和小游戏已经分组。顶部的多层标题与解释仍偏多；“亟待开放”占据一个完整卡片，和可用工具有相似视觉权重。

- P1：按真实使用频率提供最近使用/常用入口。计算器与功率分析等高频任务不应每次都先经过大段介绍。
- P1：暂不可用工具采用清楚的禁用状态或简短“即将开放”，不占用与可用工具相同的主位置；不要让用户误以为可以进入。
- P2：压缩“训练辅助 / 工具箱 / 工具数量 / 介绍 / 常用工具 / 副标题”的层级，保留一个主标题与一行介绍即可。
- P2：图片卡片增加一句简短用途或必要前提，例如“上传训练视频”或“填写重量与次数”，帮助用户知道进入后要做什么。
- P2：小游戏保留独立分区；相机授权和兼容提示应在需要使用相机时说明，而非用大量首页文案预先讲解。

本轮未进入相机、未上传视频、未触发分析任务，不声称工具的全流程或真机性能已验证。

## 5. 我的

![我的](D:/files/coachlink/artifacts/uiux-audit/2026-10-03/final-unattended/05-me-profile-index.png)

三项训练资产放在顶部，用户可快速看到自己的积累。首轮进入时三项先显示零，后续截图变成 13/3/11；这是加载状态表达问题，不能把初始零值当成真实空账户。

- P1：加载时显示占位或上次成功值，直到实际请求返回才显示统计。失败时明确“暂不可用”，不使用零值代替。
- P1：“训练记录”的单位是“个动作”。若统计的是已练动作，则把标题改成“已练动作”；训练次数另用“次训练”，避免把 11 个动作误读为 11 次训练。
- P1：菜单按“训练资产 / 教练与消息 / 账户与帮助”分组。当前排行榜、权益、消息、购买记录和内测入口混在同一长列表。
- P2：编辑资料与积分分开，主题切换提供可理解的标签；手机号可按实际展示需求隐藏中间位。
- P2：菜单“免费权益”与已确认的“功能与用量”名称不一致，应以最新产品口径统一构建与实际显示；当前截图仍是旧名称，尚未实施修复。
- 待验证：浮动导航覆盖了首屏底部部分账户设置行。需要实际滚到底部检验可达性，不能仅凭这一帧断言入口永久被遮挡。

## 共用规范与后续范围

优先统一五页的顶部导航、标题字号、正文/辅助文字层级、卡片内外间距和底部安全区。品牌按钮保持纯色 `#CF6D4E`，副按钮白底边框，布局继续遵守 8rpx 栅格。已有暖色品牌、照片资产和圆角卡片可以保留。

截图能够提示灰色小字与触控目标的可读性风险，但本轮没有量化对比度、读屏语义或真机大字号，不能宣称完整无障碍合规。

当前覆盖五个一级页面；计划库、训练记录、执行详情、资料编辑、知识详情、教练权限页及工具深层页面仍待实际采集。该报告是本轮已验证部分，不代表全部 124 个注册路由或 Web/App 已审查。自动截图阻塞已经解除，后续无需用户逐页参与。
