上一份12周：前4周B为超负荷离心、4秒离心、高位；中4周B换90°暂停；后段B换爆发引体、高位；A/C为底部暂停主项，前段配锤式弯举、海豹划船，最后两周减少辅助并测试。新稿保留这种变式分段使用的脉络，承接已有动作经验，而不是把全部变式同时堆进每次课。

第1～8周A/C参考枭马葛《8周引体计划改良版-改进前4周》（e03c8c6a）；C原7～8RM统一取8RM。B不再称原八周模板照搬，改为依据上份专项的慢离心→中段暂停安排。第10～14周A/C参考本人《15周计划-纯引体》（d498147f）的重三次、双次、单次与降重层次。

刘三乐《引体负重提升计划》（0a469e73）本身使用RM，含4～5RM三次组、7～8RM容量组，以及3RM重量的顶端保持3～6秒＋慢离心；还含反手、宽窄握、半程、握力、推举/折刀撑。《引体负重30–70kg》（71eff3ae）含顶端保持3～5秒、慢离心、全程＋半程、多组及测试安排。新稿实际取用重组后降重、顶端保持加慢离心、划船/锤式弯举及减量测试，明确列为个人适配。

刘RM版后段有6RM重量做30～33组×3次、1RM重量静力到极限，以及大量扣腕悬挂；30～70版也有20×3全程加半程。本人近期记录缺视频与主项余力，无法证明已耐受这些峰值，故本稿不照搬该体量。反手/宽窄握/半程和额外推举暂不列入必做，以正手全程主项、一个阶段变式及少量辅助完成本周期目标；没有凭空认定背部、握力或某个角度是其短板。

超负荷纯离心本轮暂不安排：它是借凳到顶端、只做4～5秒下放，与完整拉起后4秒下放不同；旧计划确实做过，但缺控制视频与当前疼痛反馈。普通动态RM不足以直接确定纯离心耐受，不能写成“超负荷3RM”就视为定重完整。这是删减建议，不声称教练原模板要求删掉。

本稿以枭马葛的RM主项结构和学员既有专项为主，刘三乐提供部分方法补充。不能说两个完整模板各取一半，也不能把自编的剂量称为原作者处方。

训练思路是先提高同标准多组工作能力，再加强较重双次和单次表现，最后减少训练量以准备测试。正手全程主项贯穿周期，变式按阶段服务主项。前八周量并非单调上升；第二段第11周A为4RM：5×3＋6RM：2×4（7组、23次），第14周A为2RM：1×1＋4RM：3×2（4组、7次），让较重负荷接触与降低总量同时发生，而不是加重后继续叠组。

慢离心的设计用途是练受控下放，中段暂停是练该位置停住后继续上拉，爆发课是练快速上拉意图，顶端保持是练终点稳定。这些是训练用途，不是已诊断的个人短板；没有卡点视频就不能证明四种方法他都需要。熟悉某变式也不证明这个新剂量最合适。

目前最需验证的是B课的变式剂量和恢复影响，尤其慢离心、双暂停及高位同课可能有功能重叠。首周记录各动作质量以及后续A/C是否受影响；若B后恢复下降、主项连续受影响，先减少B的额外双暂停或高位组，不为保住模板内容牺牲主项。第9周恢复是预设管理点，并非身体一定在该周疲劳；调整规则以实际反馈为准。来源可追溯和周期结构合理，不能替代个人执行验证。

## 动作标准与RM口径

9RM重量做5组×7次，表示该动作按规定节奏、行程约可做9次的重量，工作组只做7次。各变式和辅助独立标定，不共用47.5；慢离心RM必须包含每次4秒下放，90°RM必须包含中段暂停。底部、顶端及90°暂停的1秒，是本稿新增的统一执行标准，不冒称源备注原本规定了1秒。

爆发动作的RM用于完整行程选重，快速上拉要求另看实际质量；低次数避免持续磨慢。高位按相同上胸目标高度的动作定RM：若自重不能满足所列档位，使用弹力带或器械助力并记规格；不是拿普通引体8RM直接给高位加重。顶端静力的负荷单独写明采用正手底部暂停引体的4/5RM重量，保持次数及秒数另列，不伪造静力“4次最大”。

| 动作 | 本稿执行标准 |
| --- | --- |
| 正手负重引体：底部暂停 | 底部伸肘、肩部受控，静止1秒再拉；下巴确实过杠，下降受控，不摆腿借力。 |
| 正手负重引体：底部＋顶端双暂停 | 底部静止1秒；拉过杠后顶端保持1秒，再受控下降。 |
| 4秒离心负重引体 | 从底部完整拉起，再用4秒均匀下放至伸肘；不是借凳上去只做下放。 |
| 90°暂停负重引体 | 上拉到肘约90°停1秒，随后继续拉过杠；下降受控。 |
| 爆发负重引体 | 底部先停稳，再以最大速度意图拉起；完整过杠、受控下放；第二次明显变慢就停止该组。 |
| 高位引体：必要时助力 | 完整悬垂起拉，目标上胸靠近杠；不靠摆动踢腿。按同一目标高度的RM选自重或助力，不强行挂重。 |
| 正手顶端静力维持 | 借凳到顶端，保持下巴过杠3秒，再用约3秒受控下放；每组只有一次保持，不做动态拉起。 |
| 哑铃锤式弯举 | 中立握，大臂稳定，完整屈伸；下降约2秒，不摆身体。 |
| 海豹划船 | 胸部支撑卧凳，拉向腹部，顶端停1秒；完整伸臂，不抬胸借力。 |

每课先做5～10分钟轻活动与肩肘活动，再用该日首个负重动作的12RM档位1×5、8RM档位1×3递增热身；当日第一工作组为4RM或更重时，再用5RM档位1×1，2RM重单次前可补3RM档位1×1。热身各休1～3分钟，重组前休3～5分钟；可按当天状态减少不必要阶梯，热身不做到力竭。

## 加重、停止与复盘

首周依据同动作历史工作组保守选重，用热身和第一工作组校准，不连续测不同RM极限；表里RM不是精确数学承诺。9RM×7通常约留两次，4RM×3或2RM×1约留一次，多组后余力会变，不能为凑组数做变形重复。同动作连续两次完成规定组次、节奏和行程且余力增加，再按最小可用挂片加重；不得按周自动增加公斤。后组失去标准时延长组休，仍不行则略减实际负荷或少一组并记录。爆发/高位下降到不能维持速度或高度时当组停止，不用慢次数补满。

肩肘疼痛目前未知；出现或加重时停掉诱发疼痛的动作，让教练复核。连续两次课恢复明显下降，可以提前用第9周轻课替换当周，不增加总周期、不把省掉的量挤回后面。每课记录实际外挂/助力规格、当天体重、各组次数、暂停与离心节奏、余力和不适；A重组与C末组、B变式各留侧面视频，才能判断动作与实际耐受。

目标是同标准下稳定已有成绩，再观察50/52.5kg是否可达，不承诺按表必涨。第15周去掉静力和辅助；测试前不额外加握力、攀岩或其他高疲劳拉力练习。
