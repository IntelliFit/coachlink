# 批量操作功能 - 快速启动指南

## 功能简介

通过自然语言描述来批量修改训练计划模板,实时查看处理过程。

## 快速开始

### 1. 访问功能

1. 以教练身份登录系统
2. 进入"计划库"页面: `/dashboard/plan-lib`
3. 在任意训练计划卡片上找到⚡闪电图标
4. 点击图标打开"批量操作"对话框

### 2. 输入指令

在对话框中输入自然语言指令,例如:

```
把所有引体向上类的动作都替换为有氧
```

### 3. 执行操作

1. 点击"执行"按钮
2. 实时观察处理过程:
   - 📊 加载训练计划和动作库
   - 🤖 AI 分析指令
   - 💻 生成并执行代码
   - ✅ 保存修改

### 4. 查看结果

操作完成后,可以:
- 点击"编辑"查看修改详情
- 立即应用模板到学员

## 常用指令示例

### 替换动作
```
把所有引体向上替换为跑步
```

### 修改参数
```
把所有深蹲的组数改为5组
把所有卧推的重量改为80kg
```

### 删除内容
```
删除所有休息日
删除所有有氧运动
```

### 批量设置
```
给所有训练日添加备注"注意热身"
把所有力量训练的休息时间改为90秒
```

### 组合操作
```
把第1天和第2天的深蹲改为5组8次,并把重量改为100kg
```

## 技术特点

- ⚡ **实时反馈**: SSE 流式传输,实时看到处理过程
- 🔒 **安全隔离**: 代码在独立虚拟机中执行
- 🎯 **智能理解**: DeepSeek AI 理解自然语言
- 📝 **过程透明**: 显示生成的代码,可以学习和验证

## 注意事项

1. **明确指令**: 指令越具体,效果越好
2. **动作匹配**: 确保动作库中存在要替换的动作
3. **预览修改**: 操作后建议查看详情确认结果
4. **无法撤销**: 修改会立即保存,建议先复制模板再操作

## 限制

- ⏱️ 执行超时: 10秒
- 💾 内存限制: 128MB
- 👤 权限要求: 仅教练可用
- 📋 范围限制: 单次只能操作一个模板

## 故障排除

### 问题: 找不到批量操作按钮

**解决**: 
- 确认已登录为教练角色
- 在计划库页面的训练计划卡片上查找⚡图标

### 问题: 执行失败

**可能原因**:
- 指令不够明确
- 动作库中没有匹配的动作
- 网络连接问题

**解决**:
- 重新措辞指令
- 检查动作库
- 刷新页面重试

### 问题: 修改不符合预期

**解决**:
- 查看生成的代码理解 AI 的理解
- 改写指令使其更具体
- 或手动编辑训练计划

## 进阶用法

### 查看生成的代码

对话框会显示 AI 生成的 TypeScript 代码,你可以:
1. 学习如何编程修改训练计划
2. 验证操作是否符合预期
3. 发现新的操作可能性

### 辅助函数

系统提供了两个辅助函数:
- `findActionByName(name)`: 模糊查找动作
- `findActionById(id)`: 精确查找动作

### 数据结构

了解 trainingDays 的结构可以帮助你更好地使用:
```typescript
{
  type: 'training' | 'rest',
  note: string,
  actionSets: [
    {
      actionId: string,
      params: {
        action_name: string,
        sets: number,
        reps: number,
        weight: number
      }
    }
  ]
}
```
