# kk 原计划动作与顺序审阅

## kk 原计划动作解释与顺序复核（2026-10-07，只读审阅）

- 用户要求列出全部动作，解释陌生名称（尤其仰卧中空支撑）并评估顺序/相互影响；本轮没有授权改计划，未写业务数据或重排动作。原文与已录入回读一致：16个正式动作，另外快走/固定自行车为休息日可选，脚踩箱支撑是倒立替代。所有动作名来自附件，不是录入时额外添加。
- 仰卧中空支撑为Hollow Body Hold：仰卧腰背贴地、收腹、肩背和腿离地静态保持；中文直译不好理解。建议易懂名称为“仰卧收腹静止保持（Hollow Hold）”，其它技能加直白解释；只是建议，未实际改名。
- 审阅判断：引体/双杠优先、重组在降重组前、辅助与核心后置、12周评估主项前置，符合以引体双杠增力优先的编排；深蹲/硬拉/推举相对次要。潜在问题是技能在较长力量课后、周三四上肢关节重复使用、双杠+推举+侧平举+倒立的肩部负荷，以及周六推拉后又倒立/俄挺。15分钟休息不自动保证疲劳消除，低RPE辅助练习可保留，但新技能学习或高负荷静态必须结合真实水平/视频判断，不能仅凭力量年限断言适配。
- 量化：W1引体含反手13组/双杠13组；W3、W4各15组，另外划船/弯举/技能另计。W6周六仅累计规定组间休息+单组前导后休息+技能前15分钟约75分钟，未含热身/动作时间/换器械。没有把这些组数或时间说成过量或必然伤病。
- 资料依据：Nunes等动作顺序系统综述(https://pubmed.ncbi.nlm.nih.gov/32077380/)支持优先目标先做；Branscheidt等(https://pubmed.ncbi.nlm.nih.gov/30832766/)是捏握运动学习实验，疲劳影响技能学习，不能直接证明此12周技能安排有害；CrossFit官方Hollow Hold与体操资料支持动作含义。建议少量新技能在清醒状态练习、技能分阶段而非同时赶四项，需用户确认具体调整后再改。线上RM重量规则仍按用户最新选择。
