## 3. 原计划值得保留什么，下一步调整什么

原方法已有合理结构：底部暂停统一起拉、顶端暂停培养结束位置控制、重单次保留高负荷接触、回退组积累训练、技术日安排变化，专项 W4/W8/W12 有减量。无需因为“高阶”就重新堆一套陌生动作。

我的编排建议是先补回容量，再提高重负荷表现。上一阶段后半程越来越多单次、双次，划船与弯举在后段退出，符合冲刺用途；连续复制冲刺结构，长期积累的刺激会偏少。此处是对处方结构的判断，不是证明他的肌肉量不足。

下一阶段主项保持同一种严格正手口径。若 47.5kg 是底部暂停成绩，就将底部短暂停作为测试与主项共同标准；若是普通严格引体成绩，普通严格引体作主项，暂停变式独立定重。不同握法/暂停/半程的成绩分开记录。

超负荷离心暂不列为每周固定必做项目。保留普通受控下降，90°暂停、顶端暂停和高位引体按卡点选用；同一技术日以一种主要变式为主，避免全部叠加。原超负荷离心不是被判定无效，只是本阶段无需默认增加它的恢复成本。

## 4. 总负荷与加重口径

按体重55kg、外挂1RM47.5kg，当前总负荷基准约为 **102.5kg**。

`目标外挂 = 总负荷相对强度 ×（基准体重 + 同口径外挂1RM）− 训练时体重`

| 总负荷强度 | 对应外挂 | 常用挂片近似 |
| --- | --- | --- |
| 70% | 16.75kg | 17.5kg |
| 75% | 21.875kg | 22.5kg |
| 80% | 27kg | 27.5kg |
| 85% | 32.125kg | 32.5kg |
| 90% | 37.25kg | 37.5kg |
| 95% | 42.375kg | 42.5kg |

这是编排强度的实用近似，不是精确关节力或个体重复次数预测。以动作质量和 RPE/RIR 校准优先。不能用“外挂47.5×80%”得38kg：外挂38kg实际约为总负荷91%，训练性质不同。

RIR 表示还能完成的同标准次数；RPE8约对应还能做2次，RPE7约还能做3次。个人估计有误差，重单次尤其需要视频与速度一起判断。普通力量组多数停在 RIR2～3；技术组保留更多余量。

### 正常周如何推进

1. **先看质量和RPE，再加重。** 相同动作、行程、暂停、组数与休息下，连续两次该训练日达成目标、末组RIR≥2，下一次外挂增加0.5～1.25kg；只有2.5kg最小挂片时，先在同重量提高少量次数或巩固两次，不要求每周必涨2.5kg。
2. **容量用双重递进。** 例如B日4×5→部分组6次→4×6；全部6次且RIR≥2后小幅加重并回到4×5。不同阶段优先遵守阶段组次，不把高重复递进延伸到冲刺期。
3. **顶组不是测试。** 目标≤RPE8，超过8.5、不完整、明显摆动就不加重；回退组当天下调2.5～5kg或减少一组。重量、次数、组数不同时提高。
4. **C日以速度/控制推进。** 同一高度、暂停与身体稳定下先做得更轻松，再加0.5～1.25kg；不能靠缩行程换重量。没有测速设备时只做视频定性比较，不把肉眼感觉当25%精确速度损失。
5. **连续两次退步先减疲劳。** 同重量同次数的RPE明显升高或完不成目标，先减少30～50%组数并检查额外训练、睡眠与间隔；恢复后再推进，不立刻增加离心或更多辅助。
6. **普通减量周。** 主项组数减少约40～50%，重量可比前周外挂降低2.5～5kg，以RPE6～7为准；直接弯举/划船约减半，暂停变式与高位量减少。无需用“外挂减少10%”替代总负荷判断。

W4/W8/W12/W20主要看固定重量表现，不需频繁测极限。W16、W24才是候选测试节点。

## 6. 卡点与解剖：辅助动作必须有可观察的职责

引体是肩关节、肩胛与肘关节协调的多关节运动：背阔肌/大圆肌参与上臂下拉，肱二头肌、肱肌、肱桡肌参与屈肘，肩胛周围肌群与肩袖参与位置控制。杠杆、握法和动作路径会改变各环节需求，但不能根据一次失败把它归结为某一块肌肉无力。

| 同标准视频出现的现象 | 选用的训练工具 | 怎么判定有用 |
| --- | --- | --- |
| 底部摆动借力，无法稳定起拉 | 较轻底部暂停引体1秒，替换C日主变式 | 同外挂下能从相同伸肘起点启动；身体不先甩动 |
| 在约90°附近反复卡住 | 90°短暂停1秒，2～3组×2次，单独找RIR≥3的负荷 | 原标准引体中段通过更稳定，不能只看暂停变式重量变大 |
| 顶端通过依赖伸脖子，肩向前逃 | 较轻顶端暂停1～2秒，2～3组×2～3次；保留划船 | 同标准终点能保持；颈部与身体姿态不替代行程 |
| 轻中负荷速度整体慢 | 少量快速引体/自重高位，每组1～2次 | 相同负荷、起点与高度下向上更快，且不摆动 |
| 重单次尚可，连续组退步明显 | 优先调整B日容量、休息和恢复 | 同外挂多组表现改善；不先假设需要更多峰值单次 |

每4～8周选择一个最明确问题，主要变式最多一个；A/B主项保留。若不存在明确卡点，C日只做较轻同口径引体即可。海豹划船提供水平拉工作，弯举提供可控屈肘训练，二者不能替代引体的专项练习，也不保证预防损伤。

肩胛应随动作自然协调运动，不要求全程死夹或压低。握距先用熟悉、无痛的肩宽到略宽范围，保持一致；不为了“练得更宽”突然改超宽握。小样本肩胛运动学研究提示不同握法有不同的运动模式，但不能证明某种握法必然伤肩，或据此诊断本学员。

如已有肩、肘或前臂疼痛，先根据位置、持续时间及诱发动作调整负荷/变式；持续或加重、影响日常的疼痛需运动医学/康复评估，不能把这份无痛条件下的草案当康复处方。

## 7. 减量测试与阶段目标

优先顺序：**同标准稳定 +47.5 → 严格 +50 → +52.5**；+55作为后续条件目标。不是承诺在某个月一定增加多少公斤，也不把未完成目标改写成个人成绩。

测试前5～7天减少约50～60%训练组数，保留少量非极限单次；最后一次较重训练后间隔约3～5天，根据恢复调整。测试前不增加超负荷离心、力竭弯举或额外高量背部训练。

测试日参考：自重3次、+15kg×2、+25kg×1、+35kg×1、+42.5kg×1；之后视42.5kg的质量决定是否做47.5kg，再决定是否尝试50kg。较重组休5～8分钟，最多约2～3次接近极限的正式尝试；失败或动作失去标准就结束加重。中期未恢复到既有最好成绩时，不测试新的更高目标。

每次至少记：体重、外挂、组次、RPE/RIR、主项末组、暂停标准、疼痛有无、额外训练。一周留A顶组和一组容量视频，固定侧面角度。不用数据库自动e1RM或“快速完成”替代真实最佳成绩。

## 8. 若只做4个月：16周版本

不是把24周的训练压进16周，也不把所有周重量上调。保留四个4周模块：

| 周数 | 安排 |
| --- | --- |
| W1～4 | 校准＋容量建立，沿24周W1～4，W4减量 |
| W5～8 | 力量基础，逐步从4～5次过渡3～4次；按24周W9～12结构但从适合当前RPE的重量开始，W8减量 |
| W9～12 | 双次强化，沿24周W13～16正常周结构，W12减量，不强制测试 |
| W13～16 | 前2周专项单次与低量回退，W15减量，W16测试；取消过早进行的额外极限测试 |

4个月版可用于先验证50/52.5kg里程碑；若容量、恢复或动作质量还不稳定，采用24周版的两轮强化更有调整余地。具体周期选择尚未获教练确认。

## 9. 研究依据与适用边界

下面研究支持原则；上述24周、具体组次、外挂起点和减量节奏是结合该学员历史做的编排建议，**不是论文中已验证的个人专属计划**。

- [ACSM 2026抗阻训练官方摘要](https://www.acsm.org/wp-content/uploads/2026/03/Resistance-Training-Position-Stand-infographic.pdf)：力量训练强调较高负荷与渐进；复杂方法、次次力竭并非一般健康成年人改善的必要条件。该摘要不是竞技负重引体周期模板。
- [Moesgaard等，2022，等量训练的周期化系统综述](https://link.springer.com/article/10.1007/s40279-021-01636-1)：周期化对1RM有一定优势，已训练者中波动训练量/强度可能有用；不证明某一种24周结构或固定4周减量最优。
- [Sánchez-Moreno等，2020，引体速度损失随机试验](https://pubmed.ncbi.nlm.nih.gov/32213783/)：29名受训男性、8周自重正手引体，25%速度损失组的多数表现改善优于50%组。支持避免不断磨慢和力竭；不能把25%机械照搬成所有高阶外挂组的精确阈值。
- [Robinson等，2024，距离力竭与训练结果的探索性分析](https://link.springer.com/article/10.1007/s40279-024-02069-2)：力量收益与估计RIR关系不明显；增肌与更接近力竭有关，分析存在估计与模型限制。本方案因此让主项留余量，辅助适度用力，并非断言RIR2是唯一最优。
- [Muñoz-López等，2017，引体负荷—速度研究](https://pubmed.ncbi.nlm.nih.gov/28253041/)：支持用负荷—速度描述专项强度；个体关系不应与普通杠铃动作或不同握法直接互换。
- [Prinold与Bull，2016，肩胛运动学研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4916995/)：11名健康男性，不同握法呈现不同肩关节/肩胛模式；不是长期伤病发生率研究，不能根据其结果宣布反手或宽握对所有人危险。
