# 训练首页与执行流程：Web / 小程序对齐

日期：2026-10-07。用户授权完善方案并开始本地实施；未授权本轮提交、部署或上传体验版。此前用户要求自行本地运行验收，本轮不操作浏览器或微信开发者工具窗口。

## 信息安排与功能边界

1. **预览计划**：计划来源选择、常驻周历、明确月历入口；动作处方、教练要求直接可见，逐组处方可展开。讲解独立于开练，预览不创建执行记录、不启动计时、不扣权益。多教练与个人计划仍按实例隔离。
2. **执行训练**：保留原有完整表单，当前组展开重量/次数/RPE、进步组、备注及本组视频；其他组可展开记录、允许时更正。动作教学和学员本组视频是两个入口。保留额外组/动作、非力量任务、计时与缓存逻辑。
3. **完成与退出**：区分误开取消、保留记录返回、完成训练；完成后反馈与生成打卡图沿用原流程。首页回显实际状态。

完整功能矩阵见 [V3 设计规格](./today-training-home-v3-redesign-2026-10-07.md)。旧图片右侧不是完整执行页，本次没有用其简化表格替换执行页面。

## 取消和返回的状态规则

| 当前状态 | 两端规则 |
| --- | --- |
| 预览，尚未创建 execution | 返回计划即可；没有记录可取消 |
| 计划训练已开始，云端尚无实际记录 | 提供“取消本次训练”，确认提示同时说明未保存输入将丢弃 |
| 已有组记录、实际数值、备注、PR 或视频 | 不提供丢弃训练；可保留记录并返回。服务端另查反馈、视频、PR 关联数据 |
| 请求期间另一端已经写入 | 服务端拒绝取消，前端保留当前记录并提示失败；不能先清缓存后发请求 |
| 已完成/超时/强制只读 | 不允许空训练取消；沿用已完成组更正与超时补记原边界 |
| 即兴训练 | 本次不新增删除即兴训练功能；沿用保存与完成流程，避免把计划取消 API 用到即兴记录 |

已提取 `packages/core/src/executionCancellation.ts`，供 Web、小程序及取消 API 共用空记录判断。服务端仍保留权限、关联记录检查与 updated_at 条件删除。取消只在服务端确认成功后清计时/相关缓存并返回。

## 本地代码修改

- 小程序首页恢复既有 WeekDashboardStrip，月份文字可打开月历；日期映射、解锁、重叠日期、不同计划来源仍用原排期模型。非本周的已选日展示其所在周，今日标识保持真实日期。
- compact 动作行恢复处方、完整教练要求、完成数、逐组安排；点名称/讲解走只读详情，不再通过点动作隐式进入执行。
- 新增 `openActionTeaching` 只读导航工具。首页和执行传入当前动作及当次要求，通过页面 eventChannel 传递，避免将计划备注写入全局动作缓存。详情支持 url/video_url，缺上下文时按计划实例只读加载兜底；不改变原动作库跳转兼容。
- Web 预览增加明确的动作讲解弹窗：通用说明、本次要求和视频；不再对必要备注截断两行。Web 执行补本次要求，修复讲解面板按钮嵌套。
- 小程序当前组显露上传视频入口、已完成摘要增加备注标志；保留 PR、自动新纪录、e1RM、RPE、所有原操作。允许更正已完成组时，也允许通过该编辑入口补视频；强制只读保持不可写。
- 小程序上传/贴链接按计划与即兴模式分流。分片上传复用原分片接口，在合并阶段选择既有即兴权限/配额/视频持久化工具；没有新增数据库表、存储策略或视频配额规则。
- Web 本组视频绑定也按模式分流，绑定成功立即更新对应组的视频摘要，避免已有视频时仍显示可取消空训练。
- 即兴 complete-set 两端补传 RPE 与手动进步组，服务端验证后保存；清空备注能发送空字符串。手动 PR 标记与自动 e1RM 新纪录仍为不同字段，不在即兴模式虚构计划 PR 创建记录。
- 视频上传、组保存或取消进行中阻止切换动作/组，减少异步结果附到另一组的风险。Web 休息计时补减 10 秒/加 10 秒及最小化，缩短至零即结束休息。

## 验收步骤（用户本地执行）

1. 同一账号准备教练计划、个人计划及即兴训练，使用本次本地 Web/API 与小程序源码。先记下已有记录，勿用真实完成记录测试删除。
2. 首页看周历→切日→查看逐组安排→动作讲解→返回。确认没有开始训练、计时或新增执行；有视频/仅说明/无素材及两教练不同要求分别检查。
3. 误开一项全新的空计划训练：Web 点击取消确认，首页恢复未开始；小程序重进同日也未开始。反向再测小程序取消后 Web 刷新。取消确认中选择继续训练，记录仍在。
4. 分别保存 0kg 组、普通组、备注或本组视频后返回。两端都不能当空训练丢弃；一端打开取消确认后另一端保存，再确认取消应失败且保留记录。
5. 当前组填重量/次数/RPE、标进步组、写备注、上传视频或贴链接→完成→重进→检查回读。计划和即兴分别执行；手动 PR 与自动新纪录分开核对。
6. 更正已完成组并保存/取消；正常已结束记录允许更正的入口补视频；强制只读入口不能改。上传过程中点其他组，不应把视频附到错误组。
7. 加组、加动作、删除自己的额外内容，检查原计划组不可误删；饮食、有氧、习惯保持原字段。
8. 休息加减/最小化/恢复，看讲解后返回计时继续；完成反馈、打卡图、首页完成进度、补记和多来源缓存复核。
9. 所有测试创建的训练/视频/额外内容按 ID 记录并清理；不要为清理测试而删除原有用户训练。
