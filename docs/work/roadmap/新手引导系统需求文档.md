# 新手引导系统 (Onboarding System) 需求文档

## 1. 背景与目标

### 1.1 背景

当前平台功能日益丰富（涵盖训练计划、教练管理、数据分析等），但新用户（无论是教练还是学员）在首次进入系统时，往往面临"功能过载"，不知道从何下手。

- **学员**：不知道在哪里看计划、如何开始第一次训练。
- **教练**：不知道如何创建模板、邀请学员、管理订阅。

### 1.2 核心目标

1. **降低认知负荷**：通过分步引导，让用户在 1 分钟内掌握核心流程。
2. **提升激活率**：让教练快速创建第一个计划，让学员快速完成第一次训练。
3. **标准化体验**：统一平台的新手教育流程，减少人工客服（或人工解释）成本。

---

## 2. 核心设计原则

1. **角色分流**：针对"教练"和"学员"提供完全不同的引导脚本。
2. **任务驱动**：不只是介绍功能按钮，而是引导用户完成一个关键任务（如"去看看你的计划"）。
3. **高亮聚焦**：使用遮罩层（Overlay）和高亮（Highlight）技术，屏蔽无关信息，让用户聚焦当前步骤。
4. **极简交互**：每一步只提供"下一步"或直接的操作引导，允许随时"跳过"。

---

## 3. 详细需求：学员端新手指引 (Student Onboarding)

### 3.1 触发时机

- 用户角色为 `student`。
- 首次登录 Dashboard（检查 `user_profiles.guides_completed` 字段）。

### 3.2 引导脚本流程

| 步骤   | 聚焦区域 (Highlight)           | 文案 (Title & Description)                                                                                      | 交互操作         |
| :----- | :----------------------------- | :-------------------------------------------------------------------------------------------------------------- | :--------------- |
| **S1** | 全局居中 (Welcome Modal)       | **欢迎来到 CoachLink！**<br>您的专业运动之旅即将开始。让我们花 1 分钟带您熟悉核心功能。                         | 按钮：[开始旅程] |
| **S2** | `今日训练卡片` (Dashboard Top) | **这是您的每日任务**<br>您的训练重量已根据您的 1RM 智能计算。点击"开始训练"即可进入跟随模式，支持手动微调重量。 | 按钮：[下一步]   |
| **S3** | `寻找教练入口` (Nav/Sidebar)   | **还没有计划？**<br>在这里浏览我们的金牌教练库，找到适合您的专业导师，为您定制专属计划。                        | 按钮：[下一步]   |
| **S4** | `个人档案入口` (Nav/Sidebar)   | **见证您的蜕变**<br>所有的训练数据、身体指标变化都会在这里形成可视化报表。                                      | 按钮：[下一步]   |
| **S5** | 全局居中 (Completion)          | **准备就绪！**<br>去做第一次训练，或者去完善一下您的个人资料吧！                                                | 按钮：[完成引导] |

### 3.3 预期效果

学员在引导结束后，应该明确知道：**"我要去点哪里开始训练"**。

## 4. 详细需求：教练端新手指引 (Coach Onboarding)

### 4.1 触发时机

- 用户角色为 `coach`。
- 首次登录 Dashboard（检查 `user_profiles.guides_completed` 字段）。

### 4.2 引导脚本流程

| 步骤   | 聚焦区域 (Highlight)                | 文案 (Title & Description)                                                                                     | 交互操作                  |
| :----- | :---------------------------------- | :------------------------------------------------------------------------------------------------------------- | :------------------------ |
| **C1** | 全局居中 (Welcome Modal)            | **欢迎加入 CoachLink 教练团队！**<br>这里是您的数字化工作台。我们将帮助您高效管理学员和训练资产。              | 按钮：[开始探索]          |
| **C2** | `计划模板库入口` (Sidebar)          | **这是您的核心资产**<br>支持 **AI 一键导入**！复制文本即可生成结构化计划。在这里积累您的"数字资产"，一键复用。 | 按钮：[下一步]            |
| **C3** | `学员管理入口` (Sidebar)            | **管理您的学员**<br>查看学员列表、处理订阅请求、分配计划都在这里完成。                                         | 按钮：[下一步]            |
| **C4** | `服务与收款设置` (Sidebar/Settings) | **开始变现**<br>在这里设置您的服务定价（月卡/季卡）和收款方式（微信/支付宝），让学员能够直接订阅。             | 按钮：[下一步]            |
| **C5** | 全局居中 (Completion)               | **开始您的执教之旅**<br>建议您先去创建一个"通用训练模板"，以备不时之需。                                       | 按钮：[创建模板] / [完成] |

### 4.3 预期效果

教练在引导结束后，应该明确核心概念：**"先建模板，再收学员，再分发计划"**。

## 5. 技术与数据记录

### 5.1 数据埋点

- **记录字段**：`user_profiles.guides_completed` (JSONB)
- **记录逻辑**：
  - 当引导点击"完成"或"跳过"时，更新数据库。
  - 数据结构示例：
    ```json
    {
      "student_dashboard": true,
      "coach_dashboard": false,
      "plan_editor": true
    }
    ```

### 5.2 UI/UX 规范

- **库选型**：`driver.js` (轻量、无依赖、支持高亮)。
- **视觉风格**：
  - 遮罩透明度：0.7 (黑色背景)。
  - 弹窗背景：白色，圆角 8px。
  - 按钮颜色：主色调 (Blue-600)，次要按钮灰色。

## 6. 进阶场景引导 (Phase 2: Contextual Deep Dives)

为了解决"功能太复杂"的问题，除了全局漫游（Tour），我们需要在用户**首次进入特定复杂页面**时，触发局部功能的深度引导。

### 6.1 计划编辑器引导 (Plan Editor Guide)

- **触发时机**：教练首次进入 `/dashboard/coach/templates/new` 或编辑页面。
- **核心痛点**：不知道如何添加动作、如何设置组数、如何区分模板和实例。
- **引导步骤**：
  1. **训练日设置**：高亮左侧"Day 1"，提示"点击这里添加新的训练日或休息日"。
  2. **AI 导入**: 高亮"AI 导入"按钮，提示"把聊天记录里的计划直接粘贴到这里，AI
     帮您自动生成"。
  3. **动作库拖拽**：高亮右侧动作库，提示"支持拖拽，也支持从自己的动作库中复用视频演示"。
  4. **参数设置**：高亮动作组（Sets/Reps），提示"点击数字即可快速修改训练容量"。

### 6.2 聊天与视频引用引导 (Chat & Video Ref Guide)

- **触发时机**：用户首次进入聊天页面。
- **核心痛点**：用户不知道可以直接引用训练视频进行提问。
- **引导步骤**：
  1. **引用按钮**：高亮输入框旁的"链接/视频"图标。
  2. **功能解释**：提示"点击这里引用您的训练视频或历史数据，教练能更准确地为您解答"。

### 6.3 训练执行引导 (Execution Guide)

- **触发时机**：学员首次点击"开始训练"。
- **核心痛点**：不知道如何标记完成、如何上传视频。
- **引导步骤**：
  1. **智能重量**：高亮输入框，提示"默认显示计算好的重量，觉得轻了？直接手动修改，后续组数会自动联动"。
  2. **上传视频**：高亮相机图标，提示"上传本组视频，获取教练的动作纠正"。
  3. **完成训练**：高亮底部"完成训练"按钮，提示"所有动作完成后，别忘了点击这里提交"。

## 7. 后续迭代计划 (V2)

1. **奖励机制**：完成引导后给予虚拟徽章。
2. **强制性检测**：如果用户多次操作错误，重新触发引导。
