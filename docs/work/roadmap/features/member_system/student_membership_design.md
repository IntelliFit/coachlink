# 学员端平台会员系统设计文档 v2.0

## 1. 核心定位与目标

构建独立于"教练订阅"之外的**学员平台会员体系**。

- **定位**：做"教练订阅"的前置漏斗，服务于自学能力较强或预算有限的入门用户。
- **转化路径**：`免费用户 (基础体验)` -> `平台会员 (进阶工具+AI)` ->
  `教练订阅 (专业1v1服务)`
- **核心价值**：通过 "内置动作库" + "AI 智能计划" + "数据工具"
  提供无需教练的标准化服务。

## 3. 多层裂变与转化体系

### 3.1 裂变拉新 (获取流量)

- **🏆 挑战赛激励**：参加官方发起的 "30天打卡" 或 "力量挑战"，完赛奖励
  **+7天高级会员**。
- **🤝 跟练邀请**：邀请好友一起执行同一个计划，双方各获得 **+3天高级会员**。
- **🎬
  社交分享**：分享训练高光时刻/周报到朋友圈/小红书，回填链接审核通过后奖励会员时长。

### 3.2 向上转化 (获取收入)

- **免费 -> 会员**：当免费用户频繁使用 "AI生成" 或 "查看历史数据"
  触达限制时，弹出会员对比页。
- **会员 -> 教练**：在高级会员的 "AI 洞察报告"
  中，如果检测到平台期或数据异常，提示
  _"AI建议咨询专业教练，高级会员享首月9折"_，并推荐擅长该领域的教练。

## 4. 数据库架构设计 (更新版)

### 4.1 核心表结构

#### `student_memberships` (会员状态)

- `tier`: 'free', 'basic', 'premium' (新增 'trial' 试用)

#### `student_quotas` (配额账户 - 更新)

| 字段              | 类型 | 说明              |
| :---------------- | :--- | :---------------- |
| user_id           | UUID | 用户              |
| ai_import_balance | INT  | 剩余AI次数        |
| storage_total_mb  | INT  | 总存储空间 (MB)   |
| storage_used_mb   | INT  | 已用存储空间 (MB) |

#### `student_membership_orders` (会员订单 - **新增**)

| 字段            | 类型        | 说明                                                |
| :-------------- | :---------- | :-------------------------------------------------- |
| id              | UUID        | 订单号                                              |
| user_id         | UUID        | 用户                                                |
| product_key     | TEXT        | 'monthly_basic', 'monthly_premium', 'data_pack_1gb' |
| amount          | NUMERIC     | 实付金额                                            |
| original_amount | NUMERIC     | 原价                                                |
| coupon_id       | UUID        | 使用的优惠券 (可选)                                 |
| payment_method  | TEXT        | 'alipay', 'wechat'                                  |
| status          | TEXT        | 'pending', 'paid', 'cancelled'                      |
| created_at      | TIMESTAMPTZ | 创建时间                                            |
| paid_at         | TIMESTAMPTZ | 支付时间                                            |

#### `student_coupons` (优惠券 - **新增**)

| 字段                 | 类型        | 说明                                             |
| :------------------- | :---------- | :----------------------------------------------- |
| id                   | UUID        | 优惠券ID                                         |
| user_id              | UUID        | 持有人                                           |
| type                 | TEXT        | 'discount_cash' (满减), 'duration_gift' (赠时长) |
| value                | NUMERIC     | 面额 (元 或 天数)                                |
| condition_min_amount | NUMERIC     | 最低使用门槛                                     |
| category_limit       | TEXT        | 限制使用品类 (如 'coach_subscription_only')      |
| status               | TEXT        | 'unused', 'used', 'expired'                      |
| expires_at           | TIMESTAMPTZ | 过期时间                                         |

### 4.2 财务相关表 (保持原有设计)

- **`coach_wallets`** (教练钱包)
- **`wallet_transactions`** (钱包流水)
- **`payout_requests`** (提现申请单)
