# [需求] 活跃度提升：提醒 + 鼓励 + 签到（不依赖"点完成"习惯）

## 1. 文档概述

- **文档版本**：V1.0
- **创建时间**：2026-01-27
- **文档目的**：针对"用户把训练页当只读，不点完成"的行为现实，提供更轻量的提醒与鼓励机制（文字提醒/签到），提升学员活跃度与训练完成率。

---

## 2. 背景与问题

- 训练系统的关键反馈（进步、PR、分享卡、教练指导）依赖"记录/完成"。
- 但大量用户只看不点，造成"系统认为没训练"，从而：
  - 无法触达（不知道该提醒谁）
  - 活跃度与留存偏低

---

## 3. 目标

- **G1（P0）**：用更轻量的行为信号建立"今天练了"的确认（签到）。
- **G2（P0）**：提供非打断式提醒与鼓励文案，降低反感。
- **G3（P1）**：支持可配置提醒规则（时间窗、频率、静默时段）。

---

## 4. 核心概念

### 4.1 签到（Check-in）

- 定义：用户不必逐组记录，只需确认"我今天练了/我准备去练"，即可产生一个轻量事件用于激励与统计。
- 签到类型（V1）：
  - **训练签到**：完成训练后点击"签到"
  - **准备签到**：点击"今天我会练"（用于提醒与承诺）

> V1 可只做"训练签到"，避免复杂。

---

## 5. 功能需求列表（Feature List）

### 5.1 训练页内提醒（P0）

- 未开始时：
  - 轻提示：`点一下开始训练，系统会帮你记录进度`
- 训练中：
  - 如果长时间停留不操作（例如 8-15 分钟），出现一条不打断提示：
    - `休息好了就继续，点一下就能记录`
- 离开页面（可选）：
  - 如果用户有明显浏览行为但未开始/未完成，提示：
    - `是否要标记今天训练完成/签到？`

### 5.2 签到入口与反馈（P0）

- 入口：
  - 训练完成页/总结页主按钮：`签到`
  - 训练页底部：`我练完了` 后弹窗里包含 `顺便签到`
- 签到反馈：
  - 明确的 UI 状态（今日已签到）
  - 一句鼓励文案（短，≤ 18 字）

### 5.3 连续天数/周统计（P1）

- 展示：
  - 连续签到天数（streak）
  - 本周训练/签到次数
- 触发鼓励：
  - 第 1 次、连续 3 天、7 天、30 天

### 5.4 通知触达（P1）

- 站内通知（P1）：
  - 今天有训练未签到 → 晚上提醒（可配置）
- Web Push（若已订阅，参考 `features/pwa`）（P1）：
  - 仅推送"重点提醒"，默认开启静默时段（例如 22:00-08:00）

### 5.5 设置项（P1）

- 提醒开关（默认开启，但可关闭）
- 静默时段设置
- 鼓励文案风格（可复用"女性/小白友好"需求中的风格）

---

## 6. 验收标准（Acceptance Criteria）

### 6.1 P0（必须）

- 用户无需逐组记录，也能通过"签到"产生明确反馈（今日已签到）
- 训练页内提醒为非打断式（默认不弹窗、不强制）
- 签到入口在训练完成流程中可被发现（不藏在二级页面）

### 6.2 P1（加分）

- streak/周统计可见且数值正确
- 支持提醒设置项
- 能通过站内通知或 Web Push 触达（依赖 push 系统）

---

## 7. 边界情况

- 用户没有任何计划：签到入口仍可用（表示"自由训练/随练"）
- 用户一天多次训练：V1 仍只算一次签到（避免刷）
- 用户误签到：允许撤销（可选）
