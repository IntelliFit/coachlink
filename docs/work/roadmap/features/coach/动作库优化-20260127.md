# [需求] 教练端优化：动作库（管理效率 + 标准化 + 复用）

## 1. 文档概述

- **文档版本**：V1.0
- **创建时间**：2026-01-27
- **文档目的**：提升教练动作库的管理效率与标准化能力，减少"同动作不同名"导致的数据割裂，并让动作在计划/执行/进步曲线中更可复用。

> 关联现有方案：\
> - `docs/work/roadmap/action_library_redesign.md`（公共库 + 私有库关联）\
> - `docs/work/roadmap/action_library_implementation.md`（实现步骤/字段补齐）

---

## 2. 背景与问题

- 动作命名不一致 → PR/进步曲线无法合并，跨教练无法继承
- 教练动作库增长后管理困难：
  - 搜索慢、重复多、缺少批量操作
  - 难以维护示范视频与动作要点

---

## 3. 目标

- **G1（P0）**：按现有设计落地"公共动作库关联"，并为教练提供顺滑的关联/整理流程。
- **G2（P0）**：提升动作库管理效率（搜索、筛选、批量操作、去重提示）。
- **G3（P1）**：动作可沉淀"要点/常见错误/替代动作"，并可在训练/问卷/知识库联动展示。

---

## 4. 功能需求列表（Feature List）

### 4.1 公共库关联体验（P0）

- 动作列表展示"关联状态"：
  - 已关联：显示公共动作名（canonical）
  - 未关联：显示 `未关联` 标签 + 引导
- 动作编辑页新增：
  - `关联公共动作` 选择器（搜索 + 别名匹配）
  - 允许取消关联（保留私有动作本体）
- 存量动作引导：
  - 进入动作库时提示"你有 X 个动作未关联，关联后可获得更好的数据分析"
  - 提供"批量关联"入口（P1）

### 4.2 管理效率（P0）

- 搜索：
  - 支持按名称/别名搜索
- 筛选：
  - 已关联/未关联
  - 分类（推/拉/腿/全身或自定义）
  - 是否启用自动算重量（若字段存在）
- 列表能力：
  - 批量选择
  - 批量删除（需二次确认）
  - 批量修改分类/标签（P1）

### 4.3 去重与命名规范（P1）

- 新建动作时：
  - 输入名称即提示可能重复（同名/相似名）
  - 推荐选择公共动作而不是重复创建
- 命名规范建议（仅提示，不强制）：
  - 动作名建议包含变式（如"深蹲（低杠）"）

### 4.4 动作内容沉淀与联动（P1）

- 动作可配置：
  - 要点（3-5 条）
  - 常见错误（可选）
  - 替代动作（可选）
  - 示范视频/图片
- 联动入口（可选）：
  - 训练页动作展开区展示要点
  - 问卷可引用动作要点（减少重复讲解）
  - 知识库可关联动作条目

---

## 5. 验收标准（Acceptance Criteria）

### 5.1 P0（必须）

- 教练可在动作编辑页完成"关联公共动作"，列表能看到关联状态
- 动作库支持搜索与按关联状态筛选
- 删除/批量操作有二次确认，误触风险可控

### 5.2 P1（加分）

- 批量关联未关联动作
- 新建动作出现去重提示与公共库推荐
- 动作要点可在训练页联动展示
