# [需求] 教练端优化：模板库（计划模板的创建、管理、分发）

## 1. 文档概述

- **文档版本**：V1.0
- **创建时间**：2026-01-27
- **文档目的**：优化教练端"计划模板库"的生产与复用效率，让教练更快产出高质量模板，并更顺滑地分发给学员（或批量分配），减少重复劳动。

---

## 2. 背景与问题

- 教练常见工作流：
  - 建模板 → 拿模板复制给不同学员 → 再微调
- 当前常见痛点（需要产品验证）：
  - 模板太多后难找（缺少标签/筛选）
  - 缺少版本概念（改模板会影响后续分发口径）
  - 批量分发/批量更新能力弱
  - 缺少"行业通用模板/自用模板/生态模板"的分层

---

## 3. 目标

- **G1（P0）**：模板管理更好用：搜索、标签、归档、复制、批量操作。
- **G2（P0）**：模板分发更顺：一键分配、可预览、可备注、可追踪。
- **G3（P1）**：模板版本化与更新策略（不强行影响存量学员计划）。

---

## 4. 功能需求列表（Feature List）

### 4.1 模板库列表能力（P0）

- 列表项展示：
  - 模板名、适用人群标签、每周几练、最近更新时间
  -（可选）使用人数/分发次数
- 搜索与筛选：
  - 按名称搜索
  - 按标签筛选（目标/水平/场景）
  - 按状态筛选：活跃/已归档
- 操作：
  - `复制模板`
  - `归档/取消归档`
  - `删除`（需二次确认）

### 4.2 模板编辑体验（P0）

- 结构清晰：
  - 周结构（第 1-7 天）
  - 每天动作列表（支持拖拽排序，P1）
- 快速能力：
  - 一键复制某一天到另一天
  - 常用动作快捷添加（来自动作库）
  - 模板备注（给学员看的注意事项）

### 4.3 模板分发（P0）

- 分发入口：
  - 模板详情页主按钮：`分配给学员`
- 分发弹窗：
  - 选择学员（支持搜索/多选）
  - 设置开始日期（默认今天/下周一）
  - 可写分发备注（例如"本周期目标：提高深蹲稳定性"）
  - 预览将生成的计划实例（只读预览）
- 分发结果：
  - 成功提示 + 可跳转到该学员计划看板

### 4.4 模板版本与更新策略（P1）

- 版本化：
  - 模板发布后再次编辑，生成新版本（旧版本保留）
- 更新策略（可选）：
  - 新分发默认使用最新版本
  - 已分发给学员的计划实例不自动变更（除非教练选择"同步更新"，后续再做）

---

## 5. 非功能需求

- **可用性**：
  - 关键操作（分发/删除/归档）需要二次确认或撤销窗口
- **性能**：
  - 模板列表分页加载（避免一次拉全）

---

## 6. 验收标准（Acceptance Criteria）

### 6.1 P0（必须）

- 模板库可搜索、可按标签/状态筛选
- 模板可复制、可归档、可删除（有二次确认）
- 教练可从模板一键分发给学员（单人/多人），并能预览

### 6.2 P1（加分）

- 模板版本化可用，新分发使用最新版本
- 支持拖拽排序、复制训练日等效率工具
