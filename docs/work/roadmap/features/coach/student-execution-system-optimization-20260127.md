# [需求] 教练端优化：学员执行体系（更好地看见、提醒与指导）

## 1. 文档概述

- **文档版本**：V1.0
- **创建时间**：2026-01-27
- **文档目的**：优化教练端对学员训练执行的洞察与干预能力：更清晰地看见学员是否在练、练到哪、哪里卡住；能更轻量地提醒与鼓励；能更高效地给反馈与复盘。

---

## 2. 背景与问题

- 学员端存在“只看不点完成”的行为，导致教练端也难以判断真实执行情况。
- 教练当前需要在多个页面/聊天里来回切换才能跟进学员。
- 缺少明确的“学员执行状态总览”和“需要教练关注的异常清单”。

---

## 3. 目标

- **G1（P0）**：教练能在一个页面看到学员执行状态与风险点（未练/拖延/连续缺勤）。
- **G2（P0）**：教练可对学员触发轻量提醒/鼓励（站内/聊天引用/Push 依赖 PWA）。
- **G3（P1）**：把“反馈”结构化（对动作/训练日/视频的点评更顺手）。

---

## 4. 功能需求列表（Feature List）

### 4.1 学员执行总览面板（P0）

- 入口：教练后台新增「执行概览」页（或概览页新增模块）
- 展示维度（最小集合）：
  - 今日状态：已练 / 未练 / 进行中 / 无计划
  - 本周训练次数（或签到次数，若做签到）
  - 最近一次训练时间
  - 连续未练天数（可选）
- 支持筛选：
  - 状态筛选（只看未练/只看连续缺勤）
  - 计划来源（教练下发/学员自建）

### 4.2 “待跟进清单”（P0）

> 用异常驱动教练动作，减少教练自己翻找。

- 自动生成需要关注的学员列表（规则可先写死）：
  - 连续 \(N\) 天未训练/未签到
  - 有计划但连续跳过关键动作（若能取到）
  - 上传了视频但未收到教练反馈（超过 24h）
- 每条项提供一键动作：
  - `发提醒`（预置文案）
  - `进入学员详情`
  - `查看最近训练`

### 4.3 轻量提醒与鼓励（P0）

- 预置文案模板（可编辑）：
  - 温和提醒、硬核提醒、关怀提醒
- 发送渠道（按现有能力）：
  - 站内消息（若有）
  - 聊天消息（推荐：直接在聊天里发）
  - Web Push（P1，依赖 `features/pwa` 的推送策略）

### 4.4 学员训练详情页优化（P1）

- 在学员详情页中：
  - 增加“执行时间线”视图：按日期列出训练/签到/视频
  - 每次训练可展开看到动作/完成度/备注
  - 支持教练直接点评（文本/快捷标签）

---

## 5. 非功能需求

- **隐私与边界**：
  - 教练只能看自己订阅学员的数据
- **性能**：
  - 执行概览默认分页加载，避免一次性加载所有学员全量执行明细

---

## 6. 验收标准（Acceptance Criteria）

### 6.1 P0（必须）

- 教练能在“执行概览”看到每个学员的今日状态与最近训练时间
- 能筛选出“未练/需要关注”的学员列表
- 能对某个学员一键发送提醒（至少通过聊天发送）

### 6.2 P1（加分）

- 存在“待跟进清单”，并能按规则自动生成
- 学员详情页提供按日期的执行时间线，并可点评
