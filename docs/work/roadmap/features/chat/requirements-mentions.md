# 聊天@引用功能 - 需求文档

## 功能概述

在聊天框中点击"@"按钮，可以引用/发送教练**内容管理**中已发布的内容，而**不是**用于at人。这将极大提升教练与学员间的沟通效率，避免传统聊天工具中"这个视频在哪"的信息检索痛点。

---

## 核心用户故事

### 用户故事1：教练发送已发布内容

- **作为一个【教练】**
- **我想要【在与学员聊天时，快速引用我已发布的教学内容、训练视频或视频集合】**
- **以便于【我能高效地回复学员问题，不用口头描述或反复解释】**

### 用户故事2：学员查看引用内容

- **作为一个【学员】**
- **我想要【点击教练发来的内容卡片，能够快速预览或跳转到完整内容】**
- **以便于【我能立即查看教练想让我看的内容，无需在App中四处寻找】**

---

## 功能定义

### 1. 引用触发交互

| 交互元素     | 说明                                           |
| ------------ | ---------------------------------------------- |
| **触发按钮** | 在聊天输入框旁增加"@"按钮（或使用现有"+"菜单） |
| **触发方式** | 点击按钮打开内容选择器弹窗                     |

### 2. 内容选择器（弹窗/列表）

#### 2.1 可引用的内容类型

| 内容类型           | 数据来源                              | 说明                                |
| ------------------ | ------------------------------------- | ----------------------------------- |
| **教练发布的内容** | `coach_contents`                      | 教练在"内容管理"中已发布的文章/视频 |
| **训练视频**       | `execution_set_videos`                | 学员执行训练时上传的动作视频        |
| **进步视频**       | `execution_set_videos` (标记为进步组) | 被标记为"进步组🏆"的高光视频        |
| **视频集合**       | 按动作名/日期分组                     | 某个动作的所有历史视频              |

#### 2.2 筛选交互

```
┌─────────────────────────────────────────────┐
│  @ 引用内容                           [×]   │
├─────────────────────────────────────────────┤
│ [🔍 搜索关键词...]                          │
├─────────────────────────────────────────────┤
│ 类型: [全部 ▼] [教学内容] [训练视频] [进步]  │
│ 时间: [不限 ▼] [最近7天] [最近30天] [更早]   │
├─────────────────────────────────────────────┤
│ ▼ 教学内容 (12)                             │
│   ├─ [视频] 深蹲技术要点           2024-01-02│
│   ├─ [文章] 训练恢复注意事项       2024-01-01│
│   └─ ...                                    │
│                                             │
│ ▼ 学员训练视频 (45)                         │
│   ├─ [卧推] 第3组 @ 80kg 🏆        2024-01-03│
│   ├─ [深蹲] 第2组 @ 100kg          2024-01-02│
│   └─ ...                                    │
│                                             │
│ [加载更多...]                               │
└─────────────────────────────────────────────┘
```

#### 2.3 分页加载

- 每次加载 **20条** 记录
- 滚动到底部或点击"加载更多"时请求下一页
- 支持**下拉刷新**获取最新内容

#### 2.4 展示信息

- **仅展示标题或简短摘要**（不展示全文）
- 内容类型图标（视频/文章/图片）
- 发布/上传时间
- 进步组🏆标记（如适用）

---

### 3. 内容预览与跳转

#### 3.1 发送后状态

内容在聊天窗口中显示为**引用卡片**：

```
┌─────────────────────────────────────────┐
│ 📹 深蹲技术要点                         │
│ ┌─────────────────────────────────────┐ │
│ │     [视频缩略图/封面图]              │ │
│ │           ▶️                        │ │
│ └─────────────────────────────────────┘ │
│ 这是教练发布的教学视频，点击查看详情    │
│                            2024-01-02   │
└─────────────────────────────────────────┘
```

#### 3.2 悬停预览（Hover Preview）

- **PC端**：鼠标悬停在卡片上时，显示预览浮层
  - 视频：显示缩略图 + 时长
  - 图片：显示图片预览
  - 文章：显示前100字摘要
- **移动端**：长按显示预览

#### 3.3 点击跳转

- 点击卡片跳转到**完整的内容展示页**
- 不同内容类型跳转到对应页面：
  - 教练内容 → `/coach/profile/[id]/content/[contentId]`
  - 训练视频 → 视频播放弹窗或视频详情页
  - 进步视频 → 学员进步时间线

---

## 附件限制

> [!IMPORTANT]
> 不支持发送任意外部文件，只支持发送**项目内部已存储的内容**

**原因**：

1. 避免复杂的文件上传、缓存和存储问题
2. 保证内容安全可控
3. 保持聊天记录的可追溯性

---

## 验收标准

### 功能验收

| 序号 | 验收项    | 标准                         |
| ---- | --------- | ---------------------------- |
| 1    | @按钮可见 | 聊天输入框旁有明确的引用按钮 |
| 2    | 弹窗打开  | 点击按钮后弹出内容选择器     |
| 3    | 内容搜索  | 支持关键词搜索，结果正确     |
| 4    | 内容筛选  | 支持按类型、时间筛选         |
| 5    | 分页加载  | 数据量大时正确分页，无重复   |
| 6    | 卡片发送  | 选择内容后在聊天中显示为卡片 |
| 7    | 悬停预览  | PC端悬停可预览内容           |
| 8    | 点击跳转  | 点击卡片跳转到正确的详情页   |

### 性能验收

| 指标         | 标准    |
| ------------ | ------- |
| 弹窗打开速度 | < 500ms |
| 搜索响应时间 | < 1s    |
| 卡片渲染时间 | < 200ms |

---

## 权限说明

| 用户类型 | 可引用的内容                            |
| -------- | --------------------------------------- |
| **教练** | 自己发布的教学内容 + 学员的训练视频     |
| **学员** | 自己的训练视频 + 所关注教练的已发布内容 |

---

## UI/UX 注意事项

1. **快捷键支持**：`@` 键触发（可选，类似Slack）
2. **最近使用**：记录最近引用的内容，优先显示
3. **空状态处理**：无内容时显示引导提示
4. **加载状态**：骨架屏或加载动画
5. **错误处理**：网络错误时的重试机制
