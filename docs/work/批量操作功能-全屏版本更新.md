## 🎯 核心改动

### 1. **对话框尺寸调整为全屏**

#### 尺寸对比

| 项目 | 旧版 | 新版 |
|------|------|------|
| 宽度 | `90vw`, max `1000px` | `95vw`, max `1400px` |
| 高度 | 自适应内容 | `90vh` 固定高度 |
| 移动端 | 92vw | 100vw × 100vh 真全屏 |

#### 代码实现

```tsx
<Dialog
    style={{ 
        width: '95vw', 
        height: '90vh', 
        maxWidth: '1400px' 
    }}
    className="batch-operation-dialog-fullscreen"
    contentClassName="h-full"
>
```

**设计考虑：**
- PC端：占据 95% 视口宽度，90% 视口高度
- 最大宽度 1400px，适配大屏幕
- 移动端：100% 全屏，无圆角，沉浸式体验

### 3. **内容区域弹性布局**

#### 布局结构

```tsx
<div className="flex flex-col h-full space-y-5">
    {/* 1. 指令输入 - 固定 */}
    <div className="space-y-2 flex-shrink-0">...</div>
    
    {/* 2. 日志显示 - 固定高度 */}
    <Card className="... flex-shrink-0">
        <div className="... max-h-48">...</div>
    </Card>
    
    {/* 3. 修改预览 - 占据剩余空间 */}
    <div className="flex flex-col ... flex-1 min-h-0">
        <Card className="... flex-1 min-h-0 overflow-hidden">
            <DataTable scrollHeight="flex">...</DataTable>
        </Card>
    </div>
    
    {/* 4. 按钮区域 - 固定底部 */}
    <div className="... flex-shrink-0 border-t ... mt-auto">...</div>
</div>
```

#### 关键类名说明

| 类名 | 作用 | 应用区域 |
|------|------|---------|
| `h-full` | 占满父容器高度 | 最外层容器 |
| `flex-shrink-0` | 不允许收缩 | 指令输入、日志、按钮 |
| `flex-1` | 占据剩余空间 | 修改预览区域 |
| `min-h-0` | 允许收缩到0 | 预览容器（配合flex-1） |
| `mt-auto` | 推到底部 | 按钮区域 |
| `max-h-48` | 最大高度12rem | 日志区域 |

---

### 4. **修改预览表格自适应**

#### 改动

```tsx
// 旧版：固定高度
<DataTable scrollHeight="300px" />

// 新版：弹性高度
<DataTable scrollHeight="flex" />
```

#### 容器层级

```
Card (flex-1 min-h-0 overflow-hidden)
  └─ DataTable (scrollHeight="flex")
```

**原理：**
- 外层 Card 使用 `flex-1` 占据剩余空间
- `min-h-0` 允许 flexbox 正常收缩
- `overflow-hidden` 防止内容溢出
- DataTable `scrollHeight="flex"` 自动填充父容器

---

### 5. **按钮区域固定底部**

#### 改动

```tsx
<div className="... flex-shrink-0 border-t border-surface-100 mt-auto">
```

**新增特性：**
- ✅ `border-t`：顶部边框，视觉分隔
- ✅ `mt-auto`：自动推到最底部
- ✅ `flex-shrink-0`：始终保持完整高度
