## 5. 下一步建议补的关键埋点

为了融资材料更硬，建议尽快补或统一以下口径：

1. 日活 / 周活 / 月活事件表：不要只依赖 `last_login_at`。
2. 训练执行漏斗：查看今日训练 → 开始训练 → 完成第一组 → 完成当天 → 分享。
3. 教练运营漏斗：教练注册 → 完善主页 → 设置价格 → 创建模板 → 邀请学员 → 收款。
4. 支付订单清洗字段：标记 `is_test_order`、统一 `amount_fen`。
5. 视频点评漏斗：上传视频 → 教练查看 → 点评 → 学员查看反馈。
6. 分享事件口径：链接生成、打开、注册、订阅转化。
7. 功率分析历史完成表：不要让 `expired` 覆盖真实成功历史。
