## 初步核查记录（已由上方用户纠正收口）

用户提供群聊反馈和现有页面截图：附近入口只有位置，照片列表出现远处场地。截图未提供明确的目标设计；已异步询问本轮直接修改还是先分析方案，尚未收到选择。

## 已核实原因

- `apps/wechat/src/streetlifting/index/locations/index.tsx` 的 `nearbyLocations` 从地图点位中计算距离、排序并取前五条；渲染只包含名称、距离与地图按钮。
- 地图点位 API 与类型不带照片，地图页选中卡片也未获取完整点位或显示照片。因此附近入口不能浏览该点位已有照片。
- 下方完整照片卡片是另一套分页列表：服务端先按创建时间取一页，客户端再优先有图、图片数量、创建时间。定位未参与该列表查询或排序。
- 附近列表没有距离上限，且与下方搜索及国家/省份条件分离；“离你最近”取最近五条，并不保证都在附近。
