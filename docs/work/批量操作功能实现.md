# 批量操作功能实现文档

## 概述

实现了基于自然语言的训练计划批量操作功能,用户可以通过自然语言描述来批量修改训练计划模板。

## 技术架构

### 后端 (SSE 流式接口)

**路径**: `/api/plan-lib/batch-operation`

**功能流程**:

1. **验证用户身份**: 确保用户是教练角色
2. **加载训练计划模板**: 从数据库获取指定模板的 `trainingDays`
3. **加载动作库**: 获取教练的所有动作 (id, name, type)
4. **构建 AI Prompt**: 将动作库、trainingDays 结构、用户指令组合成系统提示
5. **调用 DeepSeek**: 生成 TypeScript 代码来执行批量操作
6. **代码执行**: 在 isolated-vm 沙箱中安全执行代码
7. **更新数据库**: 将修改后的 trainingDays 保存回数据库
8. **实时反馈**: 通过 SSE 流式传输处理进度

**安全措施**:
- 使用 `isolated-vm` 创建隔离的 V8 实例
- 内存限制: 128MB
- 执行超时: 10秒
- 无外部库访问
- 无异步操作

### 前端组件

#### 1. `BatchOperationDialog` 组件

**路径**: `src/components/BatchOperationDialog.tsx`

**功能**:
- 提供自然语言输入框
- 实时显示 SSE 消息流
- 展示处理进度和代码执行过程
- 格式化显示代码块
- 自动滚动到最新日志

**消息类型**:
- `progress`: 处理进度消息
- `tool_call`: 工具调用信息
- `code_execution`: 代码执行详情(包含生成的 TS 代码)
- `execution_result`: 代码执行结果
- `final_result`: 最终结果
- `error`: 错误信息

#### 2. `BatchOperationService` 服务

**路径**: `src/app/service/batchOperationService.ts`

**功能**:
- 封装 SSE 请求逻辑
- 解析 SSE 数据流
- 提供回调接口处理消息

## 使用示例

### 示例 1: 替换动作

**用户输入**:
```
请帮我把引体向上类的动作都替换为有氧
```

**生成的代码** (示例):
```typescript
const cardioAction = findActionByName("跑步");
if (cardioAction) {
    trainingDays.forEach(day => {
        if (day.type === 'training' && day.actionSets) {
            day.actionSets.forEach(actionSet => {
                if (actionSet.params.action_name?.includes("引体向上")) {
                    actionSet.actionId = cardioAction.id;
                    actionSet.params.action_name = cardioAction.name;
                }
            });
        }
    });
}
```

### 示例 2: 批量修改参数

**用户输入**:
```
把所有深蹲的组数改为5组
```

**生成的代码** (示例):
```typescript
trainingDays.forEach(day => {
    if (day.type === 'training' && day.actionSets) {
        day.actionSets.forEach(actionSet => {
            if (actionSet.params.action_name?.includes("深蹲")) {
                actionSet.params.sets = 5;
            }
        });
    }
});
```

### 示例 3: 删除动作

**用户输入**:
```
删除所有的休息日
```

**生成的代码** (示例):
```typescript
const newTrainingDays = trainingDays.filter(day => day.type !== 'rest');
trainingDays.length = 0;
trainingDays.push(...newTrainingDays);
```

## 数据结构

### TrainingDay

```typescript
interface TrainingDay {
    type: 'training' | 'rest';
    note?: string;
    actionSets?: ActionSet[];
    dayIndex: number;
}
```

### ActionSet

```typescript
interface ActionSet {
    actionId: string;
    setName: string;
    params: {
        action_name?: string;
        sets?: number;
        reps?: number;
        weight?: number;
        rest_seconds?: number;
        note?: string;
    };
}
```

## 辅助函数

在虚拟机环境中提供以下辅助函数:

- `findActionByName(name: string)`: 通过名称模糊查找动作
- `findActionById(id: string)`: 通过 ID 查找动作

## 安全考虑

1. **代码隔离**: 使用 isolated-vm 确保代码在独立的 V8 实例中运行
2. **资源限制**: 内存和时间限制防止资源耗尽
3. **权限验证**: 仅教练角色可访问
4. **数据验证**: 确保只能修改自己的模板
