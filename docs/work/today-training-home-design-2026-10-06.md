## 推荐层级

1. 顶部明确“今日训练”，昵称不再使用大问候卡。
2. 日期行紧凑显示当前日期，“日历”展开日期选择；不要默认展开整块月历。
3. 计划来源明确显示一个当前来源，可打开选择面板切换教练计划/我的计划。只有一份计划也显示来源，不展示无意义的两栏切换。
4. 一个主要训练区包含具体训练名、当次状态、一次动作/组数摘要、一个主要按钮和紧凑动作列表。合并原来今天重点、今日安排、计划训练三层表达。
5. 查看完整计划是次级入口：整期进度、训练日历史、训练结构等在计划详情呈现。
6. 即兴锻炼是轻量文字入口；无计划时才提升为主要操作。

动作列表保持可点击直达对应动作执行位置；首页少展示重量、休息、RPE和长备注，完整参数留在执行页面。默认最多预览 3 个动作，多于 3 个显示明确的“查看全部动作”，不能让长计划再次铺满首页。草稿图恰好为三个动作，不需要此入口。

## 状态规则

| 上下文 | 主区文案/按钮 | 辅助内容 |
| --- | --- | --- |
| 未开始 | 具体训练名、未开始；开始训练 | 动作预览，不显示成果空区 |
| 进行中 | 具体训练名、已完成 X/Y 组；继续训练 | 同一执行记录的逐动作进度 |
| 本次力量训练完成 | 训练完成；查看训练记录 | 有真实记录才提供生成打卡图 |
| 还有其他任务 | 力量训练已完成；查看训练记录 | 下方显示真实未完成任务，不能标成全日安排已完成 |
| 休息日 | 今天是休息日 | 有恢复/饮食/习惯任务才显示；不提供无内容的开始力量训练按钮 |
| 无计划/教练制定中 | 自由训练/计划制定中；即兴锻炼 | 查找教练、查看计划库等次级入口按既有资格呈现 |
| 选中历史或未来日期 | 明确具体日期及当天训练 | 不继续使用无条件“今日”措辞 |

“今日已完成”提示、主卡、动作完成组数和主按钮必须对应相同计划、日期与执行记录。若今天完成后默认推进下一次训练，应把它标成“下一次训练”，今天已完成的记录仍可回看；不能同屏把两次不同的训练都叫今日安排。

## 辅助功能如何保留

| 功能 | 新入口 |
| --- | --- |
| 补记已练过的这一天/核对训练日期 | 更多 → 训练记录 → 选中日期的补记或日期校核；保持原日期约束和业务语义 |
| 联系教练 | 更多 → 联系当前教练；自主计划不显示无对应教练的联系项 |
| 新增轻量任务 | 更多 → 添加任务 |
| 有内容的轻量任务 | 主训练区下方一组紧凑任务行，保持可见，不藏起待办 |
| 没有轻量任务 | 不渲染空模块和“暂无任务”占位卡 |
| 当前计划进度 | 查看完整计划 |
| 生成打卡图 | 训练记录/完成状态里的次按钮；部分记录需明确进度，不宣称全完成 |

更多面板建议不超过四个清晰选项，具体目标沿用既有训练记录/计划入口；不能为整理首页把业务校核功能删掉。

- 布局间距按 8rpx 的整数倍；概念图不代替尺寸标注，实际实施还需按既有小程序布局换算。
