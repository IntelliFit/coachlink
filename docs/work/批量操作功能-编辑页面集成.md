# AI 批量操作功能 - 编辑页面集成

## 问题描述

AI 批量操作功能最初只在计划库列表页面 (`/dashboard/plan-lib`) 集成,但用户在编辑页面 (`/dashboard/plan-lib/edit/[id]`) 中也需要使用该功能。

## 解决方案

在编辑页面中集成 AI 批量操作对话框,与现有的传统批量操作功能并存。

## 修改内容

### 文件: `src/app/dashboard/plan-lib/edit/[id]/page.tsx`

#### 1. 添加导入
```typescript
import { BatchOperationDialog } from '@/components/BatchOperationDialog';
```

#### 2. 添加状态管理
```typescript
const [aiBatchDialogVisible, setAiBatchDialogVisible] = useState(false);
```

#### 3. 添加成功回调处理
```typescript
const handleAiBatchOperationSuccess = async () => {
    showToast({ severity: 'success', summary: 'AI 批量操作成功', detail: '训练计划已更新' });
    setAiBatchDialogVisible(false);
    // 重新加载模板数据
    await loadTemplate();
};
```

#### 4. 在 BasicInfoForm 中添加 AI 批量操作按钮
在原有的"批量操作"按钮旁边添加"AI 批量操作"按钮:

```typescript
extraButton={
    <div className="flex gap-2">
        <Button
            label="批量操作"
            // ... 原有按钮
        />
        <Button
            label="AI 批量操作"
            size="small"
            icon="pi pi-bolt"
            className="...primary色系样式..."
            onClick={() => setAiBatchDialogVisible(true)}
            disabled={saving}
        />
    </div>
}
```

#### 5. 添加 AI 批量操作对话框组件
```typescript
{/* AI 批量操作对话框 */}
{params.id && (
    <BatchOperationDialog
        visible={aiBatchDialogVisible}
        onHide={() => setAiBatchDialogVisible(false)}
        templateId={params.id as string}
        onSuccess={handleAiBatchOperationSuccess}
    />
)}
```

## 功能特点

### 两种批量操作并存

1. **传统批量操作** (原有功能)
   - 图标: `pi-sliders-h` (滑块图标)
   - 样式: 灰色系
   - 功能: 
     - 替换动作
     - 删除动作
     - 追加动作到指定周和工作日

2. **AI 批量操作** (新功能)
   - 图标: `pi-bolt` (闪电图标)
   - 样式: 主题色系 (蓝色/紫色)
   - 功能:
     - 自然语言批量操作
     - DeepSeek AI 理解指令
     - 实时进度反馈
     - 代码透明展示

### 工作流程

#### 编辑页面使用 AI 批量操作

1. 用户在编辑页面修改训练计划
2. 点击"AI 批量操作"按钮
3. 在对话框中输入自然语言指令
4. AI 生成并执行代码
5. 操作成功后自动重新加载模板数据
6. 页面显示最新的训练计划内容

#### 与传统批量操作的区别

| 特性 | 传统批量操作 | AI 批量操作 |
|------|------------|------------|
| 输入方式 | 表单选择 | 自然语言 |
| 灵活性 | 固定操作类型 | 任意复杂操作 |
| 学习曲线 | 需要理解界面 | 直观描述即可 |
| 功能范围 | 替换/删除/追加 | 任意 TS 代码 |
| 实时反馈 | 无 | SSE 流式显示 |
| 代码可见 | 不可见 | 完全透明 |

## 集成位置

### 1. 列表页面 (`/dashboard/plan-lib`)
- 位置: 训练计划卡片上的⚡按钮
- 用途: 快速对模板进行批量操作

### 2. 编辑页面 (`/dashboard/plan-lib/edit/[id]`)
- 位置: 基本信息表单右上角
- 用途: 编辑过程中进行批量调整
- 特点: 操作后自动刷新页面数据

## 技术实现细节

### 数据同步

编辑页面的 AI 批量操作会:
1. 调用后端 API 修改数据库中的 `training_days`
2. 操作成功后调用 `loadTemplate()` 重新加载数据
3. 更新本地的 `days` 状态
4. 页面立即显示最新内容

### 状态管理

```typescript
// 对话框显示状态
const [aiBatchDialogVisible, setAiBatchDialogVisible] = useState(false);

// 成功后的处理
const handleAiBatchOperationSuccess = async () => {
    showToast({ severity: 'success', summary: 'AI 批量操作成功' });
    setAiBatchDialogVisible(false);
    await loadTemplate(); // 重新加载最新数据
};
```

### 按钮样式区分

- **传统批量操作**: 灰色边框,灰色文字
- **AI 批量操作**: 主题色背景,主题色边框,醒目显示

## 注意事项

1. **数据一致性**: AI 操作直接修改数据库,编辑页面操作后会重新加载数据
2. **未保存提示**: 如果用户在编辑页面有未保存的修改,使用 AI 批量操作后这些修改会被覆盖
3. **建议工作流**: 
   - 先保存当前修改
   - 再使用 AI 批量操作
   - 或者在 AI 操作后重新应用本地修改
