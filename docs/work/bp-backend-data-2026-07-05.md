## 2. 付费与收入口径：本版重点修正

### 2.1 正确口径：付费分两层看

CoachLink 当前不能只用 `alipay_orders` 来代表全部收入，因为产品早期还没有正式接通平台支付。早期很多订阅关系是学员直接转账给教练，后台用 `coach_subscriptions` 记录服务关系、周期、价格和支付方式。

建议 BP 中使用两个口径：

1. **已发生付费服务关系**：以 `coach_subscriptions` 为主。凡是进入订阅关系的学员，业务上代表已经与教练发生付费服务关系，其中早期多为直接转账/二维码/线下确认。
2. **平台化支付订单**：以 `coach_subscription_orders`、`alipay_orders`、`coach_subscription_settlements`、钱包流水为主。它证明平台支付、结算、钱包链路已经接通，但不能覆盖早期全部付费。

### 2.3 订阅金额与 GMV 估算

`coach_subscriptions.monthly_price` 在代码中按“分”存储，支付创建逻辑也直接把它作为订单金额使用。剔除 0 元、1 分和明显测试通道后，可以得到更稳的服务金额口径。

- `monthly_price >= 1 元` 的订阅关系：102 条
- `monthly_price >= 99 元` 的订阅关系：97 条
- 订阅关系中记录的首期/套餐金额合计：约 ¥16,998
- 剔除低价测试后金额合计：约 ¥16,993
- 若按 `monthly_price * subscribed_weeks / 4` 粗估合同服务额：约 ¥46,742

这组数字建议内部使用，不建议在 BP 正文直接写成“GMV 4.7 万”，因为：

- `monthly_price` 在历史记录里混有 1 分、1 元和测试通道；
- 早期直接转账可能没有完整平台订单可交叉验证；
- `subscribed_weeks` 是权益周期，不一定等于一次性支付周期。

更稳的对外说法：

> 已记录 138 条教练-学员付费服务关系，覆盖 122 名付费学员；历史阶段以教练直接收款为主，平台支付接通后正在迁移到支付宝/微信订单与结算链路。

## 10. 建议 BP 叙事升级

上一版可以讲“线上自由教练商业化操作系统”，本版建议再加一句更硬的商业化证明：

> CoachLink 已经验证从专业工具获客、教练订阅付费、结构化训练交付到支付结算的完整链路。早期服务交易以教练直接收款为主，平台记录订阅与训练履约；现在支付能力已接入支付宝/微信和教练结算，正在把线下/个人收款迁移为平台化交易。

投资人可能追问时的回答：

- 问：为什么平台订单金额不高？  
  答：因为早期交易发生在教练个人收款侧，平台先承接服务关系和训练交付；正式支付功能接入后，才开始把收款迁移到平台订单。
- 问：付费是否真实？  
  答：后台有 138 条教练-学员订阅服务关系，覆盖 122 名学员，并且绑定训练计划、执行记录、周期和支付方式；其中 102 条是历史/个人收款/线下确认，36 条已标记为平台支付宝/微信。
- 问：下一步收入怎么放大？  
  答：把已验证的标杆教练服务流程产品化，推动更多教练开通收款账户和平台支付，同时用街健计算、功率分析、动作库等工具入口获取高意图训练用户。
