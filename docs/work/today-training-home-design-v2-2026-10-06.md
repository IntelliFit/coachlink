## 首页只保留三块

1. **一行上下文**：左侧“10月6日 周二”可选日期，右侧“刘三乐的计划 ▾”可切计划。去掉顶部今日训练大标题、昵称、问候、教练头像、独立日期卡、独立来源卡。
2. **动作列表**：一行低权重摘要“第33天 · 3个动作 · 20组”，然后直接列动作名与完成组数。去掉额外训练大标题、分类标题、当日总览卡。右侧省略号承接当日补记、加任务等上下文操作。
3. **一个主按钮**：开始训练/继续训练/查看记录随当前选择的实际执行状态变化。不要在其下追加完整计划或即兴按钮形成新层级。即兴锻炼按需进入省略号；生成打卡图在训练执行页完成后出现。

底部导航沿用既有学员五项。白色动作列表是一组行，不把每个动作做成大卡。有真实轻任务时紧接动作区呈现紧凑任务行；无任务不渲染空区。长列表保留滚动，本地实现的主按钮跟随列表，底部留出导航空间。

## 多位教练与个人计划

- 首页显示当前选中计划，点击同一行中的来源选择器，底部面板按实际有效来源列出刘三乐的计划、另一位教练的计划、我的计划。无个人计划不显示该项；待制定/休息日/已完成按真实数据标记。
- 切换时同步替换当前计划的动作、自己的训练日序号、组数、完成提示和主按钮；不能把前一计划D33直接用于新计划，也不能把两个教练的动作或完成度相加。
- 每份计划保留自己独立的执行记录、完成情况和缓存上下文。用户先练A再练B时，主动切换即可；完成A不能替B完成。
- 记住最近选择。所选计划有进行中执行时优先恢复该日；否则展示今天刚完成的记录，再回退计划进度日。不因另一份计划推进而替换当前计划。
- 默认只展示当前有效计划，不把所有来源堆在首页。同一教练存在多个同名来源时，面板补充真实计划名区分，内部仍使用subscription/instance身份，不能按昵称或标题识别记录。
- 选择器仅负责选择，不提供暂停/删除教练计划。用户此前明确个人计划停用/管理应在“我的计划库”，该约束保留；不在此页新增管理按钮。

## 对“查看完整计划”的纠正

V1该入口原想容纳整期排期、训练日历史与总体完成进度，但用户并不需要首页新增这一层。V2取消此常驻入口，也不以它为由新增一页。日期浏览通过顶部日历承担；模板及个人计划管理沿用已有计划库入口。若后续确实需要更完整的周期管理，应单独明确需求，不能再次直接堆回首页。

## 日期与状态

日历日期、当前来源、动作与执行状态必须对应同一上下文。浏览非今天日期时明确所选日期。当前训练完成后主按钮显示查看记录；下一场不自动冒充今日未开始训练。力量部分完成但轻任务未完成时，分别按任务准确表示，不能宣布全日已完成。

## 辅助功能入口补全（主结构接受后的建议）

首页精简的是常驻模块，业务能力应有明确入口，不应让有待办的内容消失。V2静态图没有展开日期面板、省略号菜单以及有实际轻任务时的列表；不能据此推断功能已删除或页面已实施。

| 现有功能 | V2安排 |
| --- | --- |
| 本周/月历、往日记录、后续日期安排 | 点顶部日期展开日历，选中日期后替换该计划当日的内容 |
| 整期计划进度/已完成训练日数 | 放在展开日历的顶部一行，按当前计划显示，如已完成14/18个训练日；不在首页新增独立进度卡 |
| 多位教练/个人计划切换 | 点当前计划来源，选一份来源，主列表和完成状态同步替换 |
| 补记/核对训练日期 | 动作摘要右侧省略号 → 补记训练/核对日期，直接针对当前计划选中日，沿用原实际日期校核规则 |
| 即兴锻炼 | 省略号 → 即兴锻炼；无有效计划时可成为主页主操作 |
| 新增饮食、有氧、习惯等轻任务 | 省略号 → 添加任务，沿用现有动作选择和配置流程 |
| 已有饮食、有氧、习惯等轻任务 | 主动作列表下方实际显示可打卡的紧凑任务行；没有任务不显示空区，不将已有任务藏进菜单 |
| 联系当前教练 | 省略号 → 联系教练；自主计划上下文无对应教练时不显示此项 |
| 打卡图/成果分享 | 训练完成后在执行页完成总结中自动显示生成打卡图；再次查看已完成记录时页首也有入口，首页更多不放分享 |
| 动作重量/次数/休息/备注/演示视频 | 点击动作进入执行/动作详情，沿用现有参数和有资源才显示的演示入口 |
| 未确认训练日的补练或跳过 | 在日历中对应日期提供操作和必要提示，重要待处理状态不只藏在无标识菜单里 |
| 模板与个人计划库 | 既有“我的 → 我的计划库”；个人计划停用等管理仍按另一个已确认任务在库内处理，不能声称停用已实现 |

省略号是一个清晰的一层操作面板，不再套多层更多菜单。菜单项按上下文出现；需要更多低频项时在面板内分组，避免把一串功能重新铺回首页。所有操作应明确当前来源和选中日期。

本地实现已在日历顶部显示所选计划进度，日期列表保留未确认训练日补练/跳过。图里的空白区域在有真实任务时承接任务；静态样例为空不等于隐藏实际待办。
