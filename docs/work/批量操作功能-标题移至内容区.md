# 智能批量操作对话框 - 标题移至内容区

## 更新时间
2026-02-04

## 更新目标
将标题"教链 AI 计划修改器"从对话框 header 移到内容区，并在开始执行后消失

---

## 🎯 核心改动

### 1. **移除 Dialog Header**

#### 旧版
```tsx
<Dialog
    header={
        <div className="text-center py-6">
            <div className="text-3xl font-black tracking-tight text-surface-900 mb-3">
                教链 AI 计划修改器
            </div>
            <div className="text-sm text-surface-500 font-medium">
                使用自然语言描述批量操作，系统会自动识别并预览修改内容
            </div>
        </div>
    }
    ...
>
```

#### 新版
```tsx
<Dialog
    header={null}  // 移除 header
    ...
>
```

---

### 2. **标题移至内容区**

#### 新布局
```tsx
{!hasStarted && (
    <div className="flex-1 flex flex-col items-center justify-center px-8">
        <div className="w-full max-w-3xl space-y-6">
            {/* 标题区域 - 仅在未开始时显示 */}
            <div className="text-center space-y-3">
                <div className="text-3xl font-black tracking-tight text-surface-900">
                    教链 AI 计划修改器
                </div>
                <div className="text-sm text-surface-500 font-medium">
                    使用自然语言描述批量操作，系统会自动识别并预览修改内容
                </div>
            </div>

            {/* 输入框容器 */}
            <div className="relative">
                {/* ... */}
            </div>
            
            {/* 提示文字 */}
            <div className="text-center text-xs text-surface-400">
                按 Enter 发送，Shift + Enter 换行
            </div>
        </div>
    </div>
)}
```

**特点：**
- ✅ 标题在内容区顶部
- ✅ 与输入框一起居中显示
- ✅ 间距 `space-y-6` 更加舒适
- ✅ 仅在 `!hasStarted` 时显示

### 3. **CSS 样式调整**

**改动说明：**

## 🎨 视觉效果

### 优势

1. **更沉浸的体验**
   - 无固定 header，空间更充足
   - 标题和输入框一起居中，视觉更集中

2. **清晰的状态转换**
   - 未开始：标题醒目，引导用户输入
   - 已开始：标题消失，专注对话内容

3. **空间利用最大化**
   - 移除 header 后，内容区获得更多垂直空间
   - 适合显示更多日志和预览数据

4. **符合 ChatGPT 风格**
   - ChatGPT 初始界面也是标题在中间
   - 对话开始后标题消失，专注对话
