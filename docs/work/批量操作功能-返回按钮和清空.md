## 更新时间
2026-02-04

## 更新目标
1. 将"重新开始"改为"清空"
2. 在已开始状态顶部左侧添加返回按钮（← 图标）
3. 点击返回按钮关闭对话框

---

## 🎯 核心改动

### 1. **添加顶部返回按钮**

#### 布局结构

```
┌─────────────────────────────┐
│ ← (返回按钮)                 │  <- 新增
│ ─────────────────────────── │
│ [你的消息] 👤                │
│ [日志]                       │
│ [预览表格]                   │
│ ─────────────────────────── │
│ [清空]          [确认应用]   │
└─────────────────────────────┘
```

#### 实现代码

```tsx
{hasStarted && (
    <div className="flex flex-col h-full">
        {/* 顶部返回按钮 */}
        <div className="flex-shrink-0 px-8 pt-6 pb-4">
            <Button
                icon="pi pi-arrow-left"
                text
                severity="secondary"
                className="rounded-2xl text-surface-600 hover:text-surface-900 hover:bg-surface-50 active:scale-[0.98] transition-all -ml-2"
                onClick={handleHide}
                disabled={isProcessing || isApplying}
                aria-label="关闭"
                tooltip="关闭对话框"
                tooltipOptions={{ position: 'right' }}
            />
        </div>
        
        {/* 内容容器 */}
        <div className="flex-1 min-h-0 px-8 pb-6 flex flex-col">
            {/* ... 其他内容 */}
        </div>
    </div>
)}
```

**设计特点：**
- 📍 **位置**：独立区域，在用户消息上方
- 🎨 **样式**：文本按钮，圆角
- 👆 **交互**：hover 变色，active 缩放
- ℹ️ **提示**：tooltip 提示"关闭对话框"
- 🔒 **禁用**：处理中或应用中时禁用
- 📐 **偏移**：`-ml-2` 左移对齐边缘

---

### 2. **底部按钮改为"清空"**

#### 旧版
```tsx
<Button
    label="重新开始"
    icon="pi pi-refresh"
    // ...
/>
```

#### 新版
```tsx
<Button
    label="清空"
    icon="pi pi-trash"
    // ...
/>
```

**改动说明：**
- ✅ 文本：`重新开始` → `清空`
- ✅ 图标：`pi-refresh` (刷新) → `pi-trash` (垃圾桶)
- ✅ 功能：保持不变（调用 `handleRestart`）
- ✅ 语义：更直接，表达清空当前对话

---

### 3. **布局调整**

#### 结构层级

```
已开始状态容器
├─ 顶部返回按钮区域 (flex-shrink-0)
│  └─ px-8 pt-6 pb-4
│     └─ Button (← 返回)
│
├─ 内容容器 (flex-1)
│  └─ px-8 pb-6
│     ├─ 用户消息 (flex-shrink-0)
│     └─ 内容区域 (flex-1)
│        ├─ 日志
│        └─ 预览表格
│
└─ 底部按钮区域 (flex-shrink-0)
   └─ px-8 pt-4 pb-6
      ├─ 清空按钮
      └─ 确认应用按钮
```

**关键改动：**
- ✅ 顶部返回按钮独立区域
- ✅ 内容容器统一 `px-8` 内边距
- ✅ 底部按钮区域添加 `px-8` 内边距

```tsx
// 预览标题文字

```

## 🔄 交互流程

### 用户操作路径

#### 路径 1：正常完成
```
1. 输入指令 → 发送
2. 查看日志和预览
3. 点击"确认应用"
4. 应用成功后自动关闭
```

#### 路径 2：中途退出
```
1. 输入指令 → 发送
2. 查看日志（不满意）
3. 点击 ← 返回按钮
4. 对话框关闭
```

#### 路径 3：清空重来
```
1. 输入指令 → 发送
2. 查看日志和预览（不满意）
3. 点击"清空"按钮
4. 回到初始居中状态
5. 重新输入指令
```

## 🎯 按钮层次

### 视觉权重

| 按钮 | 样式 | 权重 | 用途 |
|------|------|------|------|
| ← 返回 | 文本按钮 | 最低 | 退出 |
| 清空 | 文本按钮 | 低 | 重置 |
| 确认应用 | 实心按钮 | 最高 | 主要操作 |

### 位置分布

```
┌─────────────────────────────┐
│ ← (左上角)                   │  <- 权重最低，位置隐蔽
│                              │
│ (内容区域)                   │
│                              │
│ ─────────────────────────── │
│ [清空]          [确认应用]   │  <- 清空左下，应用右下
└─────────────────────────────┘
```

**设计原则：**
- ✅ 主要操作（确认应用）：右下角，橙色高亮
- ✅ 次要操作（清空）：左下角，灰色低调
- ✅ 退出操作（返回）：左上角，最低调
