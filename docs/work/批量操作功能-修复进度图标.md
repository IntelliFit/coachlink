# 批量操作功能 - 修复进度图标显示问题

## 问题描述

用户反馈："正在加载训练计划..." 等已完成的操作左侧仍然显示转圈圈的图标。

## 问题原因

### 后端消息流程

后端代码 (`route.ts`) 发送了多条 `progress` 类型的消息：

```typescript
// 第 285 行
sendMessage({ type: 'progress', message: '正在加载训练计划...' });

// 第 302 行
sendMessage({ type: 'progress', message: '正在加载动作库...' });

// 第 316 行
sendMessage({ type: 'progress', message: '正在分析您的指令...' });

// 第 386 行
sendMessage({ type: 'progress', message: '正在生成操作方案...' });

// 第 431 行
sendMessage({ type: 'progress', message: '正在执行操作...' });
```

### 前端渲染逻辑（旧版）

```tsx
const getLogIcon = () => {
    switch (entry.type) {
        case 'progress':
            return 'pi-spin pi-spinner';  // 所有 progress 都显示旋转图标
        // ...
    }
};
```

**问题：**
- ❌ 所有 `progress` 类型的消息都显示旋转图标
- ❌ 即使操作已完成，图标仍然在旋转
- ❌ 给用户造成困惑：已完成的步骤看起来像还在进行中

---

## 解决方案

### 核心思路

**只有最后一条 progress 消息才显示旋转图标，之前的都显示"完成"图标。**

### 实现代码

```tsx
const getLogIcon = () => {
    // 检查是否是最后一条日志
    const isLastEntry = index === logs.length - 1;
    
    switch (entry.type) {
        case 'progress':
            // 只有最后一条 progress 消息才显示旋转图标
            return isLastEntry ? 'pi-spin pi-spinner' : 'pi-check';
        case 'action_plan':
            return 'pi-list';
        case 'modification':
            return 'pi-pencil';
        // ... 其他类型
    }
};
```

### 逻辑说明

1. **判断是否是最后一条日志**
   ```tsx
   const isLastEntry = index === logs.length - 1;
   ```

2. **动态选择图标**
   - 最后一条 progress：`pi-spin pi-spinner`（旋转加载）
   - 之前的 progress：`pi-check`（完成对勾）

3. **实时更新**
   - 当新的日志添加时，之前最后一条的图标会自动变为对勾
   - 新添加的最后一条显示旋转图标

## 其他日志类型

非 `progress` 类型的日志不受影响，始终显示固定图标：

| 类型 | 图标 | 说明 |
|------|------|------|
| action_plan | `pi-list` | 执行计划 |
| modification | `pi-pencil` | 修改操作 |
| stats | `pi-chart-bar` | 统计信息 |
| success | `pi-check-circle` | 成功 |
| error | `pi-exclamation-circle` | 错误 |

## 技术细节

### React 渲染机制

```tsx
const renderLogEntry = (entry: LogEntry, index: number) => {
    const isLastEntry = index === logs.length - 1;
    // ...
};
```

- `logs` 是一个 state 数组
- 每次添加新日志，整个列表重新渲染
- `index === logs.length - 1` 会动态计算
- 之前的"最后一条"自动失去旋转效果

### 性能影响

- ✅ 无性能影响
- ✅ 仅增加一次比较操作
- ✅ 不需要额外的 state 或 useEffect
- ✅ 纯函数逻辑，易于测试

3. **快速连续添加多条消息**
   - 每条都应该正确显示图标
   - 旋转图标应该始终在最后
