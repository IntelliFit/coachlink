## 🎯 核心功能

### 1. 自然语言理解
- 用户输入自然语言指令
- DeepSeek AI 解析并生成 TypeScript 代码
- 支持复杂的批量操作逻辑

### 2. 安全代码执行
- 使用 isolated-vm 创建隔离的 V8 实例
- 严格的资源限制 (内存 128MB, 超时 10s)
- 无外部库访问权限
- 无异步操作支持

### 3. 实时进度反馈
- SSE 流式传输处理过程
- 7 种消息类型覆盖所有阶段
- 用户友好的日志显示
- 代码执行透明化

### 4. 数据操作能力
- 替换动作
- 修改参数 (组数、次数、重量等)
- 删除训练日或动作
- 批量设置备注
- 组合复杂操作

## 🔧 技术栈

- **AI**: DeepSeek API (deepseek-chat 模型)
- **代码隔离**: isolated-vm
- **流式传输**: Server-Sent Events (SSE)
- **前端框架**: Next.js 16, React 18
- **UI 组件**: PrimeReact
- **数据库**: Supabase (PostgreSQL)

## 📊 架构设计

```
用户输入自然语言
    ↓
前端 (BatchOperationDialog)
    ↓
服务层 (BatchOperationService)
    ↓
API 路由 (/api/plan-lib/batch-operation)
    ↓
DeepSeek AI (生成 TypeScript 代码)
    ↓
isolated-vm (安全执行代码)
    ↓
更新数据库 (coach_plan_templates)
    ↓
SSE 流式返回结果
```

## 🔒 安全特性

1. **身份验证**: 仅教练角色可访问
2. **权限控制**: 只能操作自己的模板
3. **代码隔离**: isolated-vm 沙箱执行
4. **资源限制**: 内存和时间严格限制
5. **输入验证**: 参数合法性检查

## 📈 性能指标

- **响应时间**: < 10s (含 AI 调用和代码执行)
- **内存使用**: < 128MB
- **并发支持**: 基于 Next.js 的自然并发
- **可扩展性**: 支持大规模训练计划 (8周+)

## 🎨 用户体验

1. **简单易用**: 自然语言输入,无需编程知识
2. **实时反馈**: 每个步骤都有清晰提示
3. **过程透明**: 显示生成的代码,可学习和验证
4. **错误处理**: 友好的错误消息和恢复机制

## 🚀 使用场景

### 场景 1: 动作替换
教练想把所有"引体向上"替换为"跑步",只需输入:
```
把所有引体向上替换为跑步
```

### 场景 2: 参数调整
教练想统一调整所有深蹲的参数:
```
把所有深蹲改为5组8次,重量100kg
```

### 场景 3: 内容删除
教练想删除所有休息日:
```
删除所有休息日
```

### 场景 4: 批量设置
教练想给所有训练日添加相同备注:
```
给所有训练日添加备注"注意热身"
```

## 🔄 数据流

### 请求流
```json
{
  "templateId": "uuid",
  "instruction": "把所有引体向上替换为跑步"
}
```

### 响应流 (SSE)
```
data: {"type":"progress","message":"正在加载训练计划模板..."}

data: {"type":"progress","message":"正在加载动作库..."}

data: {"type":"progress","message":"正在分析您的指令..."}

data: {"type":"code_execution","name":"替换引体向上为跑步","code":"..."}

data: {"type":"execution_result","success":true}

data: {"type":"final_result","success":true,"message":"操作完成!"}
```
