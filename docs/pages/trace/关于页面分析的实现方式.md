# Trace 埋点实现流程速览

- **公共工具**：`TRACE_ENV`、`ALLOW_DEV_TRACE`、`hasServiceRoleKey`、`safeText`、`safeProps`、`shouldSkipTrace` 集中在 [src/app/api/trace/trace-common.ts](src/app/api/trace/trace-common.ts#L1-L41)，统一做环境判断（未开 `TRACE_ALLOW_DEV=1` 且非生产/本地则跳过）、文本裁剪和 service role key 检查。
- **API 全局自动埋点**：API 中间件在每次命中时记录 `api_hit` 事件并异步写入 `admin_trace_events`，同时尊重跳过规则与 service key 检查，位置见 [src/app/api/middleware/api-trace.ts](src/app/api/middleware/api-trace.ts#L1-L43)。
- **自定义事件采集 POST /api/trace**：接收单条或批量（最多 50 条）事件，校验/裁剪字段，填充会话用户、UA、Referrer、环境与方法后写入 `admin_trace_events`；事件字段包含 `path`（即 to_path）、`from_path`、`duration_ms`，支持可选共享密钥 `TRACE_SHARED_SECRET`（或已登录用户）授权，逻辑见 [src/app/api/trace/route.ts](src/app/api/trace/route.ts#L22-L141)。
- **事件停留补充 PUT /api/trace**：按 `trace_id` 更新 `leave_at` 及可选 `duration_ms`，同样复用跳过与授权规则，位置在 [src/app/api/trace/route.ts](src/app/api/trace/route.ts#L143-L214)。
- **关键环境变量**：`NEXT_SUPABASE_SERVICE_ROLE_KEY`/`SUPABASE_SERVICE_ROLE_KEY`（写库必需），`TRACE_ALLOW_DEV`（设置为 "1" 才会在非生产/本地环境写入），`TRACE_ENABLE_API_TRACE`（设置为 "1" 才会记录后端 API 自动埋点，默认关闭），`TRACE_SHARED_SECRET`（可选共享密钥），`TRACE_ENV`/`NEXT_PUBLIC_APP_ENV`/`APP_ENV`/`NODE_ENV`（决定埋点环境值）。
