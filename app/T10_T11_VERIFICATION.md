# T10 & T11 前端验证文档

用于验证 T10 学员档案 PR 管理、T11 知识库搜索的前端和交互预期效果。便于自查与 bug 定位。

---

## T10 · 学员档案 — PR 管理

### 入口路径

1. **我的** → **我的档案**（或教练端 **学员** → 选择学员 → **档案**）
2. 进入档案详情页
3. 切换到 **「进步足迹」** Tab

### 预期效果

#### 有 PR 记录时

| 位置 | 预期 UI | 交互与效果 |
|------|---------|------------|
| Tab 标题行 | 显示「⏰ 进步足迹（N 个记录）」 | — |
| 右侧 | 「+ 手动记录 PR」按钮（橙色渐变背景） | 点击 → 弹窗提示「请在训练执行页完成某一组后，勾选「标记为PR」来记录进步。或在网页端 coachlink.fit 的档案页进行手动添加。」→ 点「知道了」关闭 |
| 每条 PR 卡片 | 日期、动作名、重量×次数、e1RM、**底部操作区** | 见下方「操作区」说明 |
| 操作区（每条卡片底部） | 有视频时显示「▶ 查看视频」（蓝底）+「删除」（红底） | **查看视频**：点击 → 跳转 `/pages/common/video-player/index?url=xxx` 播放 PR 视频<br>**删除**：点击 → 确认弹窗「确定要删除这条进步记录吗？」→ 确认 → Toast「已删除」→ 列表刷新 |

#### 无 PR 记录时

| 位置 | 预期 UI | 交互与效果 |
|------|---------|------------|
| Tab 标题行 | 「⏰ 进步足迹」+「+ 手动记录 PR」 | 同上 |
| 内容区 | 空状态：🏆 图标 +「暂无进步记录」+「在训练中标记进步组来记录突破」 | — |

#### 加载中

- 显示「加载中...」

### 自检要点

- [ ] **删除按钮**：每条 PR 卡片底部操作区是否有「删除」按钮（红底，13px 字）
- [ ] 删除确认弹窗「取消」是否生效（不删除）
- [ ] 删除成功后列表是否立即刷新
- [ ] 删除失败时是否有 Toast 提示
- [ ] **有 video_url 时**：是否显示「▶ 查看视频」；点击是否能跳转并播放
- [ ] 手动记录 PR 弹窗内容是否清晰
- [ ] 空状态与有数据时的布局是否正常

## T11 · 知识库搜索

### 入口路径

1. **我的** → **知识库**（底部导航或 profile 入口）
2. 进入知识库首页

### 预期效果

#### 搜索栏（页面顶部）

| 元素 | 预期 UI | 交互与效果 |
|------|---------|------------|
| 左侧输入框 | 占位符「搜索知识点...」 | 可输入、可回车触发搜索 |
| 右侧按钮 | 「搜索」文字，橙色背景 | 点击触发搜索 |

#### 未搜索时（默认状态）

| 区域 | 预期 UI |
|------|---------|
| 搜索栏下方 | 标题「知识库」、描述、书籍区、技术文章区、视频课程占位 |

#### 搜索中

| 区域 | 预期 UI |
|------|---------|
| 搜索结果区 | 显示「搜索中...」 |

#### 有搜索结果时

| 位置 | 预期 UI | 交互与效果 |
|------|---------|------------|
| 顶部 | 「收起搜索」链接（橙色） | 点击 → 清空搜索、隐藏结果、恢复默认书籍+文章列表 |
| 结果区 | 「找到 N 个相关结果」 | — |
| 每条结果卡片 | 左侧图标（文章/视频为琥珀色，其余橙色）、标题、类型标签（领域/分类/主题/文章/视频）、描述、身体区域标签 | **文章/视频**：点击 → 跳转知识节点详情页<br>**其他类型**：点击 → Toast「该分类暂不支持查看」 |

#### 无搜索结果时

| 位置 | 预期 UI | 交互与效果 |
|------|---------|------------|
| 结果区 | 「没有找到与 "关键词" 相关的内容」 | — |
| 下方 | 「试试其他关键词」+ 四个标签：「深蹲」「肩颈」「拉伸」「评估」 | 点击任一词 → 自动用该词搜索并展示结果 |

### 知识节点详情页（点击文章/视频结果后）

| 位置 | 预期 UI | 交互与效果 |
|------|---------|------------|
| 顶部导航 | 「返回」+ 标题（节点标题截断） | 返回 → 返回知识库 |
| 内容区 | 类型标签、标题、描述、身体区域标签 | — |
| 视频类型 | 视频播放器 | 可播放 |
| 文章类型 | 正文（富文本） | — |
| 底部 | 「相关教练文章」列表（若有） | 点击 → 跳转 content-detail |

#### 异常情况

- 节点 ID 无效或加载失败 → 显示「加载失败，请稍后重试」+「返回上一页」

### 自检要点

- [ ] 输入关键词并点击「搜索」/回车是否触发搜索
- [ ] 空关键词时是否不会发起请求
- [ ] 有结果时卡片样式、类型标签是否正常
- [ ] 文章/视频点击是否跳转到节点详情
- [ ] 领域/分类/主题点击是否出现「暂不支持」提示
- [ ] 「收起搜索」是否恢复正常列表
- [ ] 无结果时推荐关键词是否可点击并触发搜索
- [ ] 节点详情页的视频能否播放、正文是否正确渲染

## 涉及路由与页面

| 路径 | 说明 |
|------|------|
| `/pages/profile/detail/index` | 档案详情（进步足迹 Tab 所在页） |
| `/pages/common/video-player/index?url=xxx` | PR 视频播放页（有 video_url 时从进步足迹进入） |
| `/pages/knowledge/index` | 知识库首页（含搜索） |
| `/pages/knowledge/node-detail/index?id=xxx` | 知识节点详情（文章/视频） |
| `/pages/content-detail/index?id=xxx` | 教练文章详情（从节点详情相关文章进入） |

## 常见可能问题

1. **T10 删除失败**：检查后端 `POST /api/execution/delete-pr-record` 是否可用、`recordId` 是否正确。
2. **T11 搜索无结果**：确认后端 `GET /api/knowledge/search?q=xxx` 存在且返回 `{ results: [...] }`；小程序与后端是否同一域名/环境。
3. **节点详情加载失败**：确认 `GET /api/knowledge/nodes/:id` 可用；检查 `id` 参数是否正确传入。
