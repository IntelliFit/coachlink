# 体验者直接测试 XPay（2026-10-11）

此要求覆盖旧“仅管理员联调”指引。普通体验者不提供昵称/用户编号给代理、不进入平台白名单，不提升管理员权限。

1. 微信后台确认最新体验包；Android使用自己的普通账号微信登录，退出重进仍已登录。
2. 学员与教练“我的”均有“支付测试（沙箱）”；正式版无此入口。点开可读自己的额度和订单，不受is_admin限制。
3. 密码登录且尚未绑定微信的账号也能进入，点击支付时走现有bind-wechat流程；绑定冲突清楚提示，不覆盖他人微信绑定。不可在工具中伪造openid或用cldev凭据付款。
4. 支付弹窗明确沙箱、标价2元且不扣真实款。先取消，再重试原订单；原订单号不变。
5. 微信付款回调之后，由服务端query_order核验付款，AI余额只增加3，notify_provide_goods成功后才显示通过。
6. 查单三次、退出重进，余额不再次增加。不要在联调中途使用AI导入；余额变化应失败关闭而不是重复送额度。
7. 两个普通账号只看各自订单。匿名、cldev、main或env0联调均拒绝。普通免费会员购买仍关闭、教练汇付购买/分账不变。
8. 代理不点击确认付款、不自动退款或清理支付记录。DevTools截图/Mock只用于界面验证，与真机支付结果分别报告；finally恢复本任务mock/storage并释放窗口。
