# 服务周结转回归指令

在coachlink本地执行，禁止生产库测试写入，禁止猜测学员实际训练日期。不得为了让断言通过而修改业务规则或已有测试。

1. 运行 `npx vitest run tests/service-week-carryover-regression.test.ts tests/skip-completed-day-regression.test.ts`。
2. 验证4周每周3练完成1次剩3又2/3周；同频率对应11次；换2/4/5练后仍是3又2/3服务周，预计剩余服务时长一致，末尾非整周不被截断。
3. 验证重复完成不重复扣减，跳过/休息/空attempt不扣，线下迁移与完成记录去重，变频周各按自己的训练总数折算，缺历史原计划拒绝结转。
4. 验证skip-day不能覆盖较早completed；读取错误不写；CAS冲突拒绝；重复跳过不重写时间。
5. 如有隔离数据库和浏览器环境，先确认连接不是业务库；使用独立测试身份完成登录/刷新会话、教练与个人计划CRUD、换计划、补记、重复提交和并发冲突。记录所有创建主键，在finally中清理，即使断言失败也执行；清理后查零残留。
6. 真实6196只允许读取月历/训练详情/打开取消日期弹窗，不得提交日期或训练。分别报告代码测试、浏览器读取、隔离数据库写入是否实测，未执行不得写通过。
