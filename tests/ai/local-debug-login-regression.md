# AI 回归指令：本地用户 ID 模拟登录

只在 CoachLink 本地执行，不提交/推送/上传，不改真实学员训练记录。先读仓库 AGENTS 与 weapp-devtools/port-manager 技能，按窗口管理规范确认完整路径、AppID、空闲所有者；不得因超时重复开窗。

1. 执行 `npx vitest run tests/local-debug-login.test.ts tests/local-debug-session.test.ts`；记录结果，失败不擅改既有测试。
2. 端口经分配后，用 `npm run dev:debug-login` 启动独立后端。日志应显示后台任务 disabled；配对码和签名 key 不外发、不放源码。检查 `.env` 选定的数据源，而不是假定“localhost=测试库”。
3. 用 `npm run weapp:debug-login` 构建独立产物。在闲置窗口备份 config/storage/原页后串行验证，不覆盖发布目录内容。若现有窗口的构建根无法跨项目目录，使用可恢复的内部临时副本；完成后移走。
4. 在 auth/login 真实输入本轮授权目标 UUID、配对码，点击按钮；核对警告文字。错误配对码必须失败且原账号不变。正确配对只 SELECT，不能新建或修改档案、微信绑定。
5. 核对顶部模拟身份、完整 UUID、API、数据源指纹；真实首页计划归属一致。刷新后账号保持。记录截图与至少一次实际输入/点击；截图失败记录原始错误，不凭编译成功声称 UI 通过。
6. 不在真实学员上点击开始/完成/取消或写训练数据。写操作覆盖必须另用隔离测试库/授权账号，并在 finally 精确清理全部主键；不能以任意真实学员为“测试号”。
7. 点击退出模拟：恢复原 user/token 或原未登录状态，既有训练缓存清除。多次换目标后也应恢复最初账号；过期后不能静默变成操作者微信账号。到期提示与重配对可用。
8. API 负向：生产/普通服务不接受 cldev 凭证；远程 Host/跨域/错误配对码拒绝；管理/支付/绑定拒绝。不要用真的支付请求验证，只验证被拦截的测试路径。
9. finally 恢复本任务 mock、所有原 storage、原项目配置及页面；断开每次 CLI 连接并登记释放。借用窗口不关。自建临时窗口应关闭，保留给用户须明确交接。停止本任务专用后端使临时凭证失效，不杀其他项目进程。
10. 输出清楚区分：单测、接口、UI 交互、截图、真机、完整 Web E2E。若运行旧 E2E，先确保独立测试数据源与可验证的失败清理；当前 best-effort cleanup 不能当成保证。
