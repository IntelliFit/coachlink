# 小程序自动发布

本项目优先使用本机微信开发者工具 CLI 上传体验版；没有安装开发者工具时回退到 `miniprogram-ci`。提审、查询审核和正式发布仍通过微信服务端代码管理 API 完成。

## 一次性配置

1. 在微信公众平台用小程序管理员下载代码上传密钥，并配置 CI 上传 IP 白名单。
2. 复制私有环境变量模板：

```bash
cd D:\files\coachlink\apps/wechat
copy .env.weapp-release.example .env.weapp-release.local
```

3. 填写 `.env.weapp-release.local`：

```env
WEAPP_UPLOAD_PRIVATE_KEY_PATH=D:\secure\private.wx316e39eb71c0e834.key
WEAPP_UPLOAD_PROVIDER=auto
WEAPP_DEVTOOLS_CLI_PATH=D:\software\微信web开发者工具\cli.bat
WEAPP_DEVTOOLS_CLI_PORT=28264
WEAPP_APP_SECRET=your-app-secret
```

4. 生成审核类目配置：

```bash
npm run release:categories
npm run release:pages
copy release.weapp.example.json release.weapp.json
```

把 `release.weapp.json` 里的 `first_id` / `second_id` / `first_class` / `second_class` 改成真实类目。`release.weapp.json` 和 `.env.weapp-release.local` 都被 `.gitignore` 忽略，不能提交。

## 常用命令

在仓库根目录执行：

```bash
npm run weapp:release:upload
```

构建 `dist-release` 并上传体验版。

```bash
npm run weapp:release:auto
```

构建、上传体验版、提交审核、轮询直到审核通过；默认不发布正式版。

```bash
npm run weapp:release:full
```

构建、上传体验版、提交审核、轮询审核；审核通过后直接发布正式版。

```bash
npm run weapp:release:publish
```

发布当前已审核通过的版本。

灰度发布：

```bash
npm run weapp:release:publish -- --gray 10
```

## 设计说明

- 发布构建产物固定使用 `dist-release/`，上传器直接以这个目录作为微信项目根，并在上传前校验 `project.config.json`、`app.json`、`app.js`，避免误传本地调试目录 `dist/` 或空包。
- `WEAPP_UPLOAD_PROVIDER=auto` 会优先选择已安装的微信开发者工具 CLI；可显式设为 `devtools` 或 `miniprogram-ci`。上传密钥只在走 `miniprogram-ci` 时需要。
- 提审和发布需要 `WEAPP_APP_SECRET` 换取微信 `access_token`。
- `deploy_versions/latest-weapp-release.json` 会记录最近一次上传、审核和发布结果，便于后续查看。
- `release:full` 是无人值守正式发布命令，只有在你明确下这个命令时才会审核通过后自动发布。
