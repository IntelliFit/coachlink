## 一、平台概览

**平台名称：** 启能教链（CoachLink）

**平台定位：** 面向力量训练教练群体的数字化线上执教平台，致力于成为教练的"数字化办公室"——帮助教练高效开展在线执教业务，帮助学员发现匹配的教练、购买训练服务、完成训练记录与成长追踪。

**主要功能领域：**

- 教练发现与订阅（商品市场、个人主页）
- 训练计划结构化制定与分配
- 训练执行记录与数据追踪
- 训练视频点评与动作反馈
- 智能辅助工具（AI 导入训练计划、营养分析等）
- 付费内容（图文/视频课程）
- 力量街健点位地图社区

## 二、角色与职责

### 2.1 学员（Student）

- 在平台注册后默认为学员角色
- 浏览并订阅教练训练计划
- 购买单篇付费内容或平台会员
- 执行教练分配的训练计划，记录训练数据
- 进行训练视频上传和动作反馈

### 2.2 教练（Coach）/ 二级子商户

- 需通过平台审核后方可开展业务
- 在平台发布服务商品（训练计划订阅档位、单篇内容）
- 管理学员订阅关系与训练计划
- 通过平台收取学员支付的服务费用，申请提现至本人绑定账户
- 在微信支付收付通体系中，教练作为**二级子商户**主体，需完成子商户进件，平台按合同约定比例进行分账结算

## 三、商品与服务内容

### 3.1 教练对学员的服务商品（核心商品）

教练在自定义编辑训练计划后，发布于 个人（商户）首=主页，供学员自主选择订阅：

| 商品形式 | 说明 |
|----------|------|
| **订阅制服务** | 按1/2/3月周期订阅，涵盖训练计划制定、执行指导、视频反馈、AI 辅助工具等 |
| **单篇付费内容** | 教练上传的图文或视频课程，平台用户可按篇单独购买，或成为对应教练的学员即可免费查看 |
| **访客内容购买** | 未订阅教练的用户可单独购买教练公开内容 |

### 3.2 平台向学员提供的会员商品

·基础会员（月付）  
·高级会员（月付）  
·单独购买月度智能计划生成次数   
·单独购买视频/图片等静态资源上传容量   


> 平台会员解锁平台侧功能权益（如更多存储空间、AI 调用次数），与教练订阅服务独立计费。

## 四、资金链管理

### 4.1 当前实现：支付宝收单体系

**支付流程：**

```
学员端下单
  → 平台创建支付宝订单
  → 学员跳转支付宝完成支付
  → 支付宝异步回调（验签）
  → 更新订单状态 + 履约（更新订阅记录）
  → 订单金额全额写入教练钱包流水
```

**辅助路径：教练个人收款码（非平台直连）**

- 教练可上传微信/支付宝个人收款码，供学员扫码线下付款
- 此路径资金不经过平台账户，平台不参与收单与分账

**退款流程：**

```
管理员在后台对已支付订单发起退款
  → 调用支付宝退款 API
  → 同步取消订阅记录
  → 扣减教练钱包余额
```

**提现流程：**

```
教练申请提现（填写金额 + 支付宝收款账户）
  → 生成提现单
  → 管理员在后台审核，手动向教练支付宝账户转账（⚠️存在风险，所以需要接入收付通）
  → 管理员确认到账（填写支付宝转账订单号）
  → 提现单状态变为 completed，钱包余额扣减
```

## 五、微信支付收付通接入需求

### 5.1 当前状态说明

| 能力 | 现状 |
|------|------|
| 微信登录（小程序/网页授权） | ✅ 已接入 |
| 教练微信个人收款码展示 | ✅ 已支持（非平台 API） |
| 微信支付 API 下单 | ❌ 未实现 |
| 收付通分账能力 | ❌ 未实现（协议文本已准备） |

> 微信当前支付api收账到虚拟商户账号后会自动提现到公司绑定银行卡中，该行为无法进行设置修改，存在较高法律风险，故暂未接入。

---

### 5.2 收付通产品接入方案

#### 5.2.1 服务商（平台主体）层面

1. 智健启能（北京）科技有限公司以**微信支付服务商**身份入驻，申请收付通产品权限
2. 提交材料：营业执照、法人身份证、结算银行账户、业务场景说明（在线教练服务）等材料
3. 审核通过后获得服务商 `mchid`，配置平台侧平台抽成比例

#### 5.2.2 教练作为二级子商户

1. 教练入驻时需完成**子商户进件**：
   - 提交姓名、身份证正反面、联系方式、结算银行账户
   - 走微信支付子商户资质审核流程
   - 审核通过后获得 `sub_mchid`
2. 教练须签署《平台入驻与合作协议》

#### 5.2.3 支付与分账完整链路

```
学员发起微信支付
  → 平台服务商合单下单（微信支付 V3 API：/v3/pay/partner/transactions）
  → 学员完成微信支付
  → 微信回调通知
  → 触发分账：
      ├─ 教练子商户账户：获得 (1 - 抽成比例) × 实付金额
      └─ 平台服务商账户：获得 抽成比例 × 实付金额（平台佣金）
  → 写入分账流水
  → 更新订阅状态
```
---

### 5.4 关键合规要求

1. **用户协议与隐私政策**：需在用户注册环节明确展示并获取同意
2. **消费者权益保护**：按《消费者权益保护法》落实七天无理由退款、投诉处理机制
3. **教练入驻协议**：明确平台技术服务费/抽成比例、分账规则、结算周期、违约责任
4. **微信支付合规要求**：
   - 不得将收付通用于违规场景
   - 子商户须完成实名认证
   - 需在平台页面展示商户编号与投诉渠道
