# 数据驱动训练：用训练记录与 PR 趋势做阶段复盘

训练计划的调整，最怕两件事：  
一是“凭感觉改”，二是“只盯着体重/围度忽略训练表现”。  
更可靠的做法，是把训练过程数据化，用数据做阶段复盘。

## 1. 复盘应该看哪些数据

建议关注四类指标：

- **完成度**：训练日完成率、跳过率、连续训练天数  
- **强度表现**：关键动作的训练重量/次数/主观强度（例如 RPE）  
- **PR 与趋势**：PR 发生的频率、关键动作 e1RM 变化趋势  
- **恢复信号**：同一强度下表现波动、训练间隔变化等

## 2. 从“记录”到“趋势”

结构化记录的好处是：  
每一组都能形成可聚合的数据，趋势自然可计算。

举例：卧推在 4 周内的趋势可以用下列维度观察：

- 训练重量在相同次数下是否上涨  
- 相同重量下的次数是否提高  
- 主观强度是否下降（更轻松完成）

## 3. 阶段调整的基本策略（示例）

当数据出现以下信号时，可以考虑调整：

- 完成度持续下降：先处理训练频率与恢复  
- PR 长期不出现：检查负荷进阶与动作选择  
- 表现大幅波动：检查训练安排是否过密或过稀

## 4. 结论

“数据驱动”不是复杂化，而是把训练调整变得可解释：  
让用户知道“为什么要改”，让教练知道“改了之后是否有效”。
