# 视频 + 结构化记录：让远程指导更高效的技术实践

远程指导的沟通效率，常被一个问题拖垮：  
“你发来的视频，我不知道你当时做的是哪一组、什么重量、目标是什么。”

## 1. 让视频自带上下文

更好的方式是：上传视频时，同时绑定当次训练的结构化信息，例如：

- 动作名称、组次（第几组）  
- 训练重量、次数、强度描述  
- 当天训练目标（力量/技术/容量等）

这样教练看到视频就能快速进入语境，而不是反复追问。

## 2. 结构化记录如何帮助反馈

当“视频 + 记录”绑定后，反馈能变得更具体：

- 对比同一动作不同周的技术变化  
- 结合 PR 与趋势判断动作质量是否影响表现  
- 让建议可追踪：下次训练是否按建议执行

## 3. 平台实现的最小闭环（示例）

- 训练执行页：每组完成后可上传视频  
- 视频库：按教练/学员/动作聚合  
- 点评与跟踪：反馈与该组记录绑定，后续可复查

## 4. 结论

技术手段的目的，是减少无效沟通，让指导更像“面对面”：
同一份视频，在正确的上下文里，价值会倍增。
