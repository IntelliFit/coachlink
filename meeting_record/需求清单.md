| 需求编号  | 需求描述                             | 优先级 | 来源会议 | 状态      |
| --------- | ------------------------------------ | ------ | -------- | --------- |
| INFRA-001 | 微信小程序认证与上线                 | P0     | 01-27    | ✅ 已完成 |
| INFRA-002 | 小程序改名为"智健教链"               | P0     | 01-27    | 🔄 进行中 |
| INFRA-003 | 小程序 Token 鉴权适配（替代 Cookie） | P0     | 01-27    | ⏳ 待开发 |
| INFRA-004 | 小程序服务号申请（用于推送通知）     | P0     | 01-27    | ⏳ 待申请 |
| INFRA-005 | 小程序与服务号绑定                   | P1     | 01-27    | ⏳ 待开发 |

**详细说明：**

#### INFRA-003 小程序 Token 鉴权适配

- **背景：** 微信小程序无法使用 Cookie，但后端 `getServiceSession` 当前依赖
  Cookie 获取用户会话。
- **需求：**
  1. 小程序登录后，后端返回 Token（JWT 或自定义 Token）。
  2. 小程序每次请求在 Header 中携带 `Authorization: Bearer <token>`。
  3. 后端 `getServiceSession` 或中间件优先检查 Header Token，若无再检查 Cookie。
- **验收标准：** 小程序用户可正常登录、访问所有 API。

#### INFRA-004 服务号申请

- **背景：** PWA 推送在国内不可用（依赖 Google
  FCM），小程序原生订阅消息限制多。服务号的"模板消息"是最可靠的推送方式。
- **需求：**
  1. 申请微信服务号（需企业资质）。
  2. 服务号与小程序绑定后，可在用户锁屏发送通知（如"教练给你发了新计划"）。
- **验收标准：** 能通过服务号向用户发送模板消息。

**详细说明：**

#### INFRA-010 GitHub Actions 自动化部署

- **当前状态：** 手动 SCP 上传到服务器。
- **目标流程：**
  1. 开发者推送代码到 `dev` 分支。
  2. GitHub Actions 自动运行测试。
  3. 测试通过后，自动部署到 Staging 环境。
  4. `main` 分支合并后，自动部署到 Production。

- **分支定义：**
  | 分支        | 用途         | 合并规则     |
  | ----------- | ------------ | ------------ |
  | `main`      | 生产环境     | 需多人审批   |
  | `dev`       | 开发/Staging | 需1人 Review |
  | `feature/*` | 功能开发     | 自由提交     |
- **流程：** `feature/*` → `dev`（Review）→ `main`（3人审批）

| 需求编号 | 需求描述                     | 优先级 | 来源会议 | 状态      |
| -------- | ---------------------------- | ------ | -------- | --------- |
| USER-001 | 微信一键登录（小程序）       | P0     | 01-27    | ⏳ 待开发 |
| USER-002 | 手机验证码登录               | P0     | 01-07    | ✅ 已完成 |
| USER-003 | iOS 微信内置浏览器兼容性修复 | P1     | 01-15    | ⏳ 待修复 |
| USER-004 | 年龄输入改为日期选择器       | P2     | 01-15    | ⏳ 待优化 |

**详细说明：**

#### USER-001 微信一键登录

- **流程：**
  1. 用户打开小程序，点击"微信登录"。
  2. 调用 `wx.login()` 获取 code。
  3. 后端用 code 换取 `openid` 和 `session_key`。
  4. 若用户首次登录，创建账户；否则返回已有账户信息。
  5. 返回 Token 给小程序存储。
- **验收标准：** 新用户3秒内完成注册；老用户2秒内完成登录。

#### USER-003 iOS 兼容性问题

- **现象：** iOS 微信内网页扫码登录失败。
- **原因：** 微信内置浏览器对弹窗/二维码处理有限制。
- **方案：** 检测到 iOS 微信环境时，引导用户使用小程序。
