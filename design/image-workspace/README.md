# CoachLink Image Workspace

This workspace stores visual references and generated image assets for software illustrations.

## Structure

- `references/`: source/reference images copied from local inputs.
- `outputs/`: generated or processed visual assets.
- `docs/`: reusable character, style, and production notes.
