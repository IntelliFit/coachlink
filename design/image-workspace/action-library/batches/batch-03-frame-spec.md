# batch-03 frame spec

Global: v4 persona, 3-key-frame horizontal strip, action-only red/orange highlights, no labels/text/watermark.

## 011 团身引体
- Camera/view: front 3/4 slightly below bar height.
- Equipment: fixed pull-up bar.
- Frame 1: dead hang, knees tucked, elbows straight.
- Frame 2: midpoint pull, knees tucked, elbows about 90 degrees, scapulae depressed/retracted.
- Frame 3: chin near/above bar, compact tuck held.
- Primary red: lats, teres major, mid/lower traps, rhomboids.
- Secondary orange: biceps, brachialis, brachioradialis, rear delts, forearms, abs/hip flexors lightly.
- Avoid: kip, straight legs, colored chest/legs.

## 012 引体向上
- Camera/view: front 3/4, full body.
- Equipment: fixed pull-up bar.
- Frame 1: dead hang, arms straight, legs vertical.
- Frame 2: elbows around 90 degrees, chest rising, scapulae depressed.
- Frame 3: chin above bar, elbows close to ribs.
- Primary red: lats, teres major, rhomboids, mid/lower traps.
- Secondary orange: biceps, brachialis, brachioradialis, rear delts, forearms.
- Avoid: kipping, overarched back, flared elbows.

## 013 直体双力臂
- Camera/view: side-front 3/4 showing pull-to-transition.
- Equipment: fixed pull-up bar.
- Frame 1: straight-body hollow hang.
- Frame 2: chest high to bar, wrists rolling over, torso mostly straight.
- Frame 3: top support above bar, elbows locked, shoulders stacked.
- Primary red: lats, teres major, mid/lower traps, rhomboids.
- Secondary orange: biceps, brachialis, forearms, rear delts, triceps, anterior delts.
- Avoid: knee tuck, leg kick, deep dip finish.

## 014 直腿双力臂
- Camera/view: side 3/4, straight legs and bar path visible.
- Equipment: fixed pull-up bar.
- Frame 1: hang with straight legs, slight hollow.
- Frame 2: high pull and turnover with straight legs.
- Frame 3: top support, elbows extended, legs straight.
- Primary red: lats, teres major, rhomboids, mid/lower traps.
- Secondary orange: biceps, brachialis, brachioradialis, forearms, triceps, delts, abs lightly.
- Avoid: knee bend, pike too high, ring equipment.

## 015 吊环澳式引体
- Camera/view: side 3/4 low angle, body line visible.
- Equipment: gymnastics rings.
- Frame 1: inclined supine hang, arms straight, heels on floor, straight plank body.
- Frame 2: chest moving to rings, elbows flexing, scapulae retracting.
- Frame 3: chest close to rings, elbows behind torso.
- Primary red: lats, rhomboids, mid/lower traps, rear delts.
- Secondary orange: biceps, brachialis, brachioradialis, forearms, rotator cuff.
- Avoid: hip sag, bent knees, shrugging.
