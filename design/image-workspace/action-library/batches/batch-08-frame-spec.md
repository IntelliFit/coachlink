# batch-08 frame spec

Global: v4 persona, 3-key-frame triptych, no text/labels/watermark.

## 036 俯身哑铃后束飞鸟
- Camera/view: 3/4 rear side, slight overhead.
- Equipment: pair of dumbbells.
- Frame 1: hip hinge, neutral spine, arms hanging.
- Frame 2: arms abduct outward halfway, elbows soft.
- Frame 3: arms wide in T, rear shoulders contracted.
- Primary red: 三角肌后束.
- Secondary orange: 菱形肌.
- Avoid: shrugging, rounded back, front-delt emphasis.

## 037 俯卧腿弯举
- Camera/view: side view, full bench.
- Equipment: prone leg curl machine.
- Frame 1: lying face down, legs extended, roller behind lower calves.
- Frame 2: knees flex halfway, roller moves upward.
- Frame 3: heels curl toward glutes.
- Primary red: 腘绳肌.
- Secondary orange: subtle calf stabilization if needed.
- Avoid: hip lift, back arch, quadriceps highlight.

## 038 负重双杠臂屈伸
- Camera/view: front 3/4, dip bars visible.
- Equipment: parallel bars, weight belt with plate.
- Frame 1: top support, elbows extended, torso forward.
- Frame 2: eccentric midpoint, elbows bent, chest leaning forward.
- Frame 3: press to top, elbows extended.
- Primary red: 胸大肌.
- Secondary orange: 三头肌, 肩部.
- Avoid: shoulder shrug, leg highlights.

## 039 负重引体向上
- Camera/view: front 3/4, pull-up bar centered.
- Equipment: pull-up bar, weight belt.
- Frame 1: dead hang, arms extended.
- Frame 2: elbows driving down, chest rising.
- Frame 3: chin above bar.
- Primary red: 背阔肌.
- Secondary orange: 肱二头, 核心.
- Avoid: swinging, kipping.

## 040 杠铃划船
- Camera/view: 3/4 rear side, slight overhead.
- Equipment: barbell.
- Frame 1: hip-hinged torso, bar below knees, arms extended.
- Frame 2: bar rising toward lower ribs.
- Frame 3: bar close to lower ribs, scapulae retracted.
- Primary red: 背阔肌.
- Secondary orange: 菱形肌, 三角肌后束.
- Avoid: upright row, rounded spine, trap shrug dominance.
