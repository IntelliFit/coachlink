# CoachLink

力量训练教练智能化线上执教平台。

## 📖 快速入门

如果你是新加入项目的开发者，请先阅读：

👉 **[项目全景图 (Project Bible)](./docs/PROJECT_BIBLE.md)**

该文档包含了业务愿景、核心逻辑、技术栈以及开发者规范。

## 🛠 开发环境

1. 安装依赖：`npm install`
2. 启动开发服务器：`npm run dev`
3. 环境变量：复制 `.env.example` 为 `.env.local` 并填写 Supabase 配置。

## 📂 目录结构

*   `src/app`: 路由与 API
*   `src/components`: UI 组件
*   `src/lib`: 核心业务逻辑
*   `supabase/`: 数据库与策略
*   `docs/`: 项目文档库
