## Phase 2 — 教练详情页 7/2 数字打架

- 现象：用户访问教练 桑马葛 主页时，顶部统计写 `7 教学内容`，但下方 tab 只显示 `教学内容(2)`。
- 根因：`get-aggregated-info` 不带 `required_tier` 过滤，`get-contents` 用 `lte('required_tier', accessTier)` 过滤；同源接口口径不一致。
- 修复：
  - `src/app/api/coach/get-contents/route.ts`：删除 `lte` 过滤，改为全量返回 + 未达 tier 行的 `content` 截断为 200 字预览、`media_urls=[]`、加 `is_locked: true`。
  - `src/app/api/coach/get-contents/entity.ts`：新增 `GetContentsListItem = CoachContentRow & { is_locked: boolean }`。
  - `wechat_app/src/discovery/coach-profile/components/ContentSection.tsx + .scss`：按 `is_locked` 渲染 `Lock` icon 半透明遮罩 + meta 文案 "· 订阅后可见"。
  - `get-content-by-id` 已经在 `required_tier > accessTier` 时返回 403，详情页付费墙逻辑保持。
- 知识沉淀：`docs/done/engineering/高频复发Bug清单.md` 第 26 条。

## Phase 3 — 小程序教练主页严格按网站设计对齐

- 现象：用户 `手机用户_0722`（active 订阅）访问教练主页，底部出现「智能生成计划 / 填写训练需求问卷 / 续费」三个按钮；网站上同一态只展示一个底部 CTA「查看订阅」。
- 用户原话：「这个页面请你严格按照网站的设计来 包括教学内容其实涉及到专栏 你仔细看看网站上怎么设计的」。
- 修复（基线 = `src/app/coach/profile/[id]/page.tsx` 与 `CoachIntroduction.tsx`）：
  - `wechat_app/src/discovery/coach-profile/index.tsx`：
    - 底部 CTA 折成单按钮：active→「查看订阅」/ waiting→「查看订阅进度」/ 默认→「立即订阅 / 查看价格」；删除 `handleGeneratePlan` 与 `智能生成计划` 按钮（Web 上根本没有，weapp 单飞产物）。
    - tab 文案 `教学内容(${contentsTotal})` → `教练专栏(${aggregatedInfo?.contentCount ?? contentsTotal})`，与 Web `CoachContent.tsx:57` 同名。
    - `handleSubscribe` 不再自动开启 renew 模式，改为只切到价格 tab + 提示；新增 `handleEnterRenewMode` 给面板内按钮使用。
    - 把 `handleOpenQuestionnaire` 通过 prop 传给 `CoachIntro`。
  - `wechat_app/src/discovery/coach-profile/components/CoachIntro.tsx + .scss`：新增 `onOpenQuestionnaire` prop，仅在 `userSubscription.status ∈ {waiting, active}` 时在 stats 下方渲染「查看问卷」小按钮（带 `Checklist` 图标），与 Web `CoachIntroduction.tsx:199-207` 同位置。
  - `wechat_app/src/discovery/coach-profile/components/PricingSection.tsx + .scss`：新增 `onEnterRenewMode` prop，在已订阅 banner 内渲染「续费」按钮 / 「已开启续费」标记，与 Web `CoachSubscription.tsx:431` 同位置；提示文案从「点击底部【续费】」改为「请点击右侧【续费】」。
  - `wechat_app/src/discovery/coach-profile/index.scss`：删除 `.generate-plan-btn`、`.questionnaire-btn` 失效样式块。
- 设计决策：weapp 没有 `articles/coach/[id]` 路由，Web 的「进入专栏」入口卡片暂不在 weapp 实现，避免跳空；只对齐 tab 文案与列表结构，避免造死链。
- 知识沉淀：`docs/done/engineering/高频复发Bug清单.md` 第 27 条 — Web↔小程序 UX 漂移规则（weapp 不得新增 Web 没有的功能性按钮；双端公共页以 Web 为视觉/CTA 基线）。
