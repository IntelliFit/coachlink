- Debug note: local `npm run dev` showed repeated `GET /api/auth/session 404` and `POST /api/auth/_log 404` while `/today-training` was 200.
- Finding: requests are emitted by NextAuth client usage (`SessionProvider`, `useSession`, `getSession`) in the web app. Source route exists at `src/app/api/auth/[...nextauth]/route.ts` and `.next/dev/server/app-paths-manifest.json` includes `/api/auth/[...nextauth]/route`, but live `localhost:3000` returned the built-in Next not-found HTML for `/api/auth/session`, `/api/auth/providers`, and `/api/auth/csrf`.
- Likely cause: stale/corrupted Next dev router/cache or a dev process using an old route table, not a missing page route. First recovery step should be stop dev server, remove `.next`, then restart `npm run dev`.
