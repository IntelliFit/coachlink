## WeChat Mini-Program Copy Link Diagnosis

- User compared Food Link's copied mini-program link format (`#小程序://食探/...`) with CoachLink's share sheet and asked why CoachLink seems unable to copy/share a link.
- Code findings:
  - CoachLink shareable pages already use normal mini-program sharing: page configs include `enableShareAppMessage` / `enableShareTimeline`, pages call `useShareAppMessage` / `useShareTimeline`, and `openCoachLinkShareMenu()` calls `Taro.showShareMenu`.
  - The repository has no `Taro.onCopyUrl` or `Taro.offCopyUrl` usage. Taro's WeChat typings document this as the separate right-menu `复制链接` callback and say pages should register it on entry and unregister it on exit.
- Diagnosis:
  - This is likely not a normal share-card bug. CoachLink has not implemented the Copy URL / mini-program short-link path, so the system `复制链接` item may be unavailable or not produce the expected `#小程序://...` link.
  - Final availability still needs real-device/platform verification because WeChat marks `onCopyUrl` as Android Beta and mini-program short-link capability may also be affected by WeChat backend permissions/category rules.
