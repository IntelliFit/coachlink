## Web 学员计划 `70%1RMRM` 与具体重量缺失

- 用户反馈：`/dashboard/students/plan/fcc8f6a6-3686-46a5-ba03-7844c4df21dc` 中 Wayne Tan 的计划显示 `70%1RMRM`，无法显示具体重量。
- 根因：历史计划旧字段 `params["强度"]` 可能保存为字符串 `70%1RM` / `70%rm`；前端将其误当 RM 次数并追加 `RM`，自动算重也因此拿非数字 reps 计算失败。
- 修复：`src/lib/rmCaculator.ts` 统一兼容解析旧强度字段，`ActionSetForm` 改用归一化后的 RM/百分比值，新增回归测试覆盖百分比字符串与 RM 字符串。
- 验证：`npm run lint`、`npm run typecheck`、`npm test`、`npx next build` 均通过。按用户长期偏好，未运行浏览器 UI 验证，留给用户手动确认页面显示。
