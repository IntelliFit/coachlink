# 汇付自动结算 401 根因修复

- 用户启动本地 Next 开发服务后，`HuifuSettlements ProcessDue/Reconcile` 均记录 HTTP 401 `用户未登录`。该错误日志由此前改动显式检查非 2xx 后出现，本身没有产生新的结算失败。

- 验证：本地 Apollo 开发配置下，`POST /api/admin/coach-subscription-settlements/process-due` + `dryRun:true` 已从 401 改为 200，返回 10 条待处理记录，未发生资金动作。`git diff --check`、`npm run lint`、`npm run typecheck`、`npm test`（35 files / 177 tests）、`npx next build` 均通过。
