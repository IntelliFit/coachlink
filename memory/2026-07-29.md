# 2026-07-29

- 用户认为回卷拉线式 Motion Pod 连接、固定和换动作流程麻烦，不利于普通用户推广；同时认可手环无法可靠获得训练重量、位移和力量动作速度等关键数据。
- 本轮重新头脑风暴低摩擦过渡方案，重点比较纯手机视觉、低成本视觉标记、夹扣式传感器、毫米波雷达、压力/测力设备和智能训练附件。
- 结论调整：拉线式传感器保留为实验室/固定力量房参考方案，不作为消费级首发。更好的过渡是“纯手机视觉 → 无电池视觉标记 Vision Tag → 可选 IMU/BLE Smart Tag”。
- 纯视觉阶段直接复用 CoachLink 当前计划里的动作与处方重量，只测轨迹、次数、节奏和速度；重量变更由学员快速确认，避免追求不现实的全自动重量识别。
- Vision Tag 可做成多面高对比已知尺寸标记，装在杠铃片/锁扣、负重腰带或身体夹上；无充电、无配对，搭配廉价手机支架，用于尺度校准和抗遮挡。试点验证高频使用后才开发主动电子夹扣。
