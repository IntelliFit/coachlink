## 功率分析 worker/队列归属复核

- 用户询问功率分析是否使用消息队列或 Redis，以及 worker 是独立项目还是当前目录内。
- 复核结论：功率分析代码在当前 `coachlink` 仓库内，worker 入口为 `scripts/power-analysis-worker.mjs`，核心逻辑在 `scripts/power-analysis-worker.ts` / `scripts/power-analysis-worker-cli.ts`，Python 分析器在 `scripts/power-analysis/analyze_video.py`。
- 运行形态是独立进程/独立 Docker 镜像，不是另一个 Git 项目；镜像文件为 `Dockerfile.power-worker`，推送脚本为 `scripts/push-power-worker-ccr.mjs`，npm 命令是 `npm run power-analysis:worker` 与 `npm run push-power-worker-ccr`。
- 队列层使用 `src/lib/taskqueue/*` 抽象；本地可用 memory queue，生产按设计使用 Kafka（`TASK_QUEUE_DRIVER=kafka`、`TASK_QUEUE_BROKERS`、`TASK_QUEUE_TOPIC`）。Redis 不是功率分析任务队列，只是项目其他功能依赖。
